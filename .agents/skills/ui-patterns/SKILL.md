# UI 元素形态契约

**事实源**：[docs/specs/ui-patterns.md](../../../docs/specs/ui-patterns.md)（元素形态目录——设计基元档位表 + 设置页/浮层元素模式 + 接入清单 + 不一致清单）。本技能是流程入口；档位与模式的正文只在该目录维护，此处不另建副本。

## 触发范围

新增或修改两个 webview（编辑器 `src/webview/main.css` 族、设置页 `src/webview/settingsPage.css`）中**用户可见的元素呈现**：二级组标题与组卡片、浮层（菜单/悬停提示/联想/查找/弹窗/toast）、按钮与徽章、设置行与控件、图标槽、圆角与阴影取值、焦点环形态。纯逻辑、纯文案（不动呈现）或仅涉公开契约兼容性的变更不适用本技能（后者走 style-contract 技能，两者可叠加：既改公开条目又改元素形态时都执行）。

## 流程

1. **先查目录再动手**：读 ui-patterns.md §1 设计基元（色彩变量族、圆角/阴影/z-index 档位、间距字号、焦点环）与 §2/§3 元素模式，为本次 UI 选定形态。**从既有档位取值，不发明新档位**；没有合型的元素先在目录登记新模式再实现。
2. **实现约束**：
   - 色彩一律主题变量优先（禁新增硬编码色值；明暗主题经变量或 color-mix 自适应）；
   - 组标题图标走 `settingsPageView.ts` 的 `ICON_PATHS` + `SettingsGroupIcon` 注册表（内联字形）或生图管线（`ai-icon-sheet-to-svg` 技能）；组头必须挂在组卡片内（负边距全幅头部，不许游离卡片外）；
   - 用户可见文字一律 i18n（`t()`，双语 parity 由编译期把关）。
3. **断言与钉住**：呈现类变更至少一条断言落**绘制层**（可见性、几何、计算色、墨迹——非 DOM 存在性）；组头/图标类沿用既有几何口径（图标 16px 贴左缘 20px、文字起点 44px、负边距与下边线）。
4. **同步目录**：新增/修改元素形态后更新 ui-patterns.md 对应小节；实现与目录不一致时以「CSS 实现 + 契约测试」为准并立即修目录。档位表新增行需在变更说明中给出理由。
5. **联动检查**：涉及公开契约条目（浮层族类名/变量多数已入 styleContract.ts）时执行 style-contract 技能全流程；用户可见变化进 CHANGELOG；人工验收项登记 manual-verification.md。

## 完成条件

- 变更后：相关绘制层测试通过、档位无私自新增、目录与实现一致（描述得出来回源码对质）；
- 交付说明列出：采用的档位与模式、钉住断言的位置、目录同步的段落；未验证项如实标注。

## 边界（不做什么）

- 不管辖公开样式契约的兼容与弃用（style-contract 技能域）；
- 不擅自统一 §5 已知不一致清单中的历史档位偏离——统一属用户可见变更，需拍板后单独立项；
- 不为未落地的设想形态预写模式（目录只登记已实现并钉住的形态）。
