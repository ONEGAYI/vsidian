# 一期建立稳定样式入口，为二期 Obsidian CSS 片段兼容预留

## 状态

已接受，2026-09-23。用户确认 MVP 时追加二期自定义 CSS 片段与 Obsidian 同款选择器，并要求一期前端留口。

## 决定

一期在实时预览与阅读视图建立明确、稳定、可测试的内容样式入口；实现时核对并记录 Obsidian 对应选择器及变量。内部结构可演进，但不能无记录地破坏公开样式入口。对已交付语法逐项验证，新增表格、双链等功能时同步扩展兼容表。

二期实现 CSS 片段的配置、加载和应用。三期仅考察“插件上插件”，一期不建设通用插件框架。

## 取舍与边界

稳定选择器会约束前端 DOM 重构，但可减少二期为了兼容已有样式而重做视图的成本。兼容范围以实际映射与测试结果公开，不把 Obsidian 窗口布局、核心插件或第三方插件私有 DOM 一并视为已兼容。

一期用内部固定测试样式证明入口可用，不开放用户片段加载。二期再明确 CSS 外部资源、安全策略、作用域与优先级。

官方 CSS 片段资料仅作为格式与行为参考，不证明本项目已有兼容能力：[Obsidian CSS snippets](https://obsidian.md/help/snippets)。

状态：已接受设计方向，尚未实施。用户确认用户级指定文件夹、各项目共用，并将可定制范围扩展至正文、大纲、代码块按钮和图表弹窗等编辑器 webview 界面。本地与 Remote SSH 分别配置各环境的目录；独立设置页不应用片段，并提供暂停全部片段的恢复命令。

资源加载范围包括片段目录内的相对路径图片、字体和 CSS 导入，以及 HTTPS 字体和 HTTPS CSS 导入。使用浏览器标准 CSS 解析，扩展负责资源路径、热更新和可观测的加载失败反馈；被引用的本地 CSS 修改也须触发更新，首版不额外提供在线资源离线下载管理。此决定支持分文件样式及在线字体服务，同时引入依赖刷新与网络失败验证成本。

本地文件临时读取失败时，当前窗口保留上一次样式并提示；明确删除或关闭片段则撤下。网络字体失败使用备用字体，远程 CSS 失败不影响其他片段。CSS 语法错误遵循浏览器的无效规则忽略行为，不提供整份样式事务回滚承诺。

公开选择器和 CSS 变量作为兼容接口维护。建立结构化公开清单，记录用途、适用模式、示例及兼容状态；用户指南由清单生成，并与安装版本配套，通过扩展设置页提供样式参考入口。Obsidian 原名选择器和变量仅承诺明确清单中的支持项，不把语义对应等同于原名片段可直接使用。

清单驱动契约验证，验证须在真实渲染内容上证明片段产生预期样式效果，并覆盖模式切换、视口卸载后重新挂载。源码中仍含有类名或 DOM 节点存在，均不能单独证明样式契约有效。文档生成校验负责发现指南与清单不一致，渲染验证负责发现实现与清单不一致。

公开入口默认长期兼容，禁止随内部重构静默移除。确实无法兼容时，先发布弃用声明及替代写法，至少经过两个后续次版本且满 30 天后才允许移除；期限从包含弃用声明的版本实际发布时起算，不从工作分支写入日期起算。到期仅允许显式移除，不触发自动删除。具体兼容清单在规格阶段核实。此决定约束未来 DOM 重构，并增加渲染验证成本；收益是用户能够依据当前版本指南编写片段，既有片段的兼容性有可执行检查保护。

### 自动化执行建议（待纳入实施规格）

- 公开清单保留稳定标识、选择器或变量名、支持模式、弃用版本、替代写法和移除记录；用户参考由清单生成，CI 检查生成结果一致性。
- 以已发布版本的契约与回归片段作为历史基线，对候选实现执行旧片段渲染验证；不能只检查候选分支自身的清单和测试，避免实现、清单和测试一起被改后失去旧约束。
- 移除校验对照发布记录核实弃用版本、实际发布日期及版本跨度；缺少历史证据时校验失败，禁止以修改候选分支日期或单纯抬高版本号代替迁移期。
- 将清单差异校验、指南生成校验和历史片段绘制验证纳入合并必需检查，并在发布前复验时间与版本条件。具体仓库保护设置须在实施时核实；当前工作流注释称 unit/integration 为必需、browser 尚非必需，注释不作为远端配置已核实的证明。
- 兼容检查器、CI 工作流和历史基线的变更须单独审查；AGENTS.md 负责指引代理遵守入口，受保护的 CI 与评审负责约束，不能宣称仅靠同一分支内的测试绝对防止代理绕过。
