# 引用内容全文可达，锚点只决定初始定位

## 状态

已接受产品与内容模型方向，2026-10-01。来源为二期 #227 访谈 Q7、Q10，用户明确要求所有范围、容器和 Reading／Live 统一全文可达；尚未实施。

2026-10-02 用户确认 Q1–Q19 总共识，正式规格补齐下述范围身份迁移和循环规则；实现证据尚待对应票验证。

## 背景

一期及 1.5 期将全文、章节与块分别作为引用内容范围：章节／块引用只呈现选定部分，范围参与读取、来源准入、递归身份和缓存。

二期用户要求标题／块引用仅改变初始定位点，后续应像全文引用一样访问整个目标文档。若继续把锚点作为内容授权与编辑边界，会迫使用户另行切全文，也会使 Reading 与 Live 的内容范围分叉。

## 决定

- 悬停、正文嵌入、递归内部、混排、列表／引用及表格格内都访问目标全文。
- 全文、标题、块引用统一内容访问范围；标题与块 id 只决定打开时的初始定位点。
- Reading 与 Live 的全文可达语义一致。Reading 仍禁写，Live 按目标文档会话提供完整编辑能力。
- 原引用中的标题／块锚点保留，不因访问全文自动改写来源文档。
- 不增加「局部切全文」操作；目标全文已默认可达。
- 打开时继续验证引用锚点。文档存在但目标标题／块标记未命中时，沿用 `anchor-missing` 及「目标笔记中不存在锚点」错误提示，不以全文替代显示。全文可达适用于合法引用成功打开后的内容范围。

## 影响与取舍

这项选择有意调整一期章节／块 Reading 的局部呈现契约。本文前的历史交付记录仍描述原有行为，二期规格、协议、测试和样式边界须按新规则同步，不能只改前端滚动。

读取数据、内部滚动与挂载预算按全文评估；锚点导航不能作为绕过实例、字节、递归或来源准入预算的路径。

## 待细化的技术边界

全文文档身份与初始导航点需要分别建模。现有 full／heading／block 范围字段参与来源租约、循环判定、缓存及位置映射；迁移方案应证明来源校验与安全边界保持成立，不把旧字段简单丢弃后继续沿用旧假设。

二期将内容范围统一为全文后，祖先循环按规范目标文档身份判定；标题／块锚点仅作初始导航，不再把同文档的不同锚点当作不同内容节点。这调整 ADR-0009 中原有的“目标加语义范围”循环身份，原因是二期实际内容范围已经相同。兄弟重复目标仍合法，来源的当前版本、精确 occurrence、原引用和预算守卫保留，全文／解析副本按实际驻留计费。

打开时锚点不存在沿用既有错误分态，不新增定位回退。已成功打开的全文实例不因用户修改初始标题／块 id 被切成错误页；重新打开原引用时再验证锚点。刷新保持合法光标与滚动，同目标不同 occurrence 的实例状态独立。写入与历史归属继续遵循 [ADR-0010](0010-reference-edit-target-session.md)。

详细契约与实施前置验证见 [功能规格](../specs/hover-preview-embed.md) 的「二期正式规格」节。
