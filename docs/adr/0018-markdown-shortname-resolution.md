# 短文件名补查、内部链接类型与显式绝对路径引用

## 状态

已接受，2026-10-15 用户在 [#556](https://github.com/ONEGAYI/vsidian/issues/556) 设计访谈后最终确认以下决定并结束访谈。功能尚未实施，交互与验收要求见[实施规格](../specs/markdown-shortname-links.md)。

## 背景

[ADR-0008](0008-workspace-reference-index.md) 将链接限定为来源文档相对路径，明确移除了按文件名全根搜索。[ADR-0013](0013-wikilink-completion-file-catalog.md) 延续这一规则，双链联想显式选择目标后仍插入来源相对路径。

用户现在要求：同名 Markdown 在来源所属根内只有一个目标时，允许省略目录建立链接和引用关系。与此同时，现有相对路径链接应继续按原优先级解析，自动生成链接应由用户选择路径类型。

用户进一步确定第三档使用文件系统绝对路径，允许明确指定跨根及工作区外目标。实施后，本记录替代 ADR-0008 中禁止短名补查、禁止显式绝对路径越出来源根的限制，并为 ADR-0013 的固定插入路径增加配置。短名搜索与绝对路径访问分别定义，不把后者的访问范围用于前者的搜索。

## 已确认决定

### 统一解析规则

- 覆盖 Markdown 双链、普通 Markdown 链接及现有 Markdown 嵌入。跳转、悬停、出链与反链共享目标语义。
- 先使用现有来源相对路径解析。只有未命中且路径仅含文件名时，才补查来源所属工作区根内未被索引排除的唯一同名 Markdown。
- 补查出现多个候选时保持未解析。点击或预览提示补充路径，索引不归到任何候选；重复目标移除后重新解析并恢复。
- 新增补查只面向 Markdown，不扩展附件跨目录短名解析；不增加任意唯一目录后缀匹配。

### 内部链接类型

设置置于 Vsidian 自有设置页面。中文标题与描述使用用户给定的原文：

- 标题：内部链接类型
- 描述：设置在笔记中链接其他文件时插入“[[ ]]”中的文件路径类型。

选项依次为：

1. 尽可能简短的形式
2. 基于当前笔记的相对路径（默认）
3. 基于文件系统的绝对路径

设置覆盖全部文件候选的后续双链联想插入，不批量改写既有正文。“尽可能简短”在文件名、来源相对路径、文件系统绝对路径中选择能正确返回所选目标的最短形式；Markdown 能正确解析时可省略 `.md`。

### 显式绝对路径访问

显式绝对路径按当前扩展宿主的文件系统解释，允许跨根及访问工作区外目标。Windows 生成含盘符的完整路径，Remote SSH 使用服务器的 POSIX 路径；不把 POSIX `/` 改释为工作区根，也不新增 `file://` 等 URI 语法。

绝对路径复用各类型已有的打开、悬停、嵌入及引用编辑能力，按目标实际可读、可写状态执行。已索引来源指向外部目标的出链、反链与 VSCode 内明确更名更新均覆盖。

工作区外仅登记明确引用的目标及其关系，不扫描所在目录，不递归建库。反链范围由已索引来源决定，不宣称掌握整个文件系统中所有引用。

### 改名与移动

VSCode 内改名或移动时，自动更新应保留更名前已确定的目标身份：

- 原短名在新位置仍指向同一目标时，不改正文。
- 文件改名后，新短名仍唯一且准确时，更新短名。
- 无法安全保留短名时，改为有效的明确相对路径；跨根或外部目标无法用根内相对路径表达时，使用明确绝对路径保留目标身份。
- 已有路径链接继续按原形式更新，相对路径仍有效时保持相对，绝对路径跟随目标更名；不因切换插入设置而批量换风格。

## 影响与取舍

相对路径优先意味着：一个原靠跨目录短名补查命中的链接，在来源目录新建同名文件后，会转向该同目录文件。这是所选优先级的结果；索引与已显示的引用关系必须同步更新，不能继续显示旧目标反链。

唯一性依赖文件集合，而非单条来源文本。文件增删、改名、根变化及排除变化可能改变其他文档的解析结果；需要处理已解析边的失效，不能只重接断链。扫描未完整时不能把一个已发现候选宣称为全根唯一。

跨根关系的目标身份不能继续仅用来源根内相对路径表示。技术方案须统一规范文件身份、跨根关系、快照恢复与更名计划，避免不同根的同名路径合并。索引仍为可重建缓存。

绝对路径便于确定本机目标，但迁移笔记后可能失效，默认仍为来源相对路径。远程访问、资源加载与目标会话沿现有宿主管线，不因为允许明确文件访问而扫描整个磁盘。

新增设置要求在自有设置页提供默认值、持久化、回显与生效验证。文案经 i18n；呈现与公开样式变更执行现有项目契约。以上是后续实施要求，本次尚未运行功能验证。
