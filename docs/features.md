# Vsidian 功能与设置详解

本文是 [README](https://github.com/ONEGAYI/vsidian/blob/main/README.md) 的功能详解页：各功能的完整行为与边界、使用速查、设置项一览与开发测试说明。条目随版本演进，版本历史见 [CHANGELOG](https://github.com/ONEGAYI/vsidian/blob/main/CHANGELOG.md)。

## 编辑与视图

- **双视图编辑器**：实时预览由 CodeMirror 6 全文承载（视口外不创建 DOM），阅读模式由 markdown-it 分块渲染、按需挂载——10 万行 / 10 万块级文档性能与体量基本无关。
- **三态切换**：标题栏按钮在「实时预览 → 阅读 → 源码编辑器」间循环；最近停留模式跨窗口全局记住，源码位置锚点保持不跳变。`.md` / `.markdown` 默认由本扩展打开，可随时右键改回原生编辑器。编辑器顶栏右端另有「阅读/Live」双态切换按钮与 `Ctrl+Q` 快捷键（不涉及源码模式），图标随当前模式变化。
- **刷新嵌入资源**：编辑器顶栏右端组（双态切换左侧）的循环箭头按钮，一键刷新当前文档面板的嵌入资源——外部程序替换磁盘上的同名图片后编辑器仍显示旧图时，点击立即清空图片缓存并按新代次重新装载（视口内图片重载闪动属预期）；Mermaid 图表懒加载失败后的终态一并重置，刷新后恢复重新注入。刷新为纯视图操作：光标/选区、滚动位置、三态视图模式与查找会话全部保持，不改文档内容与撤销栈。命令面板「Vsidian: 刷新嵌入资源」同款行为，可绑定快捷键（双模式生效，默认未绑定）。
- **查找与替换**：编辑器内 Ctrl+F / Cmd+F 打开查找面板（限本编辑器激活时）——大小写敏感、全字匹配、正则三开关嵌入查找框右缘，实时生效，状态按工作区记忆。选中一段文字后「在选定内容中查找」把匹配、导航与替换限制在该范围，范围随编辑自动映射；Ctrl+H 展开替换栏，替换下一个一次一笔撤销、全部替换整批一笔撤销，非法正则红边提示不崩溃。阅读模式命中按字符精确高亮（浅黄全部、深橙当前），落在表格或图形等渲染块内的命中浮出只读源码浮层；替换仅实时预览可用。
- **多光标编辑**：实时预览正文支持多条光标与选区并行编辑——Alt+点击在指针处添加/移除选区（Ctrl+点击保留给链接跳转），Ctrl+Alt+Up/Down 逐行添加光标（命令可改绑），Esc 收敛回单光标。多选区同时键入（含中文输入法）、删除与格式操作并行生效：行内格式逐选区独立判定（一处加粗一处取消可并存），宿主撤销一次整批回退；标题、列表等结构性操作只作用于主选区。设置项「多光标」默认开启，关闭后回到单光标行为。
- **选下一处相同词**：无选区按 Ctrl+D 先选中光标所在词，此后每按一次把下一处相同词追加为选区并成为活动光标（到文档尾回绕）；会话期间显示仅含三个开关按钮的查找选项条，无选区默认档为大小写敏感 + 全字匹配，与查找面板三开关同源。Ctrl+K Ctrl+D 跳过当前，Ctrl+Shift+L 一次选中全部相同词（可继续多光标编辑）；另有无默认键位的「选上一处相同词」可自行绑定。
- **中文分词词级移动**：Ctrl+Left/Right（及 Shift 扩选变体）在连续中文段按分词逐词跳转，中英文连排先停在中英交界再进入中文段。分词引擎可切换——浏览器内置分词零下载，jieba 资源经公共 CDN 按需下载（sha256 校验，源可切换 npmmirror 或自定义），失败或离线自动回退内置分词；设置页「编辑器」页的「中文分词」组管理引擎与下载源。
- **输入与同步防护**：中文等 IME 组合期间缓冲上报，避免半截候选写回；外部修改无法安全同步时弹出冲突横幅，本地输入不丢（可复制或放弃）。
- **HTML 注释**：实时预览中 `Ctrl+/` 一键包裹或取消 `<!-- -->` 注释（有选区包裹选区、无选区插入空对，光标落开围栏内侧）；注释在实时预览淡化呈现、阅读模式完全隐藏，代码块内字面 `<!--` 不受影响。快捷键可在设置页改绑。
- **界面语言**：编辑器、设置页、通知与命令标题全部经语言包取词；「常规 → 界面语言」提供自动／简体中文／English 三档，默认跟随 VSCode 显示语言，切换即时生效。

## 格式与结构编辑

- **统一右键菜单（实时预览正文全域接管）**：空行、普通文本、选区、表格行、围栏代码内、图形块上右键均弹出统一菜单（此前这些位置弹的是浏览器原生菜单，反而丢失剪切/复制等基础功能）。菜单分三簇：**链接**（新增双链、新增外部链接、复制标题链接、复制块链接）、**块与格式**（文本格式／段落设置／插入三个级联子菜单，覆盖粗体斜体到标题六级、列表、表格、数学块等格式操作）、**剪贴板**（剪切/复制/粘贴/粘贴纯文本/全选）。粘贴与纯文本入口见下方「富文本粘贴与撤销」。结构敏感区安全降级：表格单元格、围栏代码、图形块上的写操作整簇置灰，块链接与剪贴板仍可用；frontmatter 头区与阅读模式不接管（原生菜单照常）。键盘方向键可导航与进出子菜单，段落设置按光标所在行的当前结构勾选；菜单项右侧显示快捷键提示，图标明暗主题齐备。
- **格式命令**：命令面板可切换粗体、斜体、高亮、删除线、行内代码、标题、列表、引用、代码块与链接，或清除行内格式；可插入公式、双链与分割线。显式选区优先，无选区的行内格式作用于当前词；一次操作一次撤销。
- **快速操作条**：编辑器顶栏的笔形按钮展开流内格式工具条；常用格式、标题层级弹出菜单、插入公式、分割线与建表入口直接作用于原选区，展开状态会记住。阅读模式下格式写操作不可用。
- **列表与引用编辑**：列表/引用行按 Enter 自动延续结构前缀（有序编号 +1 且保留宽度，任务新项重置为未勾选，引用内列表延续完整前缀）；空列表项/空引用行再按 Enter 退出结构还原普通段落。光标紧邻列表标记右侧按 Backspace 分层剥除（嵌套先升一级缩进，顶级一次清除整段标记）。Tab / Shift+Tab 整行缩进——列表行对齐上方最近项的内容列，普通行 2 空格，表格内保持单元格导航优先。引用块左侧有紫色提示竖条（公开变量 `--vsidian-quote-bar-color` 可被 CSS 片段覆写）。
- **表格编辑**：规范表格以网格呈现，点击格内空白进入单元格编辑且网格保持，点击格内链接文字直接跳转目标（Ctrl/Cmd+单击同效）；跨格拖选形成矩形高亮，复制为独立 Markdown 表格（选区首行为表头），格区粘贴按表格矩阵铺开、越界自动扩表。悬停边沿增添行列，点阵把手单击选行列、拖动重排；Tab / Shift+Tab 单元格导航，格内键入 `|` 自动转义；满行/满列/整表选区对应删除行列与整表。列宽按内容比例分配，短列保有随字号缩放的可读下限（大字号下短标签按约三字一行折行，不逐字竖排），编辑期间列宽保持稳定，光标离开整张表格后自动按整表高度做一次收紧优化——只改显示，不写回源文本、不占撤销记录。GFM 对齐标记逐列生效。命令面板另有六个行列命令与中英双语「创建表格」命令。
- **frontmatter 属性表格**：文档头的 YAML frontmatter 在实时预览成型为只读键值两列表格卡片（顶部标题栏 + 右上角「修改」按钮）；点「修改」弹出编辑浮层，键值对增删改、tags 一类字符串数组增删项、底部「添加属性」新增键值对，输入即时生效、每笔操作一次撤销。成型态不暴露源码（光标进入头区自动落到卡片之后）；含嵌套等复杂类型或头区非法时降级为可编辑源码，内容不丢。阅读模式渲染同款只读表格。

## 富文本粘贴与撤销

**普通粘贴保留可表达的格式**：实时预览正文中，`Ctrl+V` 或右键「粘贴」将剪贴板 HTML 转为 Markdown。默认在粘贴前询问，可选择「保留格式」「仅粘贴文本」或「取消」。只有普通文字包装时直接粘贴，不询问。

**纯文本入口明确绕过格式与图片**：`Ctrl+Shift+V` 或右键「粘贴纯文本」优先插入剪贴板原始文字，原始 Markdown 标记逐字保留。缺少文字格式时从 HTML 提取文字；遇图片只插入文字并提示，无文字则保持文档不变。两种粘贴操作都可在快捷键管理中改绑、清空和恢复默认。

**撤销默认分为文本与格式两步**：选中「旧内容」粘贴粗体「新内容」后，撤销顺序为 `**新内容** → 新内容 → 旧内容`，重做按相反顺序恢复。前后输入和连续粘贴保持各自历史。关闭「分步撤销富文本粘贴」后，粘贴整体只占一次撤销；纯文本回退或没有格式差异时也只有一次。

格式范围包括标题、段落、换行、粗体、斜体、删除线、链接、列表、任务列表、引用、行内代码、代码块及普通表格。字体、字号、任意颜色和复杂布局不保留；合并单元格等复杂表格降级为文字，公式只保留可提取文本。HTML 图片仅完整 HTTP(S) 地址保留为外链引用，不下载；相对、本地或临时地址只保留替代文字。独立剪贴板图片继续沿用原有落盘流程。

代码与表格内粘贴优先保持既有规则。多选区的文字分发与转换后的 Markdown 无法保持一致时，保留原纯文本分发并提示转换失败。格式转换失败有文字时回退纯文本，没有可用文字则保持文档不变。

编辑器视口底部的轻提示说明结果：图片纯文本误用为淡黄提示，转换失败为淡红提示，保留格式与第一次撤销格式使用主题普通提示。提示不会抢输入焦点；取消或未实际完成格式编辑时不会提示格式成功。

设置页「编辑」小节提供三个默认开启的开关：「粘贴保留富文本」「分步撤销富文本粘贴」「粘贴前询问」。关闭总开关时子项灰化，已存值保留。询问中勾选「不再提示该信息」并选择保留或仅文本，会记住选择并关闭询问；取消不保存。需要重新询问时在设置页打开对应开关。

## 链接与跳转

- **链接、图片与双链**：链接与 `[[双链]]` 在光标进入时显形源码，单击跳转；双链支持 `[[笔记]]`、`[[路径/笔记]]`、`[[笔记|别名]]`、`[[笔记#标题]]`、`[[笔记#^块id]]` 五形态，`[[#标题]]` / `[[#^块id]]` 本文件锚点可省笔记名，跳转落到标题行或目标块首行，缺失目标与缺失锚点提示；跨文件跳转统一在扩展面板打开（不与源码标签并存），标签的滚动位置与模式被记住，切回恢复离开位置。本地图片经宿主通道装载，`file://`、`javascript:` 等危险 scheme 被拦截；普通链接与图片的目标可含空格。
- **双链输入联想**：实时预览中输入 `[[]]`（或嵌入的 `![[]]`）即弹出文件候选，方向键选择、Enter/Tab 确认，无需输入完整文件名。候选覆盖工作区全部可链接文件——即使没有任何笔记引用过的图片、PDF、音视频与文本文件也能直接搜索插入；不输入查询文字时按修改时间从新到旧列出常用资源，同名文件靠目录区分，按 `↓` 到列表末尾继续加载下一页，文件新建、删除、改名后及时更新。确认生成相对当前文档的路径并自动带文件名作显示文字（Markdown 去掉 `.md` 后缀，其他文件保留全名）；大工作区的文件清单尚在建立时，候选显示已读到的部分并标注「部分结果」。文件目标明确后按 `#` 列出该文档的标题候选（读取当前正文，含未保存修改；重复标题全部展示，选同名标题时轻提示「跳转将定位到第一个」），按 `^` 列出可引用块（含尚无块标识的块，选中时自动补写 `^id`；撤销链接插入时尽量一并撤回自动补写的标识，无法安全撤回时保留并提示），按 `|` 直接进入显示文字编辑（已有别名保留）。Esc 关闭候选后，把光标移回 `[[]` 内的目标部分并输入或删除才重新打开；中文输入法选词期间候选不接管键盘。表格单元格、悬停浮窗、正文嵌入与递归内部编辑均可使用联想（插入路径以实际编辑文档为准，表格内别名竖线写转义 `\|`）；阅读模式只读，不适用。
- **悬停文档预览**：悬停正文双链或本地 Markdown 链接预览目标笔记，不打开文件——阅读模式直接悬停，实时预览按住 Ctrl 悬停（设置项「实时预览中直接悬停显示」可改为免修饰键），反链/出链面板条目始终直接悬停；总开关「悬停预览引用文档」关闭后全域悬停不再弹出。`[[笔记]]` 预览全文、`[[笔记#标题]]` 预览标题章节、`[[笔记#^块id]]` 预览完整块，普通链接与页内锚点同款支持。浮层按目标自身目录解析（相对图片正常显示、内链可点击跳转），顶部标题条含目标名与跳转入口；浮窗内可直接编辑并保存目标笔记——有未保存修改时目标名旁显示圆点，指针移出或失焦不关闭，无修改照常自动关闭。可滚动可复制、移入保活、Esc 关闭；目标或锚点缺失就地提示原因，不弹通知。可绑定操作「预览当前链接」以光标处或键盘聚焦的链接为目标（默认未绑定，键盘打开时 Esc 返回触发处）；悬停不会弹出浮层时可开启「悬停显示跳转目标」查看目标路径（见「悬停显示跳转目标」设置项）。
- **悬停 PDF 与文本文件**：悬停指向本地 PDF 或代码/配置等文本文件的双链与链接同样开浮层预览。PDF 按页绘制：`[[文件.pdf#page=N]]` 指定初始页（普通链接从第一页开始），页码越界如实报错不静默跳回第一页；文内跳转链接在预览内直接翻页，网页链接点击交系统浏览器打开，PDF 脚本/外部程序/附件与非许可协议一律禁用并提示。文本文件以只读视图呈现：语法着色与 VSCode 当前主题同源（无高亮语言为普通前景单色），行号与语言字体跟随编辑器设置，文字可选择复制；锚点 `#line=N` 定位到某行、`#range=B-E` 只显示第 B 到 E 行（起止端可省略一端），锚点写法有误时就地说明具体原因。文件修改（含未保存）自动刷新，删除/不可读就地提示并待恢复重载。
- **图片双链嵌入与悬停**：`![[图片.png]]` 与 `![](图片.png)` 呈现行为一致——加载、失败重试、外部修改刷新与「放大查看」弹窗同款，不新增第二种卡片或交互；悬停指向图片的双链直接在浮层内显示图片本体。`apng`（动图 PNG）一并按图片对待。
- **外链标题摘要卡片与原网页预览**：开启「悬停预览外部链接卡片」后，悬停 HTTP(S) 网页链接经扩展受限抓取显示标题、摘要与域名（默认关闭——关闭时不发起任何网络请求；边界与隐私语义见设置项说明）；「外链预览形态」选「原网页」时在浮层内以沙箱隔离的网页视图尽力显示网页本身（会连接目标站点及其第三方服务，不继承日常浏览器登录态），网站拒绝内嵌、HTTP 页面或抓取失败时自动退回卡片并显示真实原因，浮层内常驻「退回卡片」按钮；域名链接与标题条打开按钮均在系统浏览器打开。抓取尊重 VSCode `http.proxy` 代理配置（`proxySupport=off` 时不使用；未配置时回退 `HTTPS_PROXY`／`HTTP_PROXY` 环境变量）。
- **正文文档嵌入**：`![[笔记]]` 在阅读与实时预览都渲染为引用卡片，支持全文、标题章节与块引用（与双链同一目标语法）；长内容卡内滚动，最大高度可在设置页调整。实时预览中卡片内容可直接就地编辑并保存目标笔记：输入只写目标文档，父文档正文与未保存状态不受牵连；卡片头部显示目标名，有未保存修改时名称旁出现圆点，Ctrl+S（或头部保存入口）只保存目标文档，撤销/重做也只作用于目标（同一目标的多个视图共用一份撤销历史）；嵌入内的格式、表格、右键菜单等操作与图片粘贴归属全部作用于目标文档。光标触及引用源码即显形、原位直接编辑，卡片移到行下方让位，离开后恢复隐藏。关闭有未保存修改的嵌入（头部关闭按钮、Esc 或删除引用行——含在嵌入内删除指向另一嵌入的引用行）时先经保存并关闭／丢弃修改并关闭／取消三项确认，丢弃为文档级（回滚该文件全部视图的未保存修改）；目标被外部程序修改且无法安全写入时暂停编辑，可选对比解决（VSCode 原生对比页）、放弃当前版本或取消；目标被删除时给出提示。关闭父文档标签页后，编辑过且仍有未保存修改的目标自动打开为独立标签（同一目标只开一个，干净目标不打开）。阅读模式嵌入始终只读，不自动创建缺失的目标文件。嵌入不要求独占一行——正文混排、无序/有序/任务列表、引用块与表格单元格内均挂载卡片（表格内别名竖线 `\|` 转义在解析与更名改写中全程保真）。卡片内独占行引用递归展开，默认三层，设置页「嵌入笔记展开层级」1–6 层可调。嵌入引用进入反链/出链面板与更名自动更新。
- **PDF 与文本文件嵌入**：`![[文件.pdf]]` 在正文嵌入内显示 PDF 全文——按页滚动浏览（只保留可见页附近的页面，页数多也不占内存），页码行固定在浏览区底部并随滚动更新，翻页操作与滚动互通（默认未绑定，可在快捷键设置自配）；缩放支持放大/缩小/适合宽度三操作（默认未绑定），内存占用受上限约束；文字可选择复制（中英文均可，扫描页无文字层不虚构）；同一 PDF 多处引用共享一份数据、各自独立滚动。`![[文件.ts]]` 等文本嵌入以只读文本视图呈现（着色/行号/字体与悬停浮层同款，锚点同 `#line`/`#range`），长文只渲染可见区段。两者在混排、列表、引用块、表格单元格与递归嵌入内均可用。
- **复制块链接**：右键任意块（段落、列表、引用、表格、代码块）复制 `[[笔记名#^块id]]`，标题行还可复制 `[[笔记名#标题]]`；目标块没有块 id 时自动在块尾后空一行写入独立行 `^id`（6 位随机查重 id，一笔可撤销编辑）再复制。手写的独立行或行尾块 id 两形态都识别复用；块 id 标记在实时预览淡化、阅读模式隐藏。快捷键 `Ctrl+Shift+C` 对光标所在块执行同款复制。
- **跳转目标高亮**：锚点跳转后目标标题/段落整体覆盖半透黄提示，任意操作（点击、滚动、切页）后消失；颜色经 `--vsidian-anchor-flash-background` 变量暴露，可在 CSS 片段中覆盖，双视图同款。
- **图片粘贴**：实时预览中 `Ctrl+V` 粘贴剪贴板图片自动落盘并在光标处插入引用——截图生成 `Pasted image 时间戳.png`（Obsidian 默认风格），复制文件沿用原名（Windows 非法字符清洗、重名 `-1` 递增）；浏览器复制的 URL 编码文件名先解码再清洗。存放位置与子路径可配置（同目录 / 相对工作区根 / 相对当前文件），绝对路径与 `..` 越界被拒并通知，目录不存在自动创建；插入一步可撤销（落盘文件保留）。阅读模式与设置页输入不接管，IME 组合期间放行默认粘贴。
- **图片弹窗查看与防误触**：Markdown 图片悬停（加载成功后）右上角浮现按钮组——实时预览为「编辑源码」与「放大查看」，阅读模式仅「放大查看」；点击图片本体不再跳转源码（错误占位仍可点击重试）。「放大查看」打开全屏弹窗：滚轮/键盘缩放、拖拽平移、快捷键 0 重置、Esc 或点击空白关闭；工具条「刷新」按当前文档重新定位该图并重载（图片被移动后仍能追到，被删除则维持当前画面），「导出」把原图以原格式另存副本（http(s) 外链图禁用导出）。链接内嵌图片与表格网格内图片不接按钮组，点击行为不变。
- **图片自动刷新与删除态**：磁盘上的图片被覆盖保存或删除时，已打开文档中的图片约半秒内自动失效重载（无需关闭重开）；删除的图片撤下旧图并显示「找不到」错误态（点击可重试），远程 SSH 断连或权限错误显示「暂不可访问」（连接恢复后自动恢复显示）。机制为宿主文件监视器即时失效加已挂载图片约 30 秒合并核验兜底；HTTP(S) 外链不纳入自动刷新，手动入口见上文「刷新嵌入资源」。
- **反链面板与引用索引**：右侧栏「反向链接」面板显示当前笔记被哪些文档引用（与大纲、出链面板互斥切换，双模式可用）——按来源文件分组，组头显示来源名与计数、可折叠，组内每条引用是一张上下文卡片，命中的链接原文黄底高亮；工具栏提供排序（文件名、编辑时间、创建时间各正逆共六项）、搜索（匹配来源名与片段文本）、折叠全部/全部展开与更多上下文（引用行 ±2 行）切换；点击条目打开来源文档并定位到引用处。背后是持久化的工作区引用索引：扫描各工作区根 Markdown 中的双链、链接、图片与引用定义四类引用（代码块与行内代码内的字面量不计），索引缓存在扩展私有工作区存储中按根分区，重启即恢复、不写笔记目录（Remote SSH 存宿主侧）；未保存编辑约半秒后反映到面板，文件保存与外部修改自动重扫；断链与未命中引用保留显示。多工作区根各自独立（跨根引用不解析，嵌套根按最具体根归属）。设置页「索引维护」分页提供排除模式（默认 `**/.git/**` 与 `**/node_modules/**`）、清理缓存与完整重建；「显示或隐藏反链面板」已登记为可绑定操作（默认未绑定）。
- **出链面板**：右侧栏「当前笔记中的链接」面板平铺当前笔记的全部出链（目标名 + 路径两行；双链、链接、图片与引用定义四类），按命中优先与目标名稳定排序；点击条目打开目标文档并按该链接的实际锚点定位（`[[笔记#标题]]` 定位到该标题，无锚点定位到文档顶），图片附件经系统预览器打开；断链条目整体弱化且不可点，https 等外部链接不进面板；未保存编辑约半秒即时反映。「显示或隐藏出链面板」可绑定（默认未绑定）。
- **更名/移动自动更新引用**：在 VSCode 内重命名或移动 Markdown 文件与图片等附件（含整个文件夹与一次多文件）时，指向它们的双链、链接、图片与引用定义按新位置自动重算相对路径——别名、标题/块锚点、URL 编码与省略扩展名的语义保留；文件夹内互链相对关系不变的不改写，移动到不同深度后指向外部的出链重算。改写随更名一并应用（一步撤销整体恢复）；未保存内容受保护，区间对不上时跳过该文档并明确告知；跨工作区根移动不生成跨根相对引用；索引未就绪时明确提示本次未更新。外部工具（非 VSCode）改名只刷新索引、不改写链接。
- **搜索定位恢复**：工作区搜索点击结果由 Vsidian 打开笔记后，命令「定位到搜索选中结果」（默认未绑定，可在快捷键设置自配）把光标定位到搜索选中条目的匹配处并高亮提示——外部入口打开不自动定位是 VSCode 公开 API 缺口（跟踪 vscode#289785，规格 [specs/search-reveal.md](specs/search-reveal.md)）。光标落在匹配词首（VSCode 内部命令不提供匹配终点，以行级高亮补偿）；条目行文本与当前文档不吻合时安全放弃并通知；定位会短暂占用文本剪贴板并恢复，非文本剪贴板（图片）内容会丢失。

## 代码块与图表

- **代码块卡片**：围栏代码块在光标离开时收起为卡片——语言头部横带（彩色徽标 + 显示名）、卡内行号、复制与折叠按钮。头部按钮区为 [折行（阅读视图）] [复制] [折叠]，折叠钮固定最右，可连续开合；复制/折行按钮进入卡片即显、离开即隐，整条头部横带可点击折叠。围栏符号与代码文本严格同列对齐，卡内行号左缘留 8px 边距。设置页提供卡片、卡内行号、复制按钮、语法高亮四个开关。阅读视图头部有折行开关，点击联动全文代码块（含大围栏分片），关闭后代码区横向滚动、行号列与头部钉住。
- **语法高亮**：内置 Lezer + legacy-modes 引擎覆盖常用语言与纯文本（支持别名），配色按用户 VSCode 主题导出逐词取色——明、暗、暗高对比三档自动跟随，函数与属性调用为暖黄；实时预览与阅读观感一致，用户 CSS 片段仍可按 `tok-*` 类覆写。超过 4096 行的围栏跳过着色回退纯文本。
- **公式渲染**：行内 `$…$` 与块级 `$$…$$` 的 LaTeX 公式双视图渲染（KaTeX 本地打包，无 CDN）；光标进入公式显形源码直接编辑，解析失败稳定降级为可读原文；普通美元、转义与代码区不误判。
- **Mermaid 图表**：语言标记为 `mermaid` 的围栏代码块渲染为图（本地按需加载，无 CDN）；光标进入围栏显形源码，语法错误降级为错误提示与可读源码，不影响后续内容；明暗主题自动联动，图内链接不执行跳转。
- **图形化代码块交互**：渲染图形右上角悬停显示按钮组——「编辑源码」（仅实时预览）与「弹窗预览」（双视图全屏浮层：滚轮/键盘缩放、拖拽平移、一键回到整图、按当前源码刷新，缩放按矢量重排文字不糊）；点击图形本体不进入编辑。图表可导出 SVG 与 PNG（宿主另存为对话框；环境不支持光栅化时自动降级为仅 SVG）。按钮组、弹窗与导出由渲染器注册表统一驱动，新增同类图表语言登记即继承全部交互。

## 大纲面板

- **右侧栏与大纲**：右侧栏按钮一键展开收起（状态跨面板记忆），左缘拖拽调宽（双击恢复默认，方向键微调）。「大纲」面板：标题层级实时同步（ATX/Setext 语义，代码围栏与 frontmatter 伪标题不计入）；点击条目跳转正文对应标题（双模式），常驻高亮指示当前章节；六档「结绳」滑块统一展开深度，条目箭头手动折叠，滚动自动展开当前路径；工具条提供跳转末尾、重置与标题搜索（片段级高亮）；标题行内样式与主题层级配色同源透传；右键菜单提供结构命令、复制、调整层级、重命名（保留行内标记）与整段删除；拖拽标题按「控制域」整段重排，控制域外内容零误伤，一次撤销完整回滚。右键子菜单右缘放不下自动翻到左侧展开。

## 外观与定制

- **CSS 片段**：在设置页「外观」分页选择用户级目录后，第一层 `.css` 文件作为跨项目共享的独立片段——新片段默认关闭，按文件名顺序加载（同层叠优先级后加载者覆盖），逐项启停、手动重新加载、保存自动生效。入口片段经 `@import` 引用子目录 CSS（嵌套与 media/supports/layer 条件语义），相对图片/字体按各自 CSS 文件目录解析；`@import url(https://…)` 远程样式表与 `@font-face` 在线字体（如 Google Fonts）直接经网络加载（仅放行 HTTPS），字体晚到自动重测高度并保持滚动位置。循环导入有界；越出片段目录的引用（`../` 逃逸、根相对、`file:`）与符号链接逃逸被拒绝并提示，修复后自动恢复。命令面板「暂停全部/恢复」全局冻结与还原（保留逐项开关，重启保持）；目录与启用状态按本地 / SSH 环境分别记录。片段只作用于实时预览与阅读视图，不影响输入与文档内容。
- **样式参考与公开样式契约**：全部公开样式入口（正文域与界面域）登记支持等级与生命周期，设置页「外观」分页的「样式参考」页签离线查阅——按小类分栏、分页浏览、等级过滤与跨类目搜索。标记「直接兼容」的 Obsidian 原名选择器与 CSS 变量（如 `.cm-strong`、`.markdown-preview-view p`、`--h1-color`）经内置别名桥实际生效，vsidian 原名保持既有语义且优先。契约 JSON 可经「导出 JSON」按钮或命令面板另存，供 AI 助手与外部工具直接消费。
- **可读行宽**：设置页「可读行宽」滑块（0–1600px 步进 20，0 = 铺满为默认档）同时约束实时预览与阅读模式的正文列宽；可用宽度不足时自动收缩避让右侧大纲栏，正文列水平居中、随侧栏开合实时跟随，Live 行号列随正文列一起居中。CSS 片段可分别覆盖两模式（Obsidian 别名 `--file-line-width` 同接两变量）。
- **快捷键管理**：设置页「快捷键」分页集中管理全部可绑定操作；按键录制添加绑定（支持两段键），逐条删除、一键清空、单项或全部恢复默认，清空选择持久保留。插件内部冲突按「键位相同且生效范围重叠」判定；写操作快捷键仅在 Live 编辑正文时拦截。
- **独立设置页**：设置在扩展自带设置页管理（不占用 VSCode 统一设置中心），左侧分类导航与全局搜索定位；支持明暗主题、窄窗口与键盘操作。用户级保存、重开回显、变更即时生效。

## 设置项一览

- **界面语言**（默认自动）：跟随 VSCode 显示语言，可固定简体中文或 English。
- **显示行号**（默认开启）：实时预览左侧行号栏显示源文件行号，表格段显示段首行号；阅读模式始终无行号。
- **代码块卡片 / 卡内行号 / 复制按钮 / 语法高亮**（默认开启）：卡片整体外观及三项子开关，语法高亮独立于卡片。
- **粘贴图片插入**（默认开启）与**图片存放位置 / 图片存放子路径**：见上文「图片粘贴」。
- **粘贴保留富文本 / 分步撤销富文本粘贴 / 粘贴前询问**（默认开启）：见上文「富文本粘贴与撤销」。关闭富文本总开关不关闭独立图片粘贴。
- **可读行宽**（默认 0 = 铺满）：见上文「可读行宽」。
- **多光标**（默认开启）：多光标交互总开关，关闭后回到单光标行为。
- **悬停预览引用文档**（默认开启）：悬停预览浮层的总开关。关闭后全部触发入口——悬停路径（阅读正文、实时预览、反链/出链面板与浮层内子引用）与「预览当前链接」键盘命令（执行但静默）——均不再弹出浮层；正文嵌入卡片不受影响。设置页归「引用视图」组。
- **实时预览中直接悬停显示**（默认关闭）：开启后实时预览无需按 Ctrl，直接悬停链接即预览；悬停中补按 Ctrl 亦可触发。
- **悬停显示跳转目标**（默认开启）：悬停在引用上且本次悬停不会弹出预览浮层时（实时预览中未按住 Ctrl，或「悬停预览引用文档」已关闭），短暂停留后显示目标位置的小浮标——内容为目标相对其所属根的完整路径，锚点按源码形态附加（`#标题` / `#^块id`）；覆盖实时预览链接、阅读正文与反链/出链面板，外部链接与嵌入卡片不提示；补按 Ctrl 弹出浮层时立即消失，解析失败不出提示。独立于总开关，关闭总开关后仍可用。
- **悬停预览外部链接卡片**（默认关闭）：开启后悬停 HTTP(S) 网页链接显示标题、摘要与域名卡片——由扩展发起受限网络抓取（仅 HTML 元信息，限制超时、响应大小、重定向与并发，拒绝内网地址与带凭据的 URL；不发送笔记内容、路径、Cookie 或身份凭据），提取过程不执行网页脚本、不加载图片等子资源；失败显示真实原因并保留浏览器打开入口；同一链接的请求合并、浮层关闭即取消，结果仅内存短存（不记录浏览历史）；远程开发（Remote SSH）下抓取发生在远端。关闭时不发起任何网络请求。抓取尊重 VSCode `http.proxy` 代理配置（`proxySupport=off` 时不使用；未配置时回退 `HTTPS_PROXY`／`HTTP_PROXY` 环境变量），代理环境下与系统浏览器走同一网络路径。设置页归「引用视图」组。
- **外链预览形态**（默认卡片）：悬停外部链接的呈现形态——「卡片」显示标题摘要域名；「原网页」在浮层内以沙箱隔离的网页视图尽力显示网页本身（网页在编辑器本地加载，会连接目标站点及其第三方服务，不继承日常浏览器登录态；两条网络路径的差异见「悬停预览外部链接卡片」说明）。网站拒绝内嵌（X-Frame-Options / frame-ancestors）、HTTP 页面无法安全内嵌或抓取失败时自动退回卡片并显示真实原因；浮层内常驻「退回卡片」按钮与浏览器打开入口，网页是否完整显示无法确认（如实说明，不编造加载状态）；退回不修改本设置。开关关闭时本项灰化（值保留）。
- **嵌入笔记展开层级**（默认 3，范围 1–6）：父文档为第 0 层；1 只显示直接嵌入，3 显示至第三层。设置保存后已打开卡片即时收缩或继续展开。递归覆盖全部容器形态——独占行、段落混排、列表／引用容器、表格单元格内的卡片与悬停预览浮层内的嵌入均沿同一层级与预算展开（悬停浮窗始终一次一个）。设置页归「引用视图」组。
- **嵌入内容最大高度**（默认 480px）：正文嵌入卡片长内容的卡内滚动高度，即时生效。设置页归「引用视图」组。
- **中文分词**：分词引擎（浏览器内置 / jieba）与下载源设置，见上文「中文分词词级移动」。
- **CSS 片段**：目录选择与逐片段启停，见上文「CSS 片段」。

## 开发与测试

```bash
npm install                     # 安装锁定依赖（版本全部精确锁定）
npm run compile                 # esbuild 双产物 + tsc 类型检查
npm run watch                   # esbuild watch
npm run test:unit               # vitest 与启动器契约测试（无 VSCode 宿主依赖）
npm run test:browser            # Playwright 原生键盘/IME 表格光标回归（首次需 npx playwright install chromium）
npm run test:integration        # 1.82.3 真宿主集成测试（#255 起矩阵钉在承诺下界）（可设 VSIDIAN_ITEST_SHARDS=4 分片）
node test/integration/runInstalled.mjs  # VSIX 安装态回归（先 package 出 VSIX）
node test/perf/runPerf.mjs      # 性能档位测量（报告写 docs/perf/data/）
npm run release:check           # 打包 + 发布前包内容与体积检查
npm run release                 # 以上 + 创建 GitHub Release 并上传 VSIX（需 v<version> 标签）
```

Windows 上两条集成测试路径默认将真实 VSCode 宿主启动在同一交互会话的独立桌面：测试窗口不遮挡当前桌面，宿主非零退出会使启动器失败，启动器会记录宿主 PID、独立桌面可见窗口数并每半秒采样前台 PID。独立桌面创建失败时测试直接失败，不会悄悄改为当前桌面启动。启动器将本次宿主及其子进程放入单独的 Job Object，宿主退出、启动器失败或中断时关闭该组；测试宿主默认限时 15 分钟，超时以非零退出，fixture 工作区由启动器清理。在不支持交互式桌面的环境（例如无人登录的 CI 服务）中，可在专用 Windows 会话内设置 `VSIDIAN_TEST_HOST_MODE=foreground` 显式选择前台模式。

浏览器回归默认三并发运行（`-- --workers=1` 回退串行，`-- --suite=<名称>` 定向运行）；每轮写入独立运行报告（`out/test/browser-runs/`）。集成测试逐片报告写入 `.vscode-test/` 下的运行日志。

发布流程、VSIX 体积红线与包内容检查的约定见仓库内技能 [.agents/skills/release/SKILL.md](https://github.com/ONEGAYI/vsidian/blob/main/.agents/skills/release/SKILL.md)；公开样式契约的修改约束见 [.agents/skills/style-contract/SKILL.md](https://github.com/ONEGAYI/vsidian/blob/main/.agents/skills/style-contract/SKILL.md)。项目定位与功能边界见 [CONTEXT.md](https://github.com/ONEGAYI/vsidian/blob/main/CONTEXT.md)，MVP 规格见 [docs/specs/](https://github.com/ONEGAYI/vsidian/blob/main/docs/specs/)，架构决策见 [docs/adr/](https://github.com/ONEGAYI/vsidian/blob/main/docs/adr/)。
