## 目标与范围

- 在宿主运行生命周期提供可序列化规则登记、普通拒绝与释放句柄，来源身份由平台注入。
- 共享基础规则定义，广播到已开/新开页面，在生产 htmlToMarkdown 遍历中消费标签/属性匹配、取值与具备类型的模板槽。
- 按优先级、组件 ID、规则 ID 确定性执行；首条成功接管，单规则失败继续，最终回内置转换；不复活内置忽略元素。
- 接回原富文本询问、plain 等值守卫与宿主分步撤销，不复制粘贴或历史管线。

## 验收标准

- [ ] TDD 先出现命中、不命中、缺属性、非法 URL、冲突顺序、失败回退与停用回收的失败用例，再实现通过。
- [ ] 浏览器双载荷样本中来源特化链接可恢复，旁边 strong/code/pre 保持；纯文本操作不经过规则。
- [ ] 首次撤销只撤格式、第二次撤文字的宿主历史不变，转换结果等于 plain 时只有一次。
- [ ] 停用/故障/代次结束撤回规则；新页面拿到当前快照，迟到快照不复活旧代次。
- [ ] 未实现的高级节点明确拒绝，不静默当成正文；本票不声称已完成 T02。
- [ ] API 目录、参考、编译期消费者、测试消费夹具、覆盖映射及兼容门禁同步完成。

- 可执行行为遵循 TDD，优先使用生产控制器/公开 SDK/真宿主的既有测试接缝。
