## 目标与范围

- 在 T01 同一登记与消费入口扩展正则匹配/捕获组、all/any/not 条件及子节点嵌套转换。
- 共享类型与校验解释同源，缺失必需取值、非法正则和未知表达式明确拒绝；嵌套只能向子节点下降。
- 集中定义规则数、表达式深度和求值步预算，保持 URL 槽校验、字面正文与已转换子片段的转义边界。
- 用长输入证据说明正则实现的实际预算；不能将事后计时称为中断同步 RegExp。

## 验收标准

- [ ] TDD 覆盖捕获组、条件组合、缺值、嵌套标记/表格、非法表达式及全部预算边界。
- [ ] 多组件冲突和规则求值失败保持确定性回退，不导致全组件故障。
- [ ] 真实浏览器回放嵌套 HTML，验证既有格式与分步撤销；不存在动态 eval/Function/DOM 回调入口。
- [ ] 长输入与深嵌套证据落报告，所选正则实现不伪称可中断超时。
- [ ] T01 的注册/停用/代次/URL/纯文本与历史回归保持通过。
- [ ] 高级声明与消费样例、API 文档和门禁同步；#530 的全部故事有实现与验证映射。

## 不包含

不开放任意脚本、向父节点递归、任意 DOM 遍历或新的用户规则编辑页面。

## 验证与维护纪律

- 可执行行为遵循 TDD，优先使用生产控制器/公开 SDK/真宿主的既有测试接缝。
- 呈现变更按 ui-patterns/style-contract，至少一条断言落绘制层；涉及输入/光标必跑 browser。
- API 变更同步 addonApiCatalog、生成参考、编译期消费者和覆盖映射；若声明/语义冻结命中，兼容基线显式重锚定须同 PR 独立说明。候选台账不写虚构发行日期。
- 长命令首次即保存日志、退出码或工具报告，复核读已有报告。文档/人工验收与自动化结果分开，不关闭父票代替整体验收。
