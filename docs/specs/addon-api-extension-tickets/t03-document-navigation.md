## 目标与范围

- 在编辑器页 views 能力中提供结构化导航请求，由 SDK 注入来源组件与代次，明确来源实例。
- 宿主复用 linkTarget/vaultLink 目标解析；Markdown 用 Vsidian 打开或重显，可读文本用原生编辑器。
- 行号、标题、块 ID 互斥；来源为嵌入 B 时以 B 为基准，CRLF 转 LF，折叠/阅读定位沿既有链路。
- 复用面板就绪、view.locate 与确认机制，提供内部定位执行体供 #534 消费；不让内核反向调用组件 SDK。

## 验收标准

- [ ] TDD 先覆盖已开/未开、来源 B、md/文本、标题/块/行、无工作区、越根、not-found 与非法组合。
- [ ] 请求区分打开与定位结果，首次行号越界不默默钳到末行，未送达不报成功。
- [ ] 目标在异步等待中变短、来源释放、页面重载与代次结束有明确终态，旧偏移不抢回定位。
- [ ] 浏览器与真宿主证明 Vsidian/原生编辑器真实落点、CRLF、阅读态及折叠隐藏区展开。
- [ ] API 消费者、开发指南与引用视图分工、目录、参考、覆盖映射及兼容门禁同步。
