## 目标与范围

- 编辑器页面提供只读浮窗请求与本次请求关闭句柄，宿主复用 hoverDocAccess/refContent 来源、准入、读取与租约。
- 在有效触发文字/控件旁按现有几何摆放；缺省不抢焦点，键盘路径复用进入/归还焦点。
- 单页单浮窗，新请求替换旧请求；旧句柄和迟到回包不能误关/重开后来的浮窗。
- 所创建实例及递归内容保持只读，复用错误视图、刷新与释放链，给 T06 保留内部复用接缝。

## 验收标准

- [ ] TDD 先覆盖来源 B、合法/非法锚点、预算、请求替换、旧句柄、迟到回包与代次释放。
- [ ] 有效触发位置下的目标失败显示真实错误；无效来源/位置普通拒绝，不创建无锚点空浮窗。
- [ ] 浏览器证明触发位置旁的实际浮窗、单实例仲裁、Esc、键盘焦点与来源消失关闭。
- [ ] Live 父视图与历史模式记忆不能把本 API 引用切为可写；递归内容与保存/编辑入口保持禁写。
- [ ] 真宿主覆盖目标更新/失效、组件停用、页面关闭和租约回收；绘制层断言及历史样式命中证据齐备。
- [ ] API 目录、参考、消费者、开发指南样例、覆盖映射与门禁同步。

## 不包含

不实现组件容器嵌入，不新增多浮窗/固定/拖动，不开放自定义浮窗 DOM、目标写入或外链网络能力。

## 验证与维护纪律

- 可执行行为遵循 TDD，优先使用生产控制器/公开 SDK/真宿主的既有测试接缝。
- 呈现变更按 ui-patterns/style-contract，至少一条断言落绘制层；涉及输入/光标必跑 browser。
- API 变更同步 addonApiCatalog、生成参考、编译期消费者和覆盖映射；若声明/语义冻结命中，兼容基线显式重锚定须同 PR 独立说明。候选台账不写虚构发行日期。
- 长命令首次即保存日志、退出码或工具报告，复核读已有报告。文档/人工验收与自动化结果分开，不关闭父票代替整体验收。
