父票：[规格/总览 #532](https://github.com/ONEGAYI/vsidian/issues/532)。本票切片编号：T06。

Blocked by: [#544](https://github.com/ONEGAYI/vsidian/issues/544)

用户故事：R-U08–R-U11，并复验 R-U03/R-U04/R-U07。

## 目标与范围

- 在组件自有面板或渲染根（及其后代）挂载内核只读引用子根，不接管正文/其他组件容器。
- 复用 T05 的来源、目标访问、只读能力、预算与释放机制，不复制独立读取通道。
- 多处同目标可共享解析缓存，但实例、滚动、属性状态与 DOM 独立；外层卸载/脱树/停用整组释放。
- 本请求零正文写入、零撤销项，插入 ![[...]] 仍由其他既有编辑 API 显式执行。

## 验收标准

- [ ] TDD 先覆盖容器归属、重复挂载、同目标双实例、父根释放、脱树、停用与迟到结果。
- [ ] 浏览器真实组件面板中嵌入可见，双实例滚动不串用，正文文本与宿主撤销历史不变化。
- [ ] 引用树保持只读，模式继承或内部控件不能建立目标写会话。
- [ ] 真宿主目标更新/删除/恢复沿既有分态，释放后无残留订阅或迟到重挂载。
- [ ] T05 浮窗与错误/预算回归通过，绘制层与历史样式兼容证据齐备。
- [ ] API 声明、目录、参考、消费样例、开发指南与覆盖映射同步。

## 不包含

不自动修改 Markdown 正文、不新增通用内核容器接管权限、不提供目标写入或另一套引用状态源。

## 验证与维护纪律

- 可执行行为遵循 TDD，优先使用生产控制器/公开 SDK/真宿主的既有测试接缝。
- 呈现变更按 ui-patterns/style-contract，至少一条断言落绘制层；涉及输入/光标必跑 browser。
- API 变更同步 addonApiCatalog、生成参考、编译期消费者和覆盖映射；若声明/语义冻结命中，兼容基线显式重锚定须同 PR 独立说明。候选台账不写虚构发行日期。
- 长命令首次即保存日志、退出码或工具报告，复核读已有报告。文档/人工验收与自动化结果分开，不关闭父票代替整体验收。
