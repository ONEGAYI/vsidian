## 目标与范围

- 宿主登记带稳定身份、多语言名称和本组件提供者关联的主题目录，不依赖先开编辑器页面。
- 外观第四页签原位更名“主题”，组件主题集中单选，profile 级唯一首选驱动设置回显与实际渲染。
- 新主题只增加候选不自动切换；主题关联提供者不走普通自动接管，其他普通渲染器保持旧规则。
- 编辑器页提供 VSCode 实际生效主题快照与订阅，四态、缓存先更新和释放正确，已挂载文档图形重画。
- 保留内核 codex 路径供过渡，不在此票提前执行 #535 的旧值迁移或删除。

## 验收标准

- [ ] TDD 覆盖目录登记/回收、身份与关联校验、唯一首选、安装不切换、不可用回落/恢复、普通提供者不受影响。
- [ ] 明暗当前值与通知覆盖四态、VSCode 固定暗色而系统变亮、热更新、重复值与释放；不开放任意配置读取。
- [ ] 真实设置页验证页签名称、单选、同名来源、语言切换、搜索定位、持久化与重开回显。
- [ ] 无编辑器时仍能列主题；真宿主多文档与组件停用生效，文档图形配色有绘制层断言。
- [ ] 图表弹窗快照、default、旧 codex 与非主题渲染规则不回归，UI/样式技能证据完整。
- [ ] API 目录、参考、消费者、覆盖映射、开发指南及兼容门禁同步；向 bridge#3 提供可消费的接口样例。

## 不包含

不移除内核 Codex/ELK，不自动安装或发布组件，不新建 CSS 主题系统或第二主题入口。

## 验证与维护纪律

- 可执行行为遵循 TDD，优先使用生产控制器/公开 SDK/真宿主的既有测试接缝。
- 呈现变更按 ui-patterns/style-contract，至少一条断言落绘制层；涉及输入/光标必跑 browser。
- API 变更同步 addonApiCatalog、生成参考、编译期消费者和覆盖映射；若声明/语义冻结命中，兼容基线显式重锚定须同 PR 独立说明。候选台账不写虚构发行日期。
- 长命令首次即保存日志、退出码或工具报告，复核读已有报告。文档/人工验收与自动化结果分开，不关闭父票代替整体验收。
