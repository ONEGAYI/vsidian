# 附加组件文档导航与普通链接行号规格（#531 / #534）

## 1. 状态与范围

2026-10-15 用户确认产品决策与拆票。#531 改为规格/父票；T03 实施组件文档打开与定位，既有 #534 作为 T04 实施普通链接尾部行号。依赖与票号见[批次索引](batch-2026-10-addon-api-extensions.md)。功能尚未实施。

两种入口共用目标解析与行定位语义：组件请求是结构化导航，普通 Markdown 链接是源码语法入口；不通过组件 API 间接模拟点击，也不把来源特化协议放入内核。

## 2. 已定产品规则

- Markdown 目标用 Vsidian 打开或重显，保留目标既有三态记忆；可读文本目标用 VSCode 原生文本编辑器打开。
- 相对路径以明确来源视图对应的文档为基准。A 中的 B 引用内部触发时以 B 为基准，不能误用外层 A。
- 组件导航由宿主解析、打开与定位，页面只提交请求；不新增任意文件读取面。
- 普通链接的 `:正整数` 是行号后缀，仅普通 Markdown 链接（含宽松链接）支持。双链不增加冒号行号，既有 `#line=` / `#range=` 范围保持。
- `note.md:20#第二章` 为非法混合定位，直接失败；浮窗显示错误，点击用 toast 报错，不选择其中一个定位。

## 4. 组件导航请求

### 4.1 载荷与归属

在既有 views 能力下增加异步文档打开请求，并由 SDK 注入组件身份与代次。请求包含来源实例、目标路径和可选定位描述。来源实例必须来自本页面有效视图句柄；不按宿主当前活动标签猜测来源，也不接受作者伪造来源文档 URI。

定位描述是互斥选择：无定位、1-based 行号、标题、块 ID。禁止同时提交行号与其他锚点；不向 Markdown 文件引入文本附件专用 `#line=` / `#range=` 片段语法。返回结果须区分是否打开和是否定位，不能在目标已打开但锚点失败时谎称完整成功。

本面仅编辑器页可请求，阅读态也能导航；设置页不提供编辑器 views。宿主仍是实际执行方，未来独立宿主调用不是本批范围。

### 4.2 解析、执行与完成

来源身份与存在性经现有视图桥确认；路径使用 linkTarget / vaultLink 的目录、所属根、扩展名候选、大小写及工作区限制。无工作区的跨文档组件请求明确拒绝；本文件锚点沿既有本文件语义处理。不能因新 API 放开绝对路径或重建 basename 全根搜索。

Markdown 经 `vscode.openWith` 打开或重显，再通过面板就绪与 `view.locate`/确认重送管线定位；原生文本经 showTextDocument 与 revealRange。行号转 LF 行首坐标，CRLF 转换仍由 NewlineCoordinator 负责；目标在等待中变化时以执行时的权威文本重新校验行号，不发送旧偏移。

复用现有定位到阅读块、展开标题折叠隐藏区和失效面板守卫。组件请求必须具有有界终态；面板关闭、来源失效、代次结束或定位未送达时返回失败，不把仅调用 openWith 当作已定位成功。

### 4.3 失败语义

| 结果类别 | 要求 |
| --- | --- |
| invalid-request | 非法形状、非正整数行号或冲突定位；不执行打开 |
| no-workspace / escape / not-found | 对齐现有解析口径，不新增 fs 权限 |
| view-disposed | 来源或请求代次失效，拒收迟到结果 |
| anchor-not-found / out-of-bounds | 目标存在但定位失败，报告打开状态及原因，不自动钳到末行 |
| delivery-failed / error | 定位未送达或宿主执行失败，与目标不存在分开 |

最终错误码名称在共享类型中统一；普通拒绝不触发组件故障。API 不替组件弹重复通知，调用方可按结果呈现。

## 5. 普通链接尾部行号（#534）

### 5.1 解析边界

外链协议与 Windows 盘符按现有分类保留。对本地路径部分提取尾部十进制正整数后缀，必须早于 Windows ADS/怪异 basename 拦截；数字 0、负数及非数字不能成为合法行号，不进行绝对值、截断或宽容修正。

只有合法路径直接接 `#` 才是标题或块锚点。路径已含冒号行号时再带非空 fragment，整次定位语法非法，不丢弃 fragment，也不误作标题。查询段与 percent-decode 复用现有拆分入口；行号不从 query 或 fragment 中提取。

不得把任何冒号都当作行号：`a:b.md` 等非行号形态保持原有 scheme、Windows 奇异名与 POSIX 路径分类；带扩展名后的非法行号形态如 `note.md:abc` 明确拒绝。外部 `https://...:443/...` 不受影响。无扩展名目标沿既有候选规则，不能借尾部数字放行原来被禁止的协议。

### 5.2 目标分派与越界

非 Markdown 可读文本把行号转换为同源 TextAnchorSpec，使用 parseTextAnchorSpec / resolveTextNav 判定后走原生定位；Markdown 行号直接解析到行首 LF 偏移，复用 T03 的宿主定位执行体，不把数字交给标题定位器。

首次越界严格失败，不能默默钳到末行。点击沿现有“目标可打开但定位失败则提示”的导航原则，使用 i18n toast 说明；引用浮窗显示失败分态。已经打开的引用因外部编辑变短而刷新，仍沿现有 clamp 规则收缩有效窗口。语法本身非法（如混合定位）不执行打开。
