# 附加组件只读引用视图请求规格（#532）

## 1. 状态与目标

2026-10-15 用户确认同时开放浮窗与嵌入，并接受 Q9/Q10 的容器与生命周期规则。#532 为规格/父票；T05 已实施引用浮窗，T06 复用同一目标访问链路实施组件容器嵌入（尚未实施）。票号与依赖见[批次索引](batch-2026-10-addon-api-extensions.md)。人工验收未结。

目标是让组件请求内核引用内容视图，不需要重新实现 Markdown、代码文本或附件预览，也不因请求呈现而取得写目标文档的能力。

## 2. 核心边界

- 页面 SDK 提交请求与承载 UI，宿主解析来源和目标、执行有界读取。源文档、目标身份、订阅租约、预算和刷新复用 hoverDocAccess / refContent 框架。
- 本面打开的实例及其递归引用保持只读，不因父视图为 Live、历史模式记忆或内部切换入口变成可写实例。已有独立 views 编辑权限不由本面扩大或撤销。
- 嵌入只挂载在组件自己的面板或渲染区域中；本请求不向 Markdown 正文插入 `![[...]]`，也不接管平台正文根或其他组件容器。
- 浮窗内容仍由内核构造，不提供向浮窗内部注入自定义 DOM 的接口；既有鼠标悬停触发规则不被组件请求面改写。

## 3. 用户故事

1. **R-U01**：作为组件用户，我希望在触发文字或按钮旁打开目标引用浮窗，以便查看上下文而不离开当前文档。
2. **R-U02**：作为引用内部的用户，我希望目标路径以直接来源文档解析，以便 B 中的引用不误用父文档 A 的目录。
3. **R-U03**：作为用户，我希望行号与范围采用现有规则和大小限制，以便大文件或非法锚点明确失败。
4. **R-U04**：作为用户，我希望组件打开的引用始终只读，以便查看不会误改目标文档。
5. **R-U05**：作为用户，我希望新请求替换旧浮窗，以便同一页面不会堆积多个浮层。
6. **R-U06**：作为用户，我希望目标或语法错误显示在浮窗中，以便知道无法预览的原因。
7. **R-U07**：作为组件作者，我希望来源关闭、组件停用或请求被替换后自动释放资源，以便旧异步结果不会重开浮窗。
8. **R-U08**：作为组件作者，我希望在自己的面板或渲染内容中嵌入内核引用视图，以便复用成熟的内容展示。
9. **R-U09**：作为用户，我希望组件嵌入不改变正文源码或撤销历史，以便展示请求没有隐藏的文本写入。
10. **R-U10**：作为用户，我希望同一目标的两处嵌入具有各自滚动状态，以便它们不会相互干扰。
11. **R-U11**：作为用户，我希望引用随目标更新并明确显示失效，以便旧内容不会冒充当前内容。
12. **R-U12**：作为键盘用户，我希望浮窗能接收焦点并在 Esc 后归还焦点，以便完成预览操作。

## 4. 请求面与目标语义

在编辑器页面 SDK 中提供独立只读引用请求能力：打开浮窗、挂载嵌入，以及针对本次请求的关闭/释放句柄。设置页不提供此面；组件宿主若需要请求展示，仍经其既有页面通信发到实际页面，不新增全局无来源浮窗。

公共载荷包含来源实例、目标路径、可选锚点、触发位置或自有容器。组件身份、页面和代次由 SDK 注入，DOM 对象留在页面，不经 JSON 桥发送宿主。目标部分与[导航规格](addon-navigation.md)共用路径与来源口径，但不依赖 T03 的打开面板实现。

- Markdown 继续使用全文/标题/块定位的现有引用语义，不把文本附件 `#line=` / `#range=` 偷换成 Markdown fragment 新语法。
- 非 Markdown 可读文本使用 `src/shared/refText.ts` 的行号与范围解析、REF_TEXT_LIMITS 与原生文字外观链路。
- 已有图片/PDF 等本地引用类型可沿现有 provider 分派；不扩大外部网络、登录态或附件类型准入。
- 初次锚点非法仍报错；已打开内容因文件修改变短的刷新沿原 anchorOptional/clamp 口径。
- 普通链接混合定位 `note.md:20#标题` 由共享解析拒绝，不在请求侧另写一套“优先使用行号”的容错逻辑。

## 5. 浮窗契约（T05）

### 5.1 位置与焦点

必须提供有效的本页触发位置：文字对应元素或组件自有控件。平台按现有 hoverPopupGeometry 四边翻转与视口钳制摆放，不添加屏幕中心兜底或自由拖动。

缺省按鼠标请求，不抢编辑焦点；显式键盘请求复用现有键盘浮窗路径，进入可操作焦点域，Esc 关闭后归还仍有效的原焦点。缺失来源或触发位置非法时直接返回拒绝，不猜测另一处位置。

### 5.2 仲裁、关闭与错误

每个页面沿用一个浮窗与现有 popupMutex。新请求替换旧请求，旧请求句柄随之失效；旧句柄关闭不能误关后来另一组件的浮窗。并发异步结果以当前请求身份和 reqId/代次守卫，旧结果不重新挂载。

Esc、既有关闭动作、触发位置消失、来源页面结束、组件停用或故障均释放本实例。缺省鼠标路径沿用移出延迟关闭，键盘路径沿用焦点保活，不新增固定浮窗或多浮窗产品形态。

请求形状与来源有效、但目标解析/读取或锚点失败时，浮窗以现有引用错误视图显示真实原因，同时返回失败结果。连触发位置都无效的请求不创建空浮窗。普通 API 拒绝不构成组件故障。

## 6. 嵌入契约（T06）

容器必须属于本组件已取得的面板内容根或渲染内容根（可为其后代）；平台管理其中的引用子根，不覆盖组件容器的其他内容。单个引用子根只属于一次有效挂载；重复挂载同一位置须先释放旧实例。

引用内容解析可共享缓存，每处挂载仍有独立实例身份、滚动和属性展示状态。共享读取数据不共享 DOM，也不把一个挂载的释放解释为销毁所有同目标引用。

组件调用释放、外层面板/渲染根卸载、容器脱树、页面结束或组件停用时整组释放租约、订阅与子挂载。目标更新沿已有 watch 通道刷新；目标失效按现有引用视图分态显示，失效不生成新写会话。

本面创建的引用树持有只读能力，内核的 Live 切换、保存与编辑入口不得出现或生效。组件自行调用其他已授权 API 的行为不属于本次只读挂载，但不能通过本句柄写入目标。

## 7. 失败与生命周期接口

普通结果区分 invalid-request、view-disposed/released、no-workspace、escape、not-found、anchor-invalid、准入超限及实际读取失败；复用现有错误分态，不能将所有失败折叠为 not-found。关闭与释放可重复调用，返回的身份仅针对本组件本代次请求。

宿主确认的来源与现有嵌套授权通道必须复用，不把任意 URI 接成无来源读取接口。只读展示能力不等于任意 fs 读取，也不承诺同 realm 扩展代码的安全沙箱。

## 8. 呈现、快捷键与验证

采用既有 hover-popup 与嵌入容器模式，执行项目 ui-patterns / style-contract 技能约束；不发明新的圆角、阴影或公开类名。复用的公开选择器必须继续命中实际绘制节点，保留已发布历史片段证据；新增公开入口则按契约目录登记，不改历史基线来迁就新实现。

- 单测先覆盖有效/失效来源、锚点拒绝、只读继承、请求替换、旧句柄、迟到结果、容器归属与整组回收。
- 浏览器用真实组件面板/渲染根验证浮窗定位、键盘焦点、Esc、单浮窗仲裁、只读绘制、错误内容与两处嵌入独立滚动，至少一条断言落在绘制层。
- 真宿主覆盖目标读取、更新与失效、组件停用、父面板关闭和资源回收。使用现有 hoverPopup / refContent / addonT11Ui 夹具接缝，不重建假的渲染器代替生产控制器。
- 每票同步 API 目录、生成参考、编译期消费者、覆盖映射与门禁；开发指南说明与“打开独立文档”的分工，API 样例分别展示浮窗和嵌入。
- 本面不新增独立用户命令或默认快捷键；Esc/键盘进入沿既有路径，组件自己的触发命令仍经统一命令和快捷键注册。

## 9. 不包含与收口

不自动插入正文引用、不开放目标写入、自定义浮窗内容、多浮窗、固定/拖动/缩放新形态或外链网络能力。本规格不修改用户原有鼠标 hover 的总开关与修饰键语义。

T05 覆盖 R-U01–R-U07、R-U12，建立可复用只读目标访问与释放链；T06 依赖 T05，覆盖 R-U08–R-U11 并复验只读和代次回收。两票完成及验收收口前 #532 保持开放。

## T05 实施落档

公开声明在 `src/shared/addonRefViews.ts`，编辑器页面通过 `sdk.refViews.requestPopup` 请求。SDK 注入组件身份与代次；`AddonRefViewsRuntime` 解析来源实例、验证本页可见触发区域，并用现有 hoverPopup 接管几何、互斥、焦点、订阅和内容分派。宿主只接受面板文档及本会话已送达目标作为来源。

API 浮窗不挂载可写根会话。递归引用的 `RefSourceContext.readOnly` 逐层传递，模式查询、切换与编辑入口共同遵守只读能力；不能借父 Live 或历史模式覆盖获得写端口。B 来源首次读取与后续刷新均携带相同来源身份。普通目标错误保留浮窗所有权，组件停用仍能回收错误实例。

样式与元素形态采用既有 hover-popup（480px、8px 圆角、阴影与 z-index 9000 档），未增加公开样式入口、档位或快捷键。对照基线为实施前 `84e91ea028ac64d5f7fab38d51b6b7472494ca3f`；原选择器与变量均保留。浏览器以独立 `#app > .vsidian-hover-popup` 片段检查实际计算色，宿主 `paint.hoverPopup` 检查绘制命中与背景/边框。测试定位见覆盖映射的 T05 行；物理指针与键盘手感保留为人工待验。
