# 规格：锚点跳转（标题引用、块引用与复制块链接）

状态：已共识待实施。本文是锚点跳转能力的单一事实源，覆盖本批次三张实施票（wikilink 锚点、普通链接锚点、复制块链接入口；票号开立后回填）。母题为 #16 的锚点切片；反链面板、链接索引、重命名更新引用与 Markdown 嵌入**明确不在本批**（维持 ADR-0002 按需解析路线，无索引）。

## 范围

- **覆盖**：
  - wikilink 块引用定位——`[[笔记#^块id]]` 跳到目标块（此前只开文件不定位）；
  - 本文件锚点——`[[#标题]]`、`[[#^块id]]` 省略笔记名的当前文档内跳转；
  - 普通链接锚点——`[文字](./文件.md#标题)` 打开后定位标题、`[文字](#标题)` 页内定位；
  - 复制块链接入口——Live 正文右键菜单与快捷键，目标无块 id 时自动补写。
- **排除**：
  - 反向链接、出链面板、链接索引（全库扫描与缓存机制均不做）；
  - 重命名笔记/标题/块 id 后自动更新引用；
  - Markdown 嵌入 `![[…]]`；
  - 阅读视图右键菜单（阅读只读，不接管、不写 id）；
  - setext 标题匹配（沿用一期「仅 ATX」规则，容器内标题不匹配、同名取首——已知限制维持，见人工验证清单）。

## 概念定义

- **锚点**：链接目标中 `#` 之后的部分，用于在目标文档内进一步定位。两种形态：**标题引用**（`#标题文字`）与**块引用**（`#^块id`）。
- **块**：被空行分隔的连续行组——段落、列表、引用块、表格、代码块、标题行各为一个块。文件首行到第一个空行之间也是一个块。
- **块 id**：写在块内**最后一行行尾**的 ` ^id` 标记（id 与正文之间至少一个空格）。id 字符集沿用 `BLOCK_ID_RE`（`[A-Za-z0-9-]+`）。围栏代码块内部、行内代码内部的字面 ` ^id` 不视为块标记（前者是代码内容，后者不是行尾标记）。frontmatter 头区不参与。

## 已确认决策（2026-09-28 设计访谈）

1. 不做反链与索引：锚点跳转继续**按需解析**——跳转时读取目标文档文本定位，无任何持久或内存级全库索引。
2. 复制块链接入口取**正文右键菜单**形态（自绘 contextmenu，架构照大纲菜单先例），并按项目快捷键约定登记可绑定操作，默认 `ctrl+shift+c`、仅 Live 编辑正文时生效。
3. 跳转后的呈现与现有标题跳转同款（面板内 `view.locate` / 文本编辑器 selection reveal），不做 Obsidian 式目标高亮闪烁。
4. 跳转目标缺失时（标题找不到、块 id 不存在）打开文档后给出 i18n 提示，与现有「标题缺失」行为同款。

## 形态学与定位规则

### wikilink 本文件锚点

- `src/shared/wikilink.ts` 放开空路径限制：`inner` 为 `#标题`、`#^块id`（可带 `|别名`）时解析合法，`path` 为空串、`heading`/`blockId` 照常填充；其余非法形态（空锚点 `[[#]]` 等）维持拒绝降级。
- display 默认值为锚点原文（`#标题` / `#^块id`），有别名时别名优先——与 Obsidian 呈现一致。
- 宿主解析：`path` 为空时**不查文件**、目标即当前文档，直接进入锚点定位分支。

### 块定位器

- `src/host/wikilinkTarget.ts` 新增 `findBlockOffset(text, blockId)`，与既有 `findHeadingOffset` 并列：
  1. 逐行扫描行尾 ` ^id` 标记（id 全字匹配、行尾后无其他内容；跳过围栏代码块内部）；
  2. 命中行向上回溯所属块的**首行**（块边界=空行或文件头；围栏代码块的块首=开围栏行）；
  3. 返回块首行行首偏移；同 id 多命中取首；未命中返回 null。
- 定位优先级：`blockId` 与 `heading` 互斥（形态学已保证 `#^` 开头即块引用），无歧义分支。
- 跳转落位：光标与 reveal 区间取块首行整行（与标题跳转的 `[offset, end)` 行区间同款）。

### 普通链接 fragment

- `src/host/linkTarget.ts`：
  - `resolveInside` 不再丢弃 `#fragment`——按 **CommonMark 语义取首个 `#`**，其前为路径、其后整段为 fragment；路径部分再按现状剥 `?query`；
  - `preClassify` 不再把 `#` 开头的 href 拦为 blocked/empty——解析为本文件锚点目标。
- **fragment 仅对解析为工作区内文档目标的链接接管**：`http(s)`、`mailto`、`vscode` 等带 scheme 的外部链接照旧外部打开，其 `#` 是网页锚点语义，不做标题定位。
- 定位执行：目标文档打开后复用与 wikilink 同源的定位器（标题→`findHeadingOffset`；fragment 本批仅支持标题语义——`#^块id` 形态的普通链接同样定位到块，能力同源不额外设限）。目标已在本扩展面板走 `view.locate`，否则 `showTextDocument` + selection reveal，与 wikilink 跳转同款。
- 含空格路径（宽松链接）与锚点并存时同样按上述规则拆分，**测试矩阵必须覆盖**（见验证节）。

## 复制块链接入口（右键菜单与快捷键）

- **触发**：Live 正文 `contextmenu` 委托（CM6 内容 DOM），事件坐标经 `posAtCoords` 落到行，再判定该行所属块与是否标题行。
- **菜单项**：
  - 标题行（ATX）：「复制标题链接」+「复制块链接」；
  - 其余块：「复制块链接」。
- **复制标题链接**：拼 `[[笔记名#标题]]` 入剪贴板，标题取标题行字面文本（含行内标记），与大纲菜单 `copyLink` 及宿主 `findHeadingOffset` 的比较口径同源。
- **复制块链接**：目标块已有行尾 ` ^id` → 直接拼 `[[笔记名#^id]]` 复制；没有 → **先自动写入再复制**：
  - 写入位置为块尾行行尾（行尾不足一个空格时补一个空格再接 `^id`）；
  - id 生成：4 位随机小写字母，与文档全部已有 id 冲突时重新生成直至唯一；
  - 写入是**一笔标准编辑事务**（走 webview 单事务 dispatch → 标准 `edit.request` 出站），可撤销、参与 dirty 与保存管线；
  - 写入成功后再经宿主写剪贴板（参照 `writeHeadingLinkClipboard` 端口模式扩展块链接端口）。
- **快捷键**：登记为可绑定操作，默认 `ctrl+shift+c`，仅 Live 编辑正文时覆盖宿主绑定；语义为对**光标所在块**执行与右键同款的复制（光标在标题行=复制标题链接）。支持改绑、显式清空、单项/全部恢复默认（清空不随重启恢复）。
- **边界**：表格内右键按表格整块处理；frontmatter 成型头区不接管；阅读模式不接管右键与快捷键。

## 交互契约

1. 双视图呈现：本文件锚点 wikilink 与块引用 wikilink 的渲染走现有 live 装饰与阅读 inline rule，形态学放开后自动覆盖，不新增渲染分支；点击跳转链路复用现有 `wikilink.activate`。
2. 菜单 UI：自绘菜单（`role=menu`、键盘可导航、Esc 与外点关闭、定位纯函数），结构与样式照大纲菜单先例；新界面元素按 style-contract 技能评估是否登记契约探针。
3. 所有用户可见文字（菜单项、tooltip、通知）经 `src/shared/locales/` 双语言包，禁止硬编码字面量。
4. 修正过时文案：`host.wikilinkUnsupported`（块引用 `^` 属二期）随块引用定位落地同步更新。

## 用户故事

1. 作为编辑者，我希望点击 `[[笔记#^块id]]` 直达目标块，而不是只打开文件落在开头。
2. 作为编辑者，我希望用 `[[#标题]]` 在长文内快速跳节，不必写自己的文件名。
3. 作为编辑者，我希望普通 Markdown 链接 `[t](./笔记.md#标题)` 也能定位到标题，与双链行为一致。
4. 作为编辑者，我希望右键任意段落就能拿到它的块链接，id 不存在时自动帮我补上。

## 实施决策

- **票②（wikilink 锚点）**：`wikilink.ts` 放开空路径；`wikilinkTarget.ts` 增 `findBlockOffset`；`textEditorProvider.ts` 的 `executeWikilinkIntent` 接入 blockId 定位与空 path 当前文档分支；新增块 id 缺失提示词条。
- **票③（普通链接锚点）**：`linkTarget.ts` fragment 结构化传出与 `#` 前缀放行；`executeLinkIntent` 接定位；更新 `linkTarget.test.ts` 既有「锚点拦截/剥 fragment」断言（行为变更）与人工验证清单已知限制。
- **票④（复制块链接）**：webview 新增正文 contextmenu 模块（纯函数菜单模型 + DOM 装配 + 委托，照 `outlineMenu.ts` 结构）；块边界判定与票②共享形态学；快捷键入 `keybindings` 注册表。
- 依赖关系：票④ Blocked by 票②（共享块形态学与块定位器）。

## 验证与完成条件

- **TDD**：形态学（本文件锚点合法/非法矩阵）、`findBlockOffset` 矩阵（围栏内不命中、CRLF、列表块尾、多命中取首、块首=开围栏行）、普通链接 fragment 拆分先行。
- **含空格路径测试矩阵**（用户点名必测）：`[t](./my file.md#标题)`、`[t](./my file#标题)`（宽松链接两路）、`[t](#标题)` 页内、`[t](./a#b.md)` 路径含 `#`（按 CommonMark 拆分为路径 `./a` + fragment `b.md`，行为文档化为已知边界）、已编码 `%20` 形态。
- **控制器与浏览器**：jsdom 单测覆盖跳转意图上报与菜单命令；票④涉及 webview 交互，合并前必跑 `npm run test:browser`。

- **回归与文档**：compile / test:unit / test:browser / test:integration 全绿；更新 keybindings.md、人工验证清单、文件树；README 双语功能清单补锚点条目。
