# 2026-10 批次：设置页结构优化（分词归并 + 标题组图标）——批次总览

> 状态：**已并入 main**（2026-10-01，PR #271；总览 #262 + 子票 #263–#265 四票落地，评审轮修复完成，落地提交见「6. 轮次记录」R4）。本文档是本批次的实施树与共识落点；实施分支 `batch/2026-10-settings-sections` 已随合并清理，后续维护在 main。

## 0. 需求原文（2026-10-01）

1. 中文分词从一级侧栏分组并入「编辑器」分页，作为二级标题组。
2. 编辑器分页内每个二级标题组需要一个 SVG 图标，放在标题前方，对齐方式不变（原标题文字向后挪动）；字形优先自绘或贴合预置，没有的走生图管线，清单列全、逐项拍板。

约束：图标清单经两轮访谈定稿（v1 提出 → 用户改判「显示=显示器、符号输入=打字机、分词交生图方」→ v2 实形 + 占位清单拍板「可以」）。

## 1. 事实基线（2026-10-01 调研）

### 1.1 设置页结构与图标现状

- 侧栏一级 6 项：常规 / 编辑器（内建分组）+ 快捷键 / 外观 / 索引维护 / 中文分词（附加分页）。前 5 项已有内联字形（设置页视图 `icon()` 单一函数表）：常规 = 双拨杆（#230 换形）、编辑器 = 铅笔、快捷键 = 键盘、外观 = 调色板（#231 外观合并）、索引维护 = 链环（形态改版）；「中文分词」分页图标为**占位借用的 keyboard 字形**（语义本就不符）。
- 设置页统一 SVG 渲染规则：`.vsidian-settings svg` = 20px、`fill:none`、`stroke:currentColor`、1.7 圆角线帽——新增字形同族即零额外样式成本，明暗主题自动跟随文本色。
- 编辑器分页内二级 h3 组 5 个（显示 / 编辑 / 符号输入 / 代码块 / 图片，`editorSectionDefs` 顺序即渲染顺序），**全部无图标**；常规页无二级组；附加分页内部只有表单 caption 标签，无组标题。
- 分词分页 = WordSegmentSection：单页两块（引擎与下载源 radio 组 + 自定义 URL / jieba 资源下载删除管理），entries `engine` / `resource` 供全局搜索定位与宿主 `settings.focusSection` 定位（`openWithSection(section, entry)` 通道现成）。
- 编辑器分页定义集显式排除 `editor.wordSegment*` 三键（#239 呈现归分词分页，注释钉住）；全局搜索分组 = 常规 / 编辑器 / 各附加分页。
- 主工作树 main 在批次创建时已前移至 957d4dc（PR #261 合入），工作树基于该点创建。

### 1.2 资产族与生图管线

- `media/quick-actions/` = 96 viewBox **实心填充**、填色硬编码、明暗两套（PNG+SVG），右键菜单 / 查找面板族；与设置页线性字形**不同形**，直接挪作标题图标会破坏统一性（v1 清单已排除）。
- 生图管线（项目技能 ai-icon-sheet-to-svg）：**必须 Codex（ChatGPT）会话执行**，其他环境写 handoff 交接文件即停，不以其他模型或手工绘图代替；流程 = 合并生图（现有图标参考板 + 新格）→ 96×96 裁切源图 → `scripts/quick-action-icons.py`（KEYS/COLORS 契约 + VTracer 提真 SVG path + validate）→ 资产与 README / contact-sheet 更新 → 96px / 18px 明暗并排校验。

### 1.3 测试与门禁先例

- unit jsdom 分节测试：settingsPage / appearanceSettings / indexMaintenanceSettings / wordSegment（分节挂载、消息回显断言）。
- browser：settingsPage.mjs 真浏览器驱动设置页；项目「视觉层断言」评审约定——呈现类变更至少一条断言落绘制层（用户看到的东西），CSS 关键规则由契约测试钉住。
- style-contract 门禁：新增类名 / CSS 规则须走技能流程并过 `check:stylecontract` 与基线复验。

## 3. 已定边界（事实或既有契约钉住，不设为决策点）

- **h3 布局**：flex + gap，图标置于左 padding 缘，标题文字右移；「对齐方式不变」的验收口径 = 行级 margin、padding、border-bottom 视觉规则不变，仅标题文字起点右移。
- **视觉层断言**：图标可见性断言落绘制层（评审必查约定，样式注入失效时 DOM 存在性断言照样通过的教训）；CSS 关键规则由契约测试钉住。
- **i18n**：图标纯装饰 aria-hidden，无新增用户可见文案；如需可达性名称走 locales 键（双语 parity 照常）。
- **设置值零迁移**：`editor.wordSegment*` 键名与持久化值不变，重组纯呈现；快照回显、wordSegment.state 下载状态推送、notice 基调渲染路径不变；宿主 jieba 下载/删除链路不动。
- **生图产物接入**：按主题选明暗资产（img 或 CSS mask 择一，实施票定）；接入后与相邻内联字形在设置页标题实际字号下并排核验。实际落地为第三形态——**span + CSS background-image**（`vsidian-settings-generated-icon` 槽位，明暗两套 SVG 随包经打包内联进设置页 CSS，按 `body.vscode-dark` / `vscode-high-contrast` 切换）：尺寸、明暗切换与随主题表现均与 img/mask 两形态等价，评审轮拍板接受此形态，不按原两选项返工。
- **工作区**：批次在独立工作树 `vsidian-worktrees/wt-settings-sections`（分支 `batch/2026-10-settings-sections`）实施，主工作树留用户本人；同文件相遇的其他批次按「后开工方 rebase」惯例。
