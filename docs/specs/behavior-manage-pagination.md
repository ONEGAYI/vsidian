# 输入行为管理分页与积木筛选（#474）——规格

> 状态：**定稿**（2026-10-13 三轮访谈，用户确认；补充细则四条随定稿接受）。代码基线：origin/main @ ee8af89e（#465/#466 已合并——行为管理独立成设置页侧栏分页）。方向决策见 [ADR-0015](../adr/0015-behavior-filter-query-blocks.md)。

## 0. 需求原文（2026-10-13 票面要点）

- 左右分页：行为条目超过单页容量时支持前后翻页；页容量、页码呈现、翻页控件形态规格期定夺。
- 筛选搜索：按行为名称/组件过滤；多语言名称的匹配口径对齐 #464 `resolveAddonBehaviorName` 渲染语义。
- 票面待定夺：命中排序语义；已关闭行为是否参与筛选集；分页与调序跨页移动交互；分页状态是否持久；`focusEntry` 定位跳页复位；小数量阈值。
- 关联：#465/#466（本票承接其独立后的行为管理页）；与 #476 无依赖关系（票面钉住）。

## 1. 事实基线（2026-10-13 核查）

### 1.1 列表现状（#465 落地后）

- #465 的「分页」是设置页侧栏 **IA 级分页**；**行为列表本身全量一次性渲染**（`src/webview/addonBehaviorManageSection.ts:155-160`），无页容量、无翻页控件、无搜索框。
- 行结构（:188-241）：显示名（`resolveAddonBehaviorName` 当前语言解析）+ 所属组件（`addonEntry.label` 回落 addonId）+ 状态徽章（单项「已关闭」/「组件已停用」/「故障暂停」）+ 上移/下移按钮 + 单项开关；行下可选 `details` 说明/例子。
- 调序 = 真实按钮、**全量相邻交换**、发 `addons.behaviorsSetOrder`（:218-223）；首/末行对应按钮 disabled；重建焦点保持经 `data-rebuild-focus`（:223）。
- 会话恢复现状只记「分页 id + scrollTop」（`settingsPageView.ts:666-676`）；行为管理分节**未实现** `captureState`/`restoreState`。

### 1.2 全序与名称解析

- `orderedAddonBehaviorKeys`（`src/shared/addonBehaviors.ts:369-378`）：用户序在前 → 未调序注册项按完整键字典序追加尾部；**已关闭项保留原位（展示全序）**。`resolveAddonBehaviorOrder`（:355-364）= 链执行有效序（剔除 disabled）。
- `resolveAddonBehaviorName(name, localeLang)`（:201-223）：zh 系候选链 `zh-cn → zh → en`、非 zh 只 `en`；纯 string 原样返回。
- 完整键 = `addonId#behaviorId`（`addonBehaviorFullKey` :135-137）；行 `dataset.behaviorKey` 已是完整键。

### 1.3 持久化与定位现状

- 行为状态存储：globalState 单键 `vsidian.addonBehaviors.state.v1`（version 1：`order` + `disabled`）（`src/host/addons/addonWiring.ts:241-252`；服务 `src/host/addons/addonBehaviorStateService.ts:37-114`，写串行化、失败回滚、`onChanged` 钩子已有）。
- focusEntry：本分节仅 `behaviors` 整卡条目（:30、:50-58），定位 = 整卡 located 类 + `scrollIntoView`（:170-172），无行级/页级定位。
- 设置页 webview **无 toast 组件**（CONTEXT.md「轻提示（toast）」原钉在编辑器视口语境；`settingsPageView.ts`/`settingsMain.ts`/`settingsPage.css` grep 零命中）。

## 2. 设计树（决策节点与拍板记录）

### 2.1 列表分页

- **D1 页容量 20 行/页**；规模预期数十到一两百条（R1 轮 Q6 暂定假设，用户接受）。〔Q7〕
- **D2 翻页控件**：上一页 / 下一页 + 「第 x / y 页」指示 + **首页 `<<` / 末页 `>>` 按钮**（到头/到底页，按需禁用、发灰）。〔Q7 + 第二轮 Q11 用户补充〕
- **D3 阈值**：总页数 ≤ 1 时不渲染分页控件（自然阈值，无额外小数量开关）。〔Q7〕

### 2.2 积木式筛选（核心设计，R1 轮起用户主导）

- **D4 形态**：搜索区**不直接输文本，呈现逻辑积木**；旁置加号与垃圾桶。
  - 加号下拉三组：**行为组件**（行为显示名 / 组件显示名 / 行为ID / 组件ID）、**逻辑组件**（AND / OR / NOT）、**状态组件**（启用状态）。
  - 字段积木 = 圆角矩形内嵌文本输入（例「（行为显示名：____）」）；逻辑积木 = 菱形带缺口，可拖入任意类型积木（例「<( ) AND ( )>」；NOT 单缺口）；状态积木 = 矩形带有限选项下拉选框（例「[ 启用状态 [已启用>] ]」）。
  - 垃圾桶带 tooltip 说明用法：单击清除整个查询；拖拽或单击选中某积木后操作则删除该积木及其嵌套内部。〔R1 轮用户设计 + R6 确认〕
- **D5 匹配语义**（均大小写不敏感子串）：行为显示名 → 当前语言解析名（所见即所搜，切语言后查询含义随之变化）；组件显示名 → 行上组件显示名；行为ID → 局部 behaviorId；组件ID → addonId。完整键不单设积木——「行为ID AND 组件ID」组合可达同等精确度。〔R3 ✅〕
- **D6 状态积木**：下拉四态「已启用 / 已关闭 / 组件已停用 / 故障暂停」，与行徽章一一对应；新积木默认「已启用」；求值 = 行当前状态等于所选值。〔R4 ✅〕
- **D7 求值模型**：顶层并列积木隐式 AND（不强制先建逻辑积木）；OR/NOT 须显式放菱形；**空文本的字段积木恒真**（不过滤，占位待填）；缺口可嵌任意积木、任意深度（受总数上限约束）；**命中保持展示全序、不重排**（用户序在前、未调序项字典序、已关闭项原位）——积木只过滤不排序；无积木 = 全集。查询树序列化与求值为 shared 层**纯函数**，UI 编辑器与求值解耦。〔R5 ✅〕
- **D8 交互**：
  - **选中态 = 该积木及其全部嵌套整体轻微发光**，明示删除范围；单击垃圾桶删除选中者及嵌套。〔第二轮用户补充〕
  - 删除前可把嵌套内容**拖出抢救**；拖拽可把积木直接放到查询区**顶层任意位置**（其他顶层积木之间或开头/末尾），也支持顶层内重排。〔第二轮用户补充〕
  - **键盘嵌套构建**：Enter 拾取（浅色高亮保持）→ 方向键移动选区（深色高亮）到目标缺口 → 再次 Enter 放下；Esc 取消拾取（规格建议，定稿时确认）。〔第二轮用户补充——推翻 R8 原「嵌套仅指针操作」推荐〕
  - Tab 焦点序列可达全部积木与控件；Delete = 删除选中积木（垃圾桶的键盘等价）；字段文本就地输入。
- **D9 复杂度上限**：积木总数 ≤ 16，超限时加号禁用 + 悬停提示说明；不另设深度上限（总数天然约束）。〔R7 ✅〕

### 2.3 调序

- **D10 跨页调序**：上移/下移语义不变（全序相邻交换）；交换后若被移动行离开当前页，**视图跟随该行跳至所在页并保持可见**（用户意图是移动这一行，视线跟着行走）。〔Q10 ✅〕

### 2.4 持久化

- **D11 作用域**：**跨重启的用户级持久**（宿主 globalState，不分工作区——行为启停本身是 user 级）；内容 = 当前页码 + 积木查询树（结构化序列化）；不持久滚动位置（页码已决定视口起点）；恢复时页码越界（注册集变化）**静默回落第 1 页**。〔Q11「持久」+ R10 ✅〕

### 2.5 定位

- **D12 协议形状**：`focusEntry` 扩两种行内形状——`page:<页码>`（定位页）与 `row:<完整键>`（定位行）；组合时行优先（先跳到行所在页再高亮行）。〔R11 ✅〕
- **D13 合法性检查**：页码 ∈ 1..总页数、行键 ∈ 当前注册全集；检查在行为载荷（`addons.behaviorsGet` 回包）到达后求值（「正在读取」态期间定位挂起）；非法 → **回落无定位默认渲染 + 轻提示（toast）**，文案走 i18n。〔Q11 + R11 ✅〕
- **D14 toast 承载与形态演进**：设置页引入轻提示组件（复用编辑器侧 toast 实现随设置页 bundle 打包）；CONTEXT.md「轻提示（toast）」术语扩域为「编辑器与设置页 webview 通用」。否决 notice 段复用（常驻形态与一次性反馈语义不符）。〔R12 ✅〕
  - **形态演进（第三轮 T2 引出）**：toast 可携带**气泡内撤销按钮**（显示窗口内可点击，恢复被清空状态）；气泡顶部新增**倒计时条**——深色条右端锚定满格、左端随倒计时向右收缩至零，标示消失窗口。悬停/聚焦气泡时暂停倒计时（规格补充细则，定稿确认）；倒计时时长实施期定（满足「读清文案 + 移动指针点撤销」）。该形态演进登记 ui-patterns toast 条目。
- **D15 定位与筛选的交互**：〔第三轮 T2 定案〕外部定位 `row:X` 时若 X 被当前持久查询过滤——**清空查询并定位**（定位意图高于筛选保持），同时弹 toast 说明发生了什么（文案 i18n，说明筛选已被清除以显示目标）；toast 显示时间窗口内，用户可点击**气泡内撤销按钮**恢复清空前的查询与页码。撤销恢复的是 UI 状态（查询树 + 页码），不涉及文档编辑历史。

## 3. 已定边界

- 搜索匹配对齐 `resolveAddonBehaviorName` 渲染语义（票面钉住）。
- 不改行为状态存储 version 1、不改调序合并语义（`mergeBehaviorOrderPreservingUnknown`）。
- 积木查询与求值为 shared 层纯函数；UI 层只做编辑。
- 翻页控件、积木（圆角矩形/菱形/矩形三态）、下拉选单、发光选中态均为**新 UI 形态**——实施前按 ui-patterns 技能「新形态先登记后实现」。
- 定位优先于恢复：focusEntry 在场时不走 restoreState（沿用既有机制语义）。

## 4. 明确不包含

- 拖拽排序与「移到顶部/底部」快捷动作（后续票，若需要）。
- 预设「仅启用/仅关闭」过滤器开关（状态积木已可表达）。
- 跨工作区/工作区级持久（用户级即止）。
- 全局搜索命中行为管理具体行（第二轮用户澄清：行级检索职能归本页搜索）。
- 键盘构建之外的指针手势细化（长按、多选拖拽等）。
