# CSS 片段与公开样式契约实施规格

状态：2026-09-27 设计访谈确认，待实施。总需求：#17；其前置 #15 已关闭。自动兼容检查和 CI 拦截为必交付范围，不是可选后续任务。

## 问题与目标
用户需要在指定目录维护 CSS，跨项目使用并复用明确支持的 Obsidian 入口。公开指南必须与安装版本一致；内部重构不能静默破坏已发布片段。

## 用户故事
1. 作为用户，我希望指定用户级目录并逐项启停片段，以便多个项目共用外观。
2. 作为用户，我希望保存 CSS 后生效并能手动刷新，以便即时调整样式。
3. 作为用户，我希望按文件名确定片段顺序，以便可预测地覆盖样式。
4. 作为用户，我希望将样式拆分到子目录并引用图片、字体，以便组织整套样式。
5. 作为用户，我希望使用 HTTPS 字体与样式表，以便使用在线字体服务。
6. 作为 SSH 用户，我希望远程环境单独指定目录，以便在不同环境使用各自资源。
7. 作为用户，我希望读取失败时保留当前可用样式，以免短暂故障打断编辑。
8. 作为用户，我希望从不受片段影响的设置页或命令暂停所有片段，以便恢复界面。
9. 作为样式作者，我希望查阅当前版本的入口、示例和兼容范围，以便正确编写片段。
10. 作为升级用户，我希望旧片段得到兼容保护和提前迁移通知，以免升级破坏外观。
11. 作为维护者，我希望自动拦截破坏公开入口的改动，即使代理同步修改当前测试，以便约束自动编码。

## 已确认行为
- 用户级目录，环境内各项目共用，无工作区级叠加。本地与 SSH 分别配置；无本地向远程同步机制。
- 第一层 .css 是独立片段，新片段默认关闭。子目录文件仅作依赖，不自动列入片段列表。
- 文件名确定加载顺序，同等层叠优先级后加载者优先；不声称可以覆盖所有 !important 或更高特异性规则。
- 保存后自动更新，保留手动刷新；开关与目录重新打开后回显。
- 定制正文、大纲、代码块按钮、图表弹窗等编辑器 webview；原生源码编辑器不受影响，独立设置页不注入用户 CSS。
- 提供暂停全部片段及恢复入口；暂停保留各片段原有开关，不能逐项清空。
- 支持目录内相对图片、字体、嵌套 CSS 导入，以及 HTTPS 字体与 @import；浏览器解析标准 CSS，不建设在线资源离线下载管理。
- 本地暂时读取失败：当前窗口保留最近成功样式并提示；明确删除/停用：撤下。网络字体回退备用字体，远程 CSS 失败不妨碍其他片段；无效 CSS 遵循浏览器处理，不承诺整份回滚。
- 样式或字体变化导致高度变化时重新测量并保持滚动锚点；不重建编辑器导致输入、选区或撤销状态丢失。
- 只承诺明确清单中的 Obsidian 原名入口；语义对应不等于原名片段可直接使用。不得为 CSS 兼容取消视口虚拟化。

## 实施边界与模块
复用 src/host/settingsService.ts 的持久化模式和独立设置页，在 shared/protocol.ts 声明并校验消息；宿主拥有配置、目录读取与监听的权威，webview 负责样式加载与渲染状态。环境身份须隔离，不能让远程目录覆盖本地配置。

沿用 textEditorProvider.ts 的资源 URI/CSP 装配；本地资源限定所选片段目录（含子目录），拒绝越界路径及链接逃逸。用户在设置页显式选择目录并启用，不从工作区自动发现或执行片段；实现须检查受限工作区行为，不借此扩大脚本执行能力。HTTPS 资源遵循浏览器跨域约束，不以宿主代理绕过字体服务限制。

列表只扫描一层不意味着监听只扫描一层：被导入的本地 CSS 变化须更新。保留嵌套导入的相对路径和标准条件语义，循环导入须有界、不得挂死。网络资源不承诺推送更新；手动刷新及缓存行为需明确。入口加载失败与嵌套跨域失败的可观测能力不同，报告能确认的状态，不虚构逐条错误定位。

设置页提供选择/打开目录、刷新、片段开关、暂停/恢复及样式参考。全部用户文字 i18n；每个用户操作评估快捷键注册和模式，默认可不绑定，遵循既有不抢源码/设置输入规则。

## 公开契约与用户指南
建立一份结构化清单：稳定 ID、选择器/变量、用途、视图及状态、必要 DOM 关系、示例、Obsidian 对应项及支持等级、验证定位、引入/弃用/移除信息。迁移既有映射表，不新建互相竞争的事实源。

先逐项核实标题、行内格式、列表/任务、链接/图片/双链、表格，再覆盖代码卡片、高亮、公式、图表、大纲、按钮及弹窗。公开项须有实际效果验证；不支持及虚拟化限制也应可查。生成与安装版本配套的用户指南，设置页可离线打开；文档与渲染验证不能仅互相检查相同字符串。

## 兼容期限与 Agent 约束
默认长期保留公开入口；先发布弃用声明、替代写法及迁移示例，至少经过两个后续次版本且满 30 天后才允许显式移除。时间从实际发布起算；例如 0.2.x 弃用，最早 0.4.0 且满足天数。补丁版本不计，跳升版本号不能伪造发布历程，到期不自动删除。

本轮工作树 AGENTS.md 的“公开样式契约：Agent 修改约束”须随实现落库；CLAUDE.md 继续只引用它。固定已发布版本/SHA 及历史片段；不得删除、跳过、弱化旧测试或把历史选择器替换成新名来消除失败。检查器/CI/基线变更独立说明审查，缺历史证据时保留兼容入口。

## 自动兼容与发布门禁（必交付）
- 比较候选清单与独立历史基线，校验指南生成一致性；旧片段在新实现上验证实际可见效果。
- 历史基线覆盖所有尚需兼容的公开入口，不能只保留最近一个版本而丢弃仍在保护期内的条目。
- 校验弃用版本、真实发布日期和发布跨度；历史数据缺失或不可取得不得降级为通过。首次建立基线须对照既有发布与映射表核实、留证。
- 必须有负向验收：候选分支同时删除实现、清单、旧测试仍失败；改日期、跳版本、隐藏检查也不能伪装正常通过。
- 把这些检查接入合并必需状态及发布前复验；不能仅加入非必需 browser job。保护检查器与历史来源不被候选分支任意替换，工作流/基线修改单独审查。
- 远端规则需实际核实并留证；实施代码不等于配置已生效。权限或授权不足时明确列为未完成，不能关闭门禁票。本次开票不包含立即修改远端保护设置。

## 验证与交付
行为修改 TDD；纯规则文档做内容/链接/差异检查。复用现有 unit、浏览器生产控制器和真实 VSCode 宿主入口；不为测试构造另一套样式加载实现。覆盖切换模式、视口卸载重挂、明暗主题、字体晚到、输入中热更新、本地与 SSH、路径含空格、读取失败、删除、循环导入、网络失败及暂停恢复。绘制层至少验证实际可见效果，单独 DOM 存在性不算通过。

各票首次长耗时验证落盘日志及退出码。真实 SSH/IME/鼠标验收与自动化分开记录；环境不足不得谎报通过。最终需 VSIX 安装态样式参考/资产加载和包体检查；README 中英文同步。

## 不在范围
任意 Obsidian 主题/插件私有 DOM 无条件兼容、原生 VSCode 界面换肤、工作区片段自动加载、跨机器同步、在线资源离线下载管理、完整 CSS 诊断器、发布或合并授权。
