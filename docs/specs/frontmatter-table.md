# 规格：YAML frontmatter 表格化呈现与就地编辑

状态：已实施（工单 [#140](https://github.com/ONEGAYI/vsidian/issues/140)）。本文是 frontmatter 表格化的单一事实源，工单验收以此为准。

## 范围

- **覆盖**：文档头 YAML frontmatter 在 Live 与阅读两侧的表格卡片呈现；Live 就地增删改键值对；手动输入构造头区的自动成型。
- **术语**：frontmatter 指首行 `---` 至闭合 `---` / `...` 行的头区；边界判定单一事实源 `markdownDoc.frontmatterRange`（8192 有界扫描，未闭合 / 超长降级普通 Markdown）。
- **一期值类型**：标量（字符串 / 数字 / 布尔 / 日期）+ 字符串数组。
- **排除**：嵌套对象、对象数组等复杂类型的表格编辑（整卡降级源码）；头区 lint / 校验、模板补全；Obsidian 属性面板完整功能对标。

## 已确认决策（2026-09-27 澄清答复）

1. **两侧表格化**：Live 表格卡片 + 阅读同款表格（对称原则）。
2. **成型**：头区合法即**常驻表格卡片**——不做「光标进入显源码」；编辑直接在表格内就地完成，交互与现有表格网格同构；源码形态仅作降级出现。
3. **值类型**：标量 + 字符串数组进表格交互；复杂类型整卡降级源码（可编辑，转简单后自动成型）。
4. **写回**：走既有文本管线（CM6 → 消息 → WorkspaceEdit；LF 坐标 NewlineCoordinator），不新增旁路。

## 交互契约

1. **成型与降级**：合法（可解析且全部键值为一期类型）→ 表格卡片；未闭合 / 超 8192 / 解析失败 / 含复杂类型 → 源码字面呈现（现状机制），编辑不受限；合法性与形态随编辑实时切换。
2. **就地编辑（Live）**：键列、值列点击进入编辑；标量为文本输入；字符串数组呈现项列表（增删项、项内编辑）；提供新增键值对（增行）与删除键值对（删行）入口；键盘行为对齐表格网格（Tab / Enter 导航，实施核对项）。
3. **阅读侧**：同款表格，只读（阅读模式除任务勾选外只读的既有边界不变）。
4. **序列化最小重写**：未改动的键值行保持原文形态（顺序、引号、缩进、行内注释尽量原样），仅重写被编辑行；数组项增删在该行内重写。若实施证明成本过高，可降级为整段规范化重写，但须在工单回报显式说明取舍。
5. **与既有机制的关系**：头区内不参与列表延续 / 公式 / 双链 / 围栏渲染 / 大纲（现状降级机制保持）；行号、查找、任务勾选、外部变更同步、撤销栈均走现状管线，不回归。
6. **围栏行的源码显形（已实现边界）**：首行 `---` 与闭合 `---` 行在光标触及该行时撤下清空 / 替换装饰、源码显形可编辑（与表格分隔行同款语义，`selectionTouchesRange` 闭区间口径）；键值行与数组项行**常驻卡片形态**，不因光标进入而显源码——编辑直接发生在源区间（mark 映射），无独立输入模型。

## 用户故事

1. 作为编辑者，我在文档头手打 `---` 与几行键值后，头区自动变成表格卡片，不需要记语法细节。
2. 作为编辑者，我在表格里直接加一行、改一个值、删一个 tag，源文件跟着变。
3. 作为读者，我希望阅读视图里头信息也是整齐的表格而不是源码块。
4. 作为编辑者，我的头区写了复杂嵌套时，它退回源码形态让我继续编辑，内容不丢。

## 实施决策

- **依赖**：引入 `yaml@2.9.1`（精确版本锁定 + lockfile）；解析失败不让错误冒泡打断编辑。
- **Live 卡片**：参照表格网格 / 代码块卡片的装饰管线——头区行经 CM6 装饰替换为表格卡片 DOM，编辑事件映射为文本变更；重渲染防抖与表格网格同策略。
- **阅读侧**：`splitReadingBlocks` 的 frontmatter 块由转义 `<pre>` 换为表格 HTML（经安全渲染层，值全转义）。
- **i18n**：表头、增删入口、空态等全部文案入两语言包。
- **协议**：如需新消息以 protocol.ts 为单一事实源（优先复用既有文本编辑消息通道）；parity 由既有机制把关。

## 验证与完成条件

- **TDD**：解析 → 编辑计划 → 序列化纯函数先行（最小重写、非法降级、头区外 `---` 不误判、数组编辑等用例）。
- **分层验证**：jsdom 控制器单测（成型 / 降级切换、增删改写回、数组项编辑）；集成（真宿主写回、dirty、外部变更同步、模式切换不丢内容）；浏览器测试（网格内输入回流，合并前必跑）。
- **视觉层断言**：表格卡片绘制层可见；全部新文案走 i18n。
- **用户人工验收**：成型手感、表格编辑观感、与阅读侧对称性。
- **回归与文档**：compile / test:unit / test:browser / test:integration 全绿；更新 README 双语、人工验证清单、文件树（CONTEXT.md 词表已随本批增补）。
