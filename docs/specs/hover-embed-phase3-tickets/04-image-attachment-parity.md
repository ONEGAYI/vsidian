## 问题与交付

图片悬停，以及与普通 Markdown 图片一致的 ![[图片]] 嵌入。

## 实施范围

- 从有效本地图片双链／普通链接到来源校验、资源装载、实际图像呈现形成纵向闭环。悬停使用既有触发与关闭规则；![[图片.png]] 按 ![](图片.png) 复用图片呈现，不新增文件名引用卡片壳。
- 以现有普通 Markdown 图片的加载、错误重试、按钮与弹窗规则为单一行为源。默认适应布局、查看大图、缩放／平移都通过已有图片路径；不独立增加一套交互。
- 固定 PNG/JPEG/GIF/WebP/SVG/BMP 与 APNG/AVIF 的下界解码矩阵；支持与失败以实测为准。不引入 TIFF/HEIC 转码。
- SVG 仅经非交互 img 资源加载，不注入 SVG DOM、不以 object／iframe 执行。动图离屏撤下资源、重新挂载重新播放；复用 #201 失效与来源边界。
- 目标 rename／移动沿用引用索引与源码更新规则；不修复本期无关的既有三重百分号编码边界。

## 验收标准

- [ ] 同一文件以两种嵌入语法绘制时尺寸、颜色、按钮、点击／编辑源码及查看大图行为一致；至少一条比较落实际绘制层。
- [ ] 加载失败、不支持解码与 SVG 恶意脚本样本给出正确状态，不执行脚本、不让第三方资源获得消息桥。
- [ ] 普通图片已有链接内／表格网格内弹窗排除不放宽；在表格格内允许显示图片不等于允许图片弹窗。
- [ ] 递归来源 B 中图片按 B 解析；父源码区间与图片内部交互不误写 A。显示、重试、弹窗与关闭均零文档写回。
- [ ] 文件改动／删除／恢复与多次装卸正确刷新、释放；大图和动图实测记录费用，不能将 CSS 缩小当作内存限制。

## 复用入口与验证

src/webview/liveLinks.ts、imageResource.ts、imagePopup.ts、reading 图片挂载、embedCard.ts；src/host 图片资源／索引通道；docs/specs/image-popup.md、vault-index-backlinks.md。

## 明确排除

链接内／表格格内图片弹窗扩大、新增图片编辑／转码、独立图像查看器；尺寸别名语法不自动新增。

## 共同完成条件

- 对可执行行为先补能暴露目标问题的契约测试，再实现；采用生产 browser／真实宿主等既有高层入口，不只检查消息调用次数或 DOM 存在。
- 呈现变更先加载项目 style-contract、固定旧契约，提供实际绘制和 CSS 契约证据。所有用户文字经 locales／t()，设置只进 Vsidian 自有页面。
- 每个新增操作登记可绑定入口、默认值和有效状态；只读内容不接管写操作，焦点和 Esc 沿用已有优先级。
