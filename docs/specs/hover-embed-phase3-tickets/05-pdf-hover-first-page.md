## 问题与交付

悬停本地 PDF 可看第一页或 #page= 指定页。

## 实施范围

- 采用 P3-02 已通过的精确引擎及资源装配，从双链／普通链接和既有键盘预览入口加载本地 PDF；首条闭环在悬停容器内绘制。
- PDF 导航选择器独立解析 #page=N，1-based 正整数；锚点仅双链（[[...]]／![[...]]）解析，普通 Markdown 链接的 fragment 不解析页码、原样交宿主打开，其悬停预览入口保持。无页码从第一页开始。页码仅初始定位，原链接不改写。
- 错误区分缺文件、页码格式／范围错误、损坏、加密、资源或渲染失败、预算拒绝和取消；加载中可关闭，迟到结果不得重开。
- PDF／图片版本使用规范资源身份和宿主失效代次／文件状态，不伪造 TextDocument.version 或 Markdown LF 范围。

## 验收标准

- [ ] 第一页和指定页均在 1.82.3 真实宿主可见，指定页图像与样本正确对应，零文档 dirty／applyEdit。
- [ ] page=0、负数、小数、非数字、越出总页数与不支持的 fragment 不静默改为顶部；有效引用可修正后重试。
- [ ] 双链 [[a.pdf#page=3]]／![[a.pdf#page=3]] 解析指定页；普通链接 [x](a.pdf#page=3) 悬停仍可预览但从第一页开始，fragment 不由本扩展解析、原样交宿主打开。
- [ ] 读取全程走已授权目标，伪造路径／越根／释放实例被拒绝；Remote SSH 文件由工作区宿主资源通道读取。
- [ ] 快速切换目标／页码、关闭、文件被替换后旧任务取消，旧 canvas 不冒充新目标。
- [ ] 所有状态文字与按钮经 i18n；预览复用既有可绑定操作，页码新操作记录默认未绑定和只读 PDF 适用范围。
