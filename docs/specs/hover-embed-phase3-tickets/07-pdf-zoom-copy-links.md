## 问题与交付

完整基础 PDF 阅读交互，保持全文可达与只读。

## 实施范围

- 增加适合宽度、放大／缩小与当前页导航，默认适合当前容器宽度；缩放与尺寸变化重绘可见页，受已锁定像素费用约束。
- 将 PDF 文本层与 canvas 精确对齐，使原生浏览器选字复制可用。扫描图页仍为图像，没有文本的页不虚构可复制文本。
- 同 PDF 的页面跳转在当前实例导航；HTTP(S) 外链经显式点击交给宿主浏览器打开，跳转不发送自动外链预览请求。
- 不执行 PDF JavaScript、Launch 动作、文件附件或任意 URI；不支持的动作给明确禁用／提示。

## 验收标准

- [ ] 缩放和适合宽度改变实际绘制尺寸，窗口／表格宽度变化后文本层仍与字符位置对应，不能仅断言按钮存在。
- [ ] 中英文文本可选择并复制准确内容；扫描页不会假称文本层可用，缺字体或不可提取文字有真实状态。
- [ ] 同页／跨页链接跳转正确；恶意脚本和非许可协议不执行、不读取工作区任意文件。
- [ ] 各操作在可绑定清单登记，默认未绑定；复制沿用浏览器选区语义，Esc 沿用外层关闭，不夺取正文／设置输入快捷键。
- [ ] 交互与关闭零 applyEdit／零 dirty；缩放不绕过画布预算，任务取消／渲染失败仍能释放。

## 复用入口与验证

P3-02 通过的 PDF API、P3-06 页视口、src/shared/keybindings.ts 及实际操作注册入口、locales、styleContract。

## 明确排除

全文搜索、OCR、密码输入／保存、标注编辑、下载／打印新功能、区域引用。

## 共同完成条件

- 对可执行行为先补能暴露目标问题的契约测试，再实现；采用生产 browser／真实宿主等既有高层入口，不只检查消息调用次数或 DOM 存在。
- 呈现变更先加载项目 style-contract、固定旧契约，提供实际绘制和 CSS 契约证据。所有用户文字经 locales／t()，设置只进 Vsidian 自有页面。
- 每个新增操作登记可绑定入口、默认值和有效状态；只读内容不接管写操作，焦点和 Esc 沿用已有优先级。
- 来源验证、请求代次、目标版本、挂载释放及已存在预算都必须保持；自动化通过不等同用户验收。首次长命令即落盘日志和退出码，复核读取报告。
- 每票按一个新 agent 上下文安排；发现需要扩大接口／产品范围时报告增量并重切片，不将不完整行为标为完成。本票不授权推送、PR、合并或版本发布。
