## 问题与交付

代码／配置文件悬停按已验证语言与主题路线只读显示。

## 实施范围

- 采用 P3-03 通过且必要差异获接受的路线。从合法链接到宿主 TextDocument 权威正文、语言身份、设置与高亮，再到只读悬停形成闭环。
- 只接受已确认可读文件：先 stat／有界探测，二进制、非法编码、超限文件或超长行就地拒绝并提供原生打开入口；编码以宿主打开文档的解码结果为准，不自行猜编码写回。
- 高亮、主题、字体字号和行号以目标资源／语言的原生配置为准；跟随主题与相关设置变化。不内置各语言 grammar 或拿现有代码块高亮冒充用户语言插件。
- 未保存正文和 token 均带目标版本；迟到或过期 token 不覆盖新正文。只读视图选择／复制不创建写端口。

## 验收标准

- [ ] 代表语言、第三方 grammar 和两主题的实际文字着色／字体与 P3-03 对照结果一致；有高亮目标不得未经确认静默降纯文本。
- [ ] 原生本来纯文本的文件可正常纯文本显示；语义 provider 暂不可用不抹掉已验证语法层。
- [ ] 二进制、编码失败、超限与超长行不读完整无界内容、不悄悄截断；失败可从显式原生打开入口继续。
- [ ] 未保存修改和语言／主题变化正确刷新；A／B 两种版本竞态均拒绝过期数据。
- [ ] 输入、粘贴、任务样式文本、右键写操作均不能改 A 或 B；真实宿主 dirty 与 applyEdit 为零。

## 复用入口与验证

P3-03 选择的宿主高亮服务、src/host/hoverDocAccess.ts、hoverPopup.ts、P3-01 只读接口、settings／locales。

## 明确排除

诊断装饰、行内提示、文本编辑、新增行区间引用／文本搜索；先全文预览，不把 Markdown 标题／块语义套到代码文件。

## 共同完成条件

- 对可执行行为先补能暴露目标问题的契约测试，再实现；采用生产 browser／真实宿主等既有高层入口，不只检查消息调用次数或 DOM 存在。
- 呈现变更先加载项目 style-contract、固定旧契约，提供实际绘制和 CSS 契约证据。所有用户文字经 locales／t()，设置只进 Vsidian 自有页面。
- 每个新增操作登记可绑定入口、默认值和有效状态；只读内容不接管写操作，焦点和 Esc 沿用已有优先级。
- 来源验证、请求代次、目标版本、挂载释放及已存在预算都必须保持；自动化通过不等同用户验收。首次长命令即落盘日志和退出码，复核读取报告。
- 每票按一个新 agent 上下文安排；发现需要扩大接口／产品范围时报告增量并重切片，不将不完整行为标为完成。本票不授权推送、PR、合并或版本发布。
