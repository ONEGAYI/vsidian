## 问题与交付

显式开启后悬停 HTTP(S) 链接可看标题、摘要和域名。

## 实施范围

- 新增外链预览总开关，默认关闭；独立形态设置默认卡片。开关和回显在 Vsidian 自有设置页，经 i18n。关闭状态连 DNS 查询都不发起。
- 仅在既有悬停延时／键盘预览实际触发后，由宿主校验当前来源链接再抓取元信息；打开文档、扫描链接和滚动不做预抓取。
- 以非执行 HTML 解析器提取标题与摘要，展示域名和浏览器打开入口；不执行远程 HTML，不自动加载第三方缩略图，不发送文档路径／正文／cookie／身份凭据。
- 限制 HTTP(S)、响应 MIME、超时、响应字节、重定向、同 URL 合并与有界内存缓存。宿主抓取拒绝私网／回环／链路本地与凭据 URL，重定向和实际连接地址一并校验，不能只 DNS 预查后重新无约束连接。
- 沿用 Live 修饰键、Reading／面板直接悬停、键盘焦点和一次一个浮层；来源／开关改变、实例关闭时取消请求并丢弃迟到结果。

## 验收标准

- [ ] 总开关默认关闭、重启／重开回显正确，关闭时 HTTP 与 DNS 请求均为零；形态默认卡片。
- [ ] 控制服务器计数证明只在有效触发后请求，同 URL 合并但每个消费者可独立取消；目标变化不串标题／摘要。
- [ ] 超时、非 HTML、超限、重定向循环、私网及 DNS 换址样本被正确限制；失败说明真实原因并保留打开入口。
- [ ] 恶意 HTML／script／meta URL 不执行、不触发图片／子资源请求；显示内容仅文字和显式安全链接。
- [ ] 内存缓存有键、费用、TTL 和淘汰测试，不持久存浏览历史；Remote SSH 抓取位置明确，网络失败不伪装成文件缺失。
