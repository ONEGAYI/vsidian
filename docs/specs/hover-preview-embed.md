## 目标与分期

在当前文档中查看引用目标，减少来回打开文件，同时为可编辑引用视图与其他文件类型保留架构空间。

| 阶段 | 交付范围 |
| --- | --- |
| 一期 | Markdown 悬停与嵌入，内部明确使用 Reading 视图且禁用写入；全文、标题章节、块引用 |
| 1.5 期 | 递归，以及表格单元格、文字混排、列表／引用容器内的嵌入 |
| 二期 | 悬停与嵌入内部的 Live 编辑，修改归属目标文档 |
| 三期 | PDF 预览与嵌入，具体渲染器与定位能力另行细化 |

父文档 Live／Reading 是展示环境，引用内容 Reading／Live 是内部视图模式，两者独立。一期父文档为 Live 时，嵌入内部仍是 Reading，不能称为“只读 Live”。

一期不包含：引用内容写入、递归展开、多层悬停浮窗、固定／拖动浮窗、PDF、其他附件新渲染器及混排嵌入。现有 Markdown 内容里的图片、公式、代码和图表仍复用既有阅读能力；不由本规格扩展它们的语法范围。

## 一期交互契约

### 悬停与键盘预览

- 正文双链、本地 Markdown 普通链接、反链／出链面板均支持预览；外部网页不接入本功能。
- 父文档 Live 默认 Ctrl+悬停，插件自有设置页可开启直接悬停；Reading 和反链／出链面板直接悬停，面板不随正文模式改变触发规则。
- 登记“预览当前链接”可绑定操作，默认未绑定。Live 以光标处的合法普通链接／双链为目标；Reading／面板以键盘聚焦链接为目标。原生源码编辑器不接管。
- 键盘命令是手动打开悬停浮层，不是光标进入链接就自动弹出。`![[…]]` 已有常驻嵌入内容，不再通过此命令生成重复浮层。
- 鼠标悬停不抢焦点；键盘打开时进入浮层，Esc 关闭后返回触发处。焦点在浮层内部时不能仅因鼠标离开而销毁键盘操作现场。
- 移入浮层后保活，可滚动和复制；鼠标离开链接与浮层后延迟关闭。面板销毁、切模式等使触发上下文失效时释放实例；异步迟到响应不得重开已关闭浮层。
- 一次显示一个浮层，内部链接可点击跳转，不再次叠加悬停窗口。
- 默认宽 480px、最大高度 400px；靠近边缘翻转，空间不足时收缩并约束在可用视口内。窗口缩放、内容变高后重新定位。

### 正文嵌入与源码显隐

- 一期支持独占正文一行的 `![[…]]`，沿用双链目标内部语法，可引用全文、标题或块。围栏／行内代码内的字面文本不作为嵌入。
- 混排、列表／引用容器及表格格内暂保留源文，1.5 期接入。首期限制只属于挂载适配，不得写死进目标解析和内容服务。
- 外观采用用户截图标注：左侧引用块样式边条，顶部文件名，右上角跳转目标文档入口。具体字体与颜色随主题，不逐像素复制截图。
- 短内容自然高度；长内容内部滚动，默认最大高度 480px，可在自有设置页调整。尺寸为实施初值，视觉验收可校准。
- 父文档 Live 中，光标／选区触及引用源码区间则显形，离开则隐藏，不设置“编辑引用”按钮。源码显形时下方 Reading 内容继续显示。
- 显隐采用已有 `selectionTouchesRange` 语义：折叠光标命中区间内部或两端；非空选区与区间严格重叠；任一 CM6 选区命中即显形。不扩大到任意相邻行。
- Reading 内部选字属于浏览器文本选区，不能被误当作父文档 CM6 源码选区；点击内容不能导致父文档错误编辑、菜单操作或写回。
- 源码未闭合时保留可编辑原文并撤下旧目标内容；完整但目标文件／锚点缺失时就地提示。修正或目标恢复后自动重新加载，不自动创建文档，不以全文代替缺失章节。
- 右上角入口与内部链接复用现有 Vsidian 打开和锚点定位行为；打开新目标不修改引用原文。

### Reading 内容、属性与刷新

- 任务框不可修改，frontmatter 无添加／删除／编辑入口。选字复制、滚动、属性折叠及跳转均不写文档。
- 全文引用保留“笔记属性”区。标题整行是悬停热区，悬停显示展开／折叠按钮，点击按钮切换；不是悬停自动展开。按钮键盘聚焦时也显示，Enter／Space 可操作。
- 属性区默认折叠，本次打开内保留展开状态，刷新不重置；重新打开恢复折叠。无 frontmatter 不显示标题行，章节／块引用不额外附带属性区。
- 属性支持类型与非法内容降级沿用现有 frontmatter 能力；截图中的更多类型及写操作不构成扩展要求，不静默丢弃不支持的原文。
- 跟随目标文档未保存修改：以宿主已收到的内容为准，短暂合并刷新，不等待保存。不承诺尚未送达宿主的前端输入已经可见。
- 刷新尽量保持滚动位置，目标范围变化时重新定位；内容缩短时合法钳制。目标引用改变视为新目标，不继续把旧内容显示成新目标。
- 引用内容沿用当前 Vsidian 主题及已启用 CSS 片段，增加悬停／嵌入专属样式入口；不为每份目标文档创建独立主题环境。

### 一层展开的含义

A 嵌入 B：显示 B；B 内的 `![[C]]` 只显示可打开的引用占位，不显示 C 正文。占位目标按 B 的目录解析。单独打开 B 后，C 相对新主文档 B 成为第一层，可正常显示。

嵌入深度和浮层叠加是两个维度。1.5 期分别设计递归预算与多层交互，不能用全局 visited 集合禁止合法重复引用。

## 通用架构与接口责任

### 分层

| 层 | 责任 | 不负责 |
| --- | --- | --- |
| 文档访问 | 目标解析、带版本正文、范围定位、资源上下文、更新订阅与释放 | 视图布局和编辑输入 |
| 内容视图 | Reading 渲染；未来按类型接入 Live、PDF；管理内部滚动与状态 | 判定自己放在浮层还是表格格内 |
| 展示容器 | 悬停定位／保活、嵌入挂载与高度；提供可用空间和生命周期 | 直接读取文件或写目标正文 |
| 编辑能力（二期） | 版本校验、范围映射、目标文档写回与同步 | 成为只读访问的依赖 |

只读视图不获得写入端口。未来 Live 可按可见实例创建独立 CM6 EditorView，共享目标文档内容服务，各自拥有选区和滚动状态；不创建独立 WebviewPanel 承载每个引用。

### 文档访问与消息约束

- 请求关联来源文档、父引用区间、引用原文、视图实例标识及请求代次；宿主按已绑定面板上下文校验，不信任前端任意 URI。
- 结果携带规范目标身份、目标版本、语义范围选择器、LF UTF-16 源范围和内容／解析上下文。不能只返回脱离来源的 HTML。
- 章节取目标标题至下一个同级或更高级标题之前，包含目标标题；匹配沿用现有 ATX、同名取首边界。块范围复用既有块 id 归属逻辑并扩展到完整块，不能拿块首行当完整正文。
- 保留全文解析上下文再选取目标范围，避免章节外的引用式链接定义丢失；不要孤立解析截取字符串。
- A 引用 B 时，B 内部链接和图片以 B 为来源；图片资源经宿主现有路径边界与 webview URI 机制加载。
- 使用 ADR-0008 的根内相对路径语义；不恢复 ADR-0002 的 basename 搜索或候选选择。索引不保存全文，不作为正文事实源。
- 订阅覆盖宿主文档修改与相关文件变化；版本变更使缓存失效。请求代次和内容版本分别校验，旧响应不能覆盖新目标或更新版本。
- 缓存有容量／内存限制，按规范目标、版本、范围、渲染选项区分；相同目标合并读取，实例订阅独立释放。DOM、文档解析和资源缓存分别计量。
- 错误至少区分文件缺失、锚点缺失、越界／不支持、读取失败与取消。就地 i18n 呈现，不连续弹宿主通知；确认删除后不无限保留旧内容。
- 更新共享消息协议及运行期校验；只读引用消息不进入父文档 edit.request 通道。二期再设计目标文档编辑路由。

### 后续阶段预留

1.5 期：引用识别保留父容器上下文，顶层块、混排、列表／引用容器、表格单元格各自适配挂载。父引用区间与目标源范围分开；表格转义、焦点和宽度不借用顶层块假设。递归沿展开路径记录目标与范围，独立限制深度、实例数及字节预算。

二期：必须另行细化现有文档会话多视图接入、带版本编辑、冲突、范围变化、撤销与保存归属、焦点与快捷键隔离。接口预留不等于这些问题已经实现。

三期：文件类型选择渲染器，PDF 不是先转 Markdown，也不要求复制一个已打开窗口的画面。引擎选型、页码与区域定位另议。

### 验证策略

- TDD：先固定范围选择、LF／CRLF、版本竞态、根边界、来源解析、源码显隐、只读能力的失败用例，再实现。
- 浏览器测试驱动生产控制器验证真实指针、键盘、IME、文本选择、嵌入高度变化与四边避障；视觉断言检查实际绘制，不能只查 DOM 存在或坐标。
- 真宿主覆盖跨文档未保存修改、外部变化、打开／锚点、面板重建、零 dirty／零写回及设置持久化。优先现有宿主与浏览器测试入口，不为每个内部函数新造 mock 框架。
- 性能分别测读取、解析、DOM、缓存：长目标、大量重复引用、快速切换目标与重复开关浮层。首期无性能实测，不宣称已满足某个数字阈值；报告须证明回收有效与编辑不发生明显阻塞。
- 修改前按 style-contract 固定旧契约；新增样式入口、i18n、快捷键注册、设置页回显、索引／rename 与文件树检查均进入完成条件。
- 执行 compile、适用单测、浏览器及真宿主回归；长命令首次落盘输出与退出码，复核消费报告。人工鼠标、观感与 Remote SSH 验收另行记录，自动化不代替用户验收。

一期边界核对结论（#225）：递归展开、混排/列表/引用/表格容器内嵌入、引用内容 Live 编辑与 PDF 均未提前实现（嵌入内容视图无 EditorView 创建点；文档访问层仅接 Markdown 并以 non-markdown 分态拒绝；嵌入扫描器与挂载适配按容器无关分层保留 1.5 期接入面）；所有引用内容 Reading 禁写（任务 checkbox 禁用、frontmatter 无编辑入口、只读消息不进 edit.request 通道——各票集成用例以双零 dirty 与零 applyEdit 钉住）。

## 外部参照与证据边界

- [Obsidian Page preview](https://help.obsidian.md/plugins/page-preview)：交互参照，不用于断言闭源实现。
- [Obsidian Embed files](https://help.obsidian.md/embeds)：笔记／局部引用与 PDF 能力参照。
- [Obsidian 公开 API](https://github.com/obsidianmd/obsidian-api/blob/master/obsidian.d.ts)：提供指定容器与 sourcePath 的 Markdown 渲染接口，不证明全部内置嵌入均走此接口。
- [PDF++](https://github.com/RyotaUshio/obsidian-pdf-plus) 与 [PDF.js](https://mozilla.github.io/pdf.js/examples/)：PDF 查看器扩展与独立页渲染的技术参照，不等于三期已选定依赖版本。
- [VS Code Webview API](https://code.visualstudio.com/api/extension-guides/webview#loading-local-content)：本地资源与容器生命周期边界。
