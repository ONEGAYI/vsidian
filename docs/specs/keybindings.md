# 快捷键操作清单与默认值（#91）

快捷键定义在 `src/shared/keybindings.ts`。设置页从该注册表生成操作列表，宿主命令与编辑器分发使用同一操作 ID。表中的「无」表示首次安装不占用按键；用户清空后会存成显式空数组，后续默认值变化也不会覆盖这项选择。除粗体、标题和查找习惯外，其余默认值是本轮的实施取舍，并非用户逐项指定。

| 操作 | 生效模式 | 默认绑定 |
| --- | --- | --- |
| 粗体 | Live | Ctrl+B |
| 斜体 | Live | Ctrl+I |
| 删除线、高亮（#105，默认未绑定，仅 Live 正文生效）、行内代码 | Live | 无 |
| 取消标题 | Live | Ctrl+0 |
| 一级至六级标题 | Live | Ctrl+1 至 Ctrl+6，逐级对应 |
| 无序列表、有序列表、任务列表、引用 | Live | 无 |
| 代码块、链接、清除行内格式 | Live | 无 |
| 插入行内公式、块级公式、双链 | Live | 无 |
| 插入分割线（#106） | Live | 无 |
| 创建表格；上方/下方插入行；删除行 | Live | 无 |
| 左侧/右侧插入列；删除列 | Live | 无 |
| 查找 | Live、阅读 | Ctrl+F / Cmd+F |
| 下一个/上一个查找结果 | Live、阅读 | F3 / Shift+F3 |
| 切换视图；转阅读；转 Live；转源码 | 双模式、Live、阅读、双模式，依次对应 | 无 |
| 打开设置 | Live、阅读 | 无 |
| CSS 片段重新加载（#128） | Live、阅读 | 无 |
| CSS 片段暂停全部；CSS 片段恢复（#131） | Live、阅读 | 无 |
| 打开样式参考（#132） | Live、阅读 | 无 |
| 导出样式参考 JSON（#145） | Live、阅读 | 无 |
| 展开/收起右侧栏；显示/隐藏大纲 | Live、阅读 | 无 |
| 搜索大纲标题；跳转到笔记末尾；重置大纲 | Live、阅读 | 无 |
| 折叠全部大纲；展开全部大纲 | Live、阅读 | 无 |

**作用域**：写操作只在可编辑的 Live 正文获得焦点时拦截按键。阅读容器可执行只读视图操作；查找输入框仅允许只读操作；源码编辑器和设置页输入不装配正文按键路由。模式切换、失焦、超时（1.2 秒）或 Escape 会取消待输入的两段键。内部冲突包含完全相同的键位，以及重叠模式中的单段键与两段键首段；模式互斥时可复用键位。

**未注册为通用快捷键的情境动作**：任务勾选、链接激活、图片点击、表格单元格/区域点击、大纲条目点击与折叠箭头、条目右键菜单（复制、重命名、调级、删除等）及拖拽依赖用户当时指向的具体元素。当前没有可由正文焦点唯一推导的目标；直接绑定会对错误条目执行写入。大纲当前控制域高亮是滚动/定位后的自动状态，不存在独立按钮动作。它们保留鼠标及原有键盘可达控件入口。后续若新增明确的目标选择语义，应逐项按 `AGENTS.md` 重新评估快捷键入口、默认值和生效模式。

**「打开样式参考」注册为全局命令、默认未绑定（#132 评估结论）**
**「导出样式参考 JSON」注册为全局命令、默认未绑定（#145 评估结论）**：只读操作（把随 VSIX 分发的机器可读契约清单 `media/style-reference/style-reference.json` 经另存为对话框导出到用户路径——不写文档、不依赖任何打开的编辑器面板），双模式可用（`mode: both`、`writes: false`）。设置页「样式参考」分页工具区的「导出 JSON」按钮经 `styleRef.export` 消息走同一实现；命令面向命令面板/脚本化场景（无需先打开设置页）。默认不占键位，用户可按需绑定。：只读视图操作（打开设置页并定位「样式参考」分页——离线查阅公开样式契约与 Obsidian 原名兼容等级），双模式可用（`mode: both`、`writes: false`）；设置页分页入口常驻，命令面向命令面板/快捷键直达场景，默认不占键位，用户可按需绑定。与「打开设置」同形态登记于 extra 表。

**「打开 CSS 片段设置」未单列命令（#128 评估结论）**：片段管理页经「打开设置」（双模式、默认未绑定）进入设置页后由左侧导航直达，单独命令只为省一次导航、收益不抵命令面板与快捷键页的条目膨胀；「CSS 片段重新加载」已注册为全局命令（双模式、默认未绑定，只读视图操作——片段可能影响任一模式的界面，命令面板始终可达）。后续若设置页支持直达分页的深链，再评估单列入口。

**CSS 片段暂停/恢复（#131 评估结论）**：「暂停全部」与「恢复」注册为宿主侧全局命令（双模式、默认未绑定、只读视图操作——不写文档，仅翻转持久化的全局冻结标志）。命令在宿主注册，不依赖任何 webview 的健康度：正文工具栏被隐藏、编辑器面板或设置页异常时命令面板仍可救回被片段影响的界面。暂停与逐项停用语义正交：暂停不清逐片段开关，恢复按原配置立即生效。设置页 CSS 片段分页的「暂停全部」按钮与暂停状态条内的「恢复」入口与命令共用同一服务入口（`snippets.setPaused` 消息）。默认不占键位：高频用户可自行绑定。

**情境输入动作（Enter / Backspace，#119 评估结论）**：列表/引用行的 Enter 前缀延续与退格清层是对「光标所在行的结构前缀」的变换——目标由光标位置即时推导（列表项、嵌套层级、引用深度），不是可枚举的固定命令目标，故不注册进快捷键操作清单、不提供用户可改绑定；键位固定为 Enter 与 Backspace，仅 Live 编辑正文生效（表格上下文让位给单元格语义，块级公式内按源码字面编辑不接管；阅读只读、源码走原生编辑器）。处理器装配在 `src/webview/listEditing.ts`，keymap 顺序在 tableEditing 之后、defaultKeymap 之前。

**情境输入动作（Tab / Shift+Tab，#120 评估结论；#125 扩展）**：通用行缩进同属光标位置即时推导的情境变换（受影响行集合与列表行智能对齐宽度均由光标与选区现场决定），不注册进快捷键操作清单、不提供用户可改绑定。键位固定为 Tab（整行缩进一级）与 Shift+Tab（反向），仅 Live 编辑正文生效：列表行一级宽度对齐上方最近项的内容列（CommonMark 口径：父项「标记+一空格」，任务标记属内容不计——无序与任务父项下均 2 格、宽编号有序父项下 4 格；跨族取上方项内容列而非自身标记宽，防止缩进越界脱离列表结构），反向缩进升至树父项标记列（顶级删全部缩进）；普通行（含纯引用行、代码围栏、缩进代码块与块级公式内）固定 2 空格；多光标时各 range 覆盖行取并集缩进（与 Enter/Backspace 的「多光标不接管」口径不同：行集合命令的自然泛化，无破坏性）；表格内保持单元格导航语义优先（边界放行也不缩进表格行）；frontmatter 与 IME 组合中不接管；无可删空白时 Shift+Tab 仍吞键——Tab 族按键放行到默认路径会被宿主 webview 预加载脚本转发为工作台焦点导航（焦点逃逸），键盘焦点移出编辑器的出口相应改为 Esc / 鼠标。处理器装配在 `src/webview/indentEditing.ts`，keymap 顺序在 tableEditing 之后、defaultKeymap 之前；快速操作条等 UI 控件的 Tab 焦点管理不受影响（其 keydown 目标不是编辑器 contentDOM，不经过本 keymap）。

**情境输入动作（围栏内 Tab 越界，#125 评估结论，归 #120 情境输入键口径）**：光标在有效成对围栏内部且无选区时，Tab 先到闭合标记左边界、再按一次越过整个闭合标记（嵌套从最内层逐层退出）——目标由「光标位置 + 当前语法树/行内配对」即时推导，同属无固定命令目标的情境变换，**沿用 #120 结论**：不注册进快捷键操作清单、不提供用户可改绑定，键位即 Tab 本身。有效优先级为**围栏越界 → 表格导航 → 既有正文缩进**（输入法/只读门控先于一切；格内先越界、越出后切格，围栏外不向右搜索）：由 keymap 装配顺序实现——CM6 keymap 按扩展数组顺序**正序**拼接尝试（靠前者先匹配，与 transactionFilter 的逆序相反），`src/webview/fenceEscape.ts` 装配在 tableEditing **之前**，优先级已经 jsdom 真控制器与浏览器真实 Tab 键两层实测（`test/unit/tabEscapeInteraction.test.ts`、`test/browser/symbolInput.mjs`）。Shift+Tab 不新增反向越界（keymap 不绑 shift 槽，落穿保持反向切格/反向缩进）；Tab 命中时派发纯选区事务（零写回零 dirty）。关闭入口为扩展设置页「符号 Tab 越界」开关（`editor.symbolTabEscape`，默认开启，与 #123/#124 相互独立），关闭后 keymap 整组退出装配、Tab 回落既有行为。**后续工单不得把任何命令绑定到 Tab 键**（keybindingRouter 会先于 keymap 拦截并 stopPropagation，破坏上述三段优先级）。

**情境输入动作（符号字符键入与空对 Backspace，#123 评估结论）**：符号自动补全由**键入普通字符**触发（括号/引号起始符补闭合、Markdown 强调触发符在连续串首补对），闭合越过由键入同一闭合符号触发，自动空对删除由空对内 Backspace 触发——三者都是对「光标邻接字符与自动补出来源状态」的即时变换，没有可枚举的固定命令目标，故不注册进快捷键操作清单、不提供用户可改绑定。触发字符集合由符号注册表登记（`src/shared/symbols.ts`，英文尖括号默认不补全）；仅 Live 编辑正文无选区时生效（选区场景归 #124 包裹；表格格区替换语义不改写），阅读只读、源码与设置页输入不装配。关闭入口为扩展设置页「符号自动补全」开关（`editor.symbolAutocomplete`，默认开启），关闭后补全/越过/空对删除三条路径一并停用。Backspace 的空对删除仅认「自动补出且仍为空」的符号对（非自动来源交默认删除），处理器装配在 `src/webview/symbolAutocomplete.ts`，keymap 顺序在 tableEditing 之后、defaultKeymap 之前；补全/越过经 transactionFilter 改写输入事务（一次补全即一笔写回，宿主撤销一次整体恢复），不走独立按键命令。

**情境输入动作（选区包裹字符键入，#124 评估结论）**：选区包裹同样由**键入普通字符**触发（有非空选区时键入注册包裹符号，在选区两侧添加 open/close 并保持原文选中；连续键入叠加标记、跨段按空行拆段分别包裹）——目标由「当前选区 + 键入字符」即时推导，没有可枚举的固定命令目标，故不注册进快捷键操作清单、不提供用户可改绑定。包裹字符集合由符号注册表的 `selectionWrap` 字段逐项显式登记（与补全集合不同源：键入 close 字符不包裹、英文尖括号不包裹）；仅 Live 编辑正文有非空选区时生效（无选区归 #123 补全；代码上下文抑制 Markdown 强调、允许括号引号；表格格区替换语义不改写），粘贴/拖放与 IME 组合链路（选区已被组合替换）不包裹。与格式按钮（快速操作条粗体/斜体等命令）是**不同入口的两种操作**：按钮走两态切换（再次执行取消格式）且按行包裹，字符键入走叠加包裹且按空行拆段，语义不混用。关闭入口为扩展设置页「选区符号包裹」开关（`editor.symbolSelectionWrap`，默认开启，与 #123 相互独立）。处理器装配在 `src/webview/symbolWrap.ts`（transactionFilter 把选区替换事务改写为两侧插入，一次包裹含跨段多块即一笔写回，宿主撤销一次整体恢复），装配顺序在 symbolAutocomplete 之后；跨段包裹后选区为多 range（各段原文），依赖随组装配的 `allowMultipleSelections`。

**外部冲突边界**：VS Code 1.86 稳定扩展 API 无法枚举用户、工作台及其他扩展的全部有效按键规则与 `when` 条件。设置页只检查 Vsidian 内部冲突，不显示「外部无冲突」。如需排查工作台优先级，可使用 VS Code 的「记录键盘快捷方式故障排查」。

**依赖导入与资源拒绝无新增操作（#129 评估结论）**：本票全部为既有片段管理链路的自动行为（@import 依赖归因热更新、越界/符号链接逃逸拒绝与恢复），不引入新的用户可绑定操作——热更新由文件监听自动驱动（「CSS 片段重新加载」仍是手动兜底入口，语义不变）；拒绝与恢复以通知和设置页行内提示呈现，无需按键触发。

**HTTPS 导入与联网字体无新增操作（#130 评估结论）**：本票全部为既有片段链路的浏览器标准能力放开（CSP 放行 https: 样式/字体源、远程引用不进依赖图、字体晚到补测）——无新用户可绑定操作。远程资源的内容刷新沿用「CSS 片段重新加载」（#128，双模式、默认未绑定）手动驱动；断网、CORS 拒绝、HTTP 错误等失败面以既有装载失败提示与备用字体回退呈现，无需按键入口。
