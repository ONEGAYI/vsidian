# PDF 导出

> 状态：2026-10-21 用户已确认三轮产品选择、正式规格与十票拆分并授权发布；[总览 #618](https://github.com/ONEGAYI/vsidian/issues/618)及子票 #619–#628 已建立，功能未实施。本文是 PDF 导出功能的范围与验收事实源，不包含标准 Markdown 导出。

## 1. 目标与范围

在 Vsidian 内配置并自动生成 PDF，默认保留当前阅读模式的主题与正文样式，并适配纸张分页。用户无须打开外部浏览器手动打印。

首期包含四种导出方式：

| 方式 | 输入与结果 |
| --- | --- |
| 当前文档 | 导出当前 Markdown 全文，包含未保存修改，生成一份 PDF |
| 选区 | 严格使用实际选中原文；多个选区按文档顺序分别作为 Markdown 片段渲染，合成一份 PDF |
| 批量 | 从可编辑导出清单逐文件生成 PDF，保留所选目录的相对结构 |
| 合并 | 按可编辑导出清单顺序生成一份 PDF，可选每篇另起一页 |

本地工作区与 Remote SSH 均纳入首期。Remote SSH 的文档和资源在远端读取，本机浏览器生成 PDF，结果保存到本机；跨宿主链路先通过技术验证。

## 2. 已确认的产品契约

### 2.1 内容版本与原文范围

- **准备阶段固定输入**：读取并固定本次各文档内容及阅读样式。已打开文档和 Markdown 嵌入目标使用未保存内容；尚未打开的文件按现有工作区读取通道取值。生成期间不混入后续编辑，不要求先保存。
- **固定输入的边界**：每个参与文档在准备阶段确定本次使用的版本，不宣称整个目录或远端文件系统在同一瞬间获得事务快照。后续刷新预览或重新开始导出形成新一轮输入，不复用上一轮未完成的结果。
- **选区不自动扩大**：不补入选区外的段落、表格行或围栏。半段语法按所选片段独立解析后的真实结果呈现，不暗中补齐原文。
- **多选区分别渲染**：按文档顺序组合各片段，片段之间不因直接拼接而产生新的 Markdown 语法。资源仍以原文档身份解析，不改用导出目录作为相对路径基准。
- 导出不修改源文、不新增正文撤销记录，不因导出触发强制保存。

### 2.2 导出清单

- 支持选择文件和目录；目录递归收集 Markdown，清单显示文件身份及顺序。
- 导出前可增删清单条目并调整顺序。批量逐文件输出，合并严格按清单顺序输出，不依赖文件枚举顺序决定最终结果。
- 文件身份、Markdown 类型与路径处理复用现有事实源。输出路径冲突先呈现实际映射，再统一选择跳过、覆盖或自动更名；不静默覆盖。
- 批量保留所选目录的相对结构；多个选择根的同名映射也进入冲突处理，不无说明地丢文件或覆盖其他根的产物。

### 2.3 正文、样式与嵌入

- 复用现有 Reading 解析、内容节点构建、净化、文档样式作用域与资源解析语义，另行装配完整导出正文。不得读取当前视口 DOM 冒充全文，也不把日常阅读改成全文 DOM 常驻。
- 默认跟随当前阅读主题、正文样式和 CSS 片段；文档内样式继续按所属文档作用域生效，合并时不得跨篇污染。纸张分页样式单独负责页边距、分页和页眉页脚等布局。
- Markdown 嵌入沿已有目标解析与范围规则展开；嵌入自己的未保存内容、样式和相对资源归属保持。循环引用与既有不支持边界不得借导出顺手放宽。
- 图片正常呈现；公式、图形化代码块、原生 HTML 与已支持的正文样式沿既有能力输出，不以整页截图代替文本排版。
- PDF、音视频和 iframe 使用静态说明与可点击链接，不承诺把 PDF 页面、视频帧或网页截图嵌入正文。说明与链接必须指向真实目标；不能将远端路径伪装成可在本机打开的文件地址。
- 资源缺失或失败须列出具体项目和原因，由用户选择继续或取消。选择继续时保留可见说明，不能留下无提示的空白。
- 不新增执行文档脚本或事件属性的权限，不因导出扩大已有资源授权面或绕过 HTML 净化。

### 2.4 导出模态与排版

参考 Better Export PDF 的“主要区域预览、侧区配置”布局组织信息；文件清单、参数与 PDF 预览在同一模态内完成。采用 Vsidian 现有变量与 UI 档位，不复制 Obsidian 的固定尺寸和颜色。

首期参数包含纸张尺寸、横纵方向、页边距、缩放、页码、页眉页脚、标题生成的 PDF 书签，以及合并时每篇另起一页。具体数值范围由真实后端能力约束并验证，不在未经验证时写死不支持的尺寸。

预览行为：

- 显示实际生成 PDF 的页面预览，不以普通 HTML 预览冒充 PDF 分页结果。
- 参数或清单改变后标记预览过期，由用户手动刷新；不因每次控件输入反复启动生成任务。
- 过期预览不能被当作当前配置的最终产物。最终导出使用与当次参数、清单和固定输入对应的结果；新旧任务以真实代次区分。
- 复用已有 PDF 阅读渲染引擎评估预览，不因此升级 PDF.js 或重新设计一套 PDF 阅读 UI。

功能入口及快捷键在实施票中统一登记。当前文档、选区、批量、合并入口均须评估可绑定操作、默认绑定与模式；默认可不绑定，源码模式与设置页输入不被正文写操作覆盖。导出是只读操作。

模态是本次导出参数的界面；需要持久化的默认参数或浏览器路径等设置只进入 Vsidian 自有设置页，并验证重新打开后的回显与生效。

### 2.5 任务结果与释放

- 浏览器缺失时提示配置已安装的 Chrome／Edge，不自动下载专用引擎。
- 批量单项失败继续其他项目，结束后汇总完成、失败、跳过及其真实输出路径；失败项可据清单重新发起，不伪称整批成功。
- 取消后保留已完成文件，停止尚未完成的工作并清理临时资源；未完成产物不得伪装成成功 PDF，也不能破坏被选择覆盖的已有有效文件。
- 关闭模态、取消、刷新预览和任务失败均配对释放本次创建的页面／进程、预览、Blob、临时文件、监听器与订阅。不终止用户原有浏览器会话。
- 进度及完成状态按实际阶段和文件计数呈现，不编造整体百分比或完成结果。

## 3. 技术方向与必须验证的接缝

浏览器依赖与运行侧决定见 [ADR-0021](../adr/0021-pdf-export-installed-browser.md)。浏览器控制库、跨宿主传输和资源打包方式尚未锁定，必须在前置验证票中以最小端到端探针确定。

### 3.1 本机浏览器与最低宿主

- 在 Windows VSCode 1.82.3 与宿主 Node 18 下验证已安装 Chrome／Edge 的调用，输出含中文、样式、图片、字体和多页正文的有效 PDF。
- 当前开发用 Playwright 1.62.1 要求 Node >=20，不能直接提升为生产依赖；PDF.js 负责阅读，pdf-lib 当前用于测试样本，均不代表已有生产导出后端。
- 验证资源、字体和图形渲染的明确完成信号。不得把固定延迟或 DOM 静默时间当作“所有资源已就绪”的通用保证。
- 验证页眉页脚、纸张参数、书签及预览产物所需接口、资源释放与打包方式，再锁精确依赖和许可。

### 3.2 Remote SSH 到本机

- 当前扩展是 workspace 运行侧。远端扩展宿主不能被假定具有本机进程与文件系统访问能力。
- 最小探针须实际证明远端正文／资源到达本机、本机浏览器执行与本机保存；明确本机执行端如何分发、发现、调用与升级，以及用户需要完成的配置。
- 不允许以远端生成、远端保存或要求远端安装浏览器替换用户已确认的行为，也不能仅凭两个端点分别可用就宣称跨宿主闭环已经通过。
- 不为导出将整个 Vsidian 从 workspace 改成 ui 运行侧。若可行路线需要新增分发单元或其他重要约束，拿证据返回方案讨论。

### 3.3 可复用入口

| 责任 | 当前入口 |
| --- | --- |
| 权威文档与未保存内容 | `src/host/documentSession.ts`、`textEditorProvider.ts` 与现有引用内容访问入口 |
| 阅读块与完整正文节点 | `src/webview/readingBlocks.ts`、`readingView.ts`；日常虚拟化仍在 `readingVirtualView.ts` |
| 图片和原生 HTML 资源 | `imageResource.ts`、`htmlResourceMount.ts` 与宿主已有解析通道 |
| 图形渲染结果 | `graphicRenderers.ts` 的 `renderSvg`、`mermaidRender.ts` 的共享缓存与渲染队列 |
| 文档样式 | `src/shared/docStyle.ts`、`src/webview/docStyleLoader.ts` |
| PDF 页面预览 | `src/webview/pdfRender.ts` 与既有 PDF 内容视图／资源生命周期 |
| 操作、文案与设置 | `src/shared/keybindings.ts`、locales、settings 及自有设置页 |

以上是复用方向，不代表这些模块已经提供完整导出接口。新增接线不得复制第二套路径解析、文档样式收集或附加组件公开 API。

## 4. 验收场景

| 场景 | 可观察结果 |
| --- | --- |
| 长文档首、中、末段 | 输出 PDF 中均有真实正文；不受当前滚动位置、正文折叠与视口回收影响 |
| 未保存正文与嵌入目标 | 输出对应准备阶段固定内容；生成期间继续编辑不混入、不保存或修改源文 |
| 单选区与多选区 | 不扩大范围，半段语法按片段解析；多段按原顺序出现且不拼接出新语法 |
| Markdown 嵌入、图片与图形 | 正文和资源来自正确文档；异步结果完成后输出，文本可提取 |
| PDF、音视频、iframe 与缺资源 | 静态说明、真实链接及缺失项列表可见；继续或取消符合用户选择 |
| 不同文档样式合并 | 顺序与每篇分页选项正确；正文样式不跨篇污染，书签对应实际标题 |
| 批量重名、失败与取消 | 不静默覆盖，结果清单真实；取消保留已完成项且无未完成伪产物 |
| 模态预览与重复刷新 | 预览来自真实 PDF；过期状态和当前参数匹配；旧任务不覆盖新结果 |
| 明暗与自定义阅读样式 | PDF 反映准备阶段阅读样式；模态控件自身符合 Vsidian UI 档位 |
| Remote SSH | 远端正文和资源正确，本机浏览器生成，文件真实保存到本机 |
| 关闭与重复执行 | 本次任务资源回收，用户浏览器会话及原编辑文档不受损 |

验证同时检查 PDF 的页数、文本与书签结构，并渲染页面检查首中末段、图片／图形、分页和样式。不能只检查 PDF 文件存在或 DOM 节点存在。

## 6. 各票共同完成条件

- 可执行行为遵循 TDD；选择与本票风险相称的单元、browser、真实宿主与产物检查，并记录未执行环境。纯文档规划不运行功能全量回归。
- UI／渲染变更执行项目 ui-patterns 与 style-contract；至少一条断言落绘制层，关键 CSS 规则由契约钉住。新形态在实施时同步目录，不为未实现的设想预写 UI 模式。
- 用户文字经 locales／t()；涉及持久设置的变更只进 Vsidian 自有设置页。所有新增面向用户操作登记快捷键入口、默认值与有效范围。
- 首次长命令落盘日志和退出码，复核消费已有报告。验证范围按实际输入变化推进，不因提交、推送、建 PR 或合并阶段切换重复跑全量。
- 交付必须区分自动化通过、未验证项和用户验收；不得把规划、探针成功或票关闭写成整个功能已完成。
- 本批建票授权不包含功能代码推送、PR 合并或版本发布；后续按仓库工程规范执行。
