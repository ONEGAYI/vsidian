# 引用视图设置组与跳转目标提示规格

> 状态：2026-10-02 设计访谈定稿（grilling 十问十答），待开票实施。领域术语见 [CONTEXT.md](../../CONTEXT.md)（引用文档视图、引用视图、跳转目标提示）；本规格为设置组改版与目标提示两项需求的单一事实源。

## 问题陈述

- 悬停触发的引用视图浮层没有总开关：唯一相关设置只调节实时预览的触发方式（直接悬停或按住 Ctrl），阅读模式、反链/出链面板与浮层内子引用的悬停触发无法关闭。
- 浮层不出现的悬停场景没有任何反馈：实时预览未按住 Ctrl 时（或上述总开关缺失导致无法构成「关闭后仍想知道目标」的场景），悬停期间不知道链接指向哪里。
- 引用视图族的设置散落：「直接悬停」类开关寄居编辑器页「显示」组，且标题「实时预览中直接悬停链接」脱离上下文读不通；嵌入层级与高度两项同族设置也在「显示」组。

## 方案

设置页编辑器分页新增二级标题组「引用视图」，聚合该族全部设置并补齐两个新开关：总开关一键启停悬停浮层；「跳转目标提示」在浮层不会出现的悬停场景显示目标完整路径。既有「实时预览中直接悬停链接」改名为「实时预览中直接悬停显示」——置于「引用视图」组内自解释，嵌入层级与高度两项迁入同组。

## 用户故事

1. 作为实时预览编辑者，我希望悬停链接但未按住 Ctrl（浮层不会打开）时看到目标位置的提示，以便不弹浮层也能确认链接指向。
2. 作为实时预览编辑者，我希望悬停中补按 Ctrl 浮层弹出时提示立即消失，以便画面不叠加两层信息。
3. 作为阅读模式读者，我希望关闭引用视图总开关后悬停正文链接不再弹出浮层，以便纯阅读不被打断。
4. 作为阅读模式读者，总开关关闭时我希望悬停链接能看到目标路径提示，以便不打开浮层也能获知目标。
5. 作为反链/出链面板使用者，我希望面板条目的悬停同样受总开关管辖、同样适用目标提示，以便正文与面板行为一致。
6. 作为浮层内容浏览者，我希望浮层内子引用的悬停遵循与顶层一致的提示规则，以便跨层级体验统一。
7. 作为引用了图片等非笔记文件的作者，我希望目标提示同样显示其路径，以便提示不只服务于笔记链接。
8. 作为使用锚点链接的作者，我希望提示在路径后按源码形态附加锚点（`#标题` / `#^块id`），以便区分目标文件内的不同位置。
9. 作为多根工作区用户，我希望提示显示目标相对其所属根的完整路径，以便路径口径可预期。
10. 作为设置页使用者，我希望引用视图族设置聚合在一个带图标的标题组内，以便一处找到全部相关开关。
11. 作为升级用户，我希望总开关默认开启、提示开关默认开启，以便升级后既有悬停预览行为不变、新提示直接可用。
12. 作为先前调整过嵌入层级或嵌入高度的用户，我希望两项迁组后取值与回显不变，以便升级零迁移。
13. 作为快速划过正文的读者，我希望提示有与浮层同款的稳定悬停延迟，以便扫过不连闪。
14. 作为键盘用户，我希望 Esc 能关闭提示，以便收尾操作与浮层一致。
15. 作为外部链接的作者，我希望悬停 `http(s)` 链接不出现提示、保持既有行为，以便站内引用与外部链接区分。
16. 作为不想要提示的用户，我希望关闭提示开关后悬停恢复无提示原状，以便退出干净彻底。
17. 作为辅助技术用户，我希望新组图标保持纯装饰、组名可感知，以便屏幕阅读器正常朗读分组。
18. 作为想彻底停用悬停预览的用户，我希望总开关连「预览当前链接」键盘命令一并关闭，以便一个开关关干净、无需再去解绑命令或快捷键。

## 实施决策

### 设置项与分组

- 新增布尔设置 `hover.enabled`（总开关「悬停预览引用文档」，默认开启）：语义为悬停触发引用视图浮层的总启停。
- 新增布尔设置 `hover.targetTip`（「悬停显示跳转目标」，默认开启）：控制跳转目标提示。**独立于总开关**，不登记设置项依赖（`dependsOn`）——总开关关闭时提示反而成为悬停的唯一反馈，不应随之灰化。
- `hover.liveDirect` 标题改为「实时预览中直接悬停显示」（英文同步）；描述必须重写——现描述「阅读模式与反链/出链面板不受影响，始终直接悬停」在总开关存在后不再成立。
- `embed.maxDepth` 与 `embed.maxHeight` 自「显示」组迁入「引用视图」组：纯位置移动，取值、范围与生效行为不变，设置值零迁移。
- 编辑器分页新增二级标题组「引用视图」，组内顺序：总开关 → 实时预览中直接悬停显示 → 悬停显示跳转目标 → 嵌入笔记展开层级 → 嵌入内容最大高度。分组归属规则中 `hover.*` 与 `embed.*` 前缀改归新组，注册表与分组过滤处钉住归属的注释同步修订。
- 新组图标 key 与接线一次到位，图标 path 数据暂以现有图标占位（用户后续补充正式图标时仅替换数据，不再动接线）；图标纯装饰（aria-hidden），组名经语言包词条提供。

### 总开关行为

- `hover.enabled` 关闭时，**浮层的全部触发入口均不打开**：悬停路径（阅读模式正文、反链/出链面板、实时预览直接悬停与按住 Ctrl 两条触发路、悬停浮层内的子引用、「悬停中补按 Ctrl」补触发）与「预览当前链接」键盘命令入口。键盘命令被拦时静默执行不误开（与该命令「无目标静默不误开」的既有形态一致），不弹任何提示。（2026-10-02 用户裁定扩权：彻底关闭应一个开关关净，豁免键盘命令不满足「完全关掉」诉求，弃用先前的豁免口径。）
- 正文嵌入卡片（`![[…]]` 常驻呈现）**不受总开关影响**——嵌入是作者显式写进正文的结构，其规模控制归「嵌入笔记展开层级」。
- 浮层既有的消失语义（Esc、点击跳转、滚动、失焦等）不变；总开关只管辖「出现」。

### 跳转目标提示行为

出现需同时满足四个条件：

1. `hover.targetTip` 开启；
2. 悬停目标在覆盖面内（见下）；
3. 稳定悬停满与浮层进入同款的延迟时长（300ms 量级，复用既有悬停计时常量口径）；
4. 本次悬停**不会打开浮层**——判定统一按「浮层是否将出现」：实时预览门控未通过（总开关开且直接悬停关且未按 Ctrl）、总开关关闭、或目标不可展开为浮层（如指向图片等非文档文件的引用），均视为不出现。

| 场景（提示开关开启时） | 浮层 | 目标提示 |
| --- | --- | --- |
| 实时预览，总开关开、直接悬停开 | 稳定悬停后开 | 不出 |
| 实时预览，总开关开、直接悬停关、未按 Ctrl | 不开 | 出 |
| 同上，悬停中补按 Ctrl | 补触发开 | 立即消失 |
| 阅读 / 面板 / 浮层内子引用，总开关开 | 稳定悬停后开 | 不出 |
| 指向图片等不可展开目标的引用，总开关开 | 不开 | 出 |
| 任意路径，总开关关 | 不开 | 出 |
| 任意路径，提示开关关 | 按上各行 | 不出 |

消失触发：浮层打开（含补按 Ctrl 的补触发路径）、指针离开悬停目标、Esc、目标脱离文档树（视口虚拟化回收）。

**覆盖面**：实时预览渲染态链接族（双链、树驱动链接、宽松链接）、阅读模式正文锚点、反链/出链面板条目、悬停浮层内子引用。**排除**：正文嵌入卡片（自身已是开幕的引用视图，无「出现前」空档）、外部 scheme 链接（与浮层入口的预滤同口径，「引用」限定工作区内目标）。

**内容口径**：解析后目标的完整路径——相对其所属根；无工作区的单文件场景相对当前文件目录；本文件锚点同样带完整路径，规则不特判。有锚点时按源码形态附加（`路径.md#标题`、`路径.md#^块id`）。目标解析失败不出提示。

### 实现形态

- 基于**统一自绘悬停提示体系**（`tooltipCard`，#300 落地、PR #301 合入）实现：复用统一小卡片组件与几何模块，不另建独立提示组件；原生 `title` 属性禁用（仓内契约防回潮）。提示的显示延迟、Esc 与定位行为以统一提示规格为准对齐，「稳定悬停后出现」的语义锚点是「提示只在浮层不将现时出现」。（原「自建并预留与规范化对齐」的约束已因统一体系落地而兑现为直接复用。）
- **不进弹窗互斥锁**——行为矩阵已保证「浮层开则提示关」，无需互斥协调；提示关闭逻辑挂在浮层打开路径上。
- 若需为提示场景登记统一体系的新变体或类名，走 style-contract 技能流程（`npm run check:stylecontract` 门禁与基线复验）。
- 全部用户可见文字（组名、设置标题与描述）经语言包双语新增/修改，键集 parity 由既有编译期与运行期门禁把关。

## 测试决策

- 好测试只测外部行为：悬停时序矩阵逐行、提示出现/消失触发、设置分组呈现与回显、门控组合下的浮层有无——不测内部 DOM 构造细节。
- 复用现有 seam，不新建：
  - 单元（vitest + jsdom）：设置注册表与分组归属断言、悬停门控纯逻辑组合、语言包 parity；
  - 设置页分节 jsdom 测试先例：新组挂载、组内顺序、开关回显与持久化；
  - 浏览器（Playwright 生产控制器）：真悬停驱动 300ms 级时序——提示出现、浮层将现不出、补按 Ctrl 即消、Esc/离场消失；按「视觉层断言」约定，提示可见性与内容至少一条断言落在绘制层；
  - style-contract 契约测试钉住新增 CSS 关键规则。
- 遵循 TDD：先以契约测试钉住上述行为矩阵，再实现。

## 明确不包含

- 正文嵌入卡片上的目标提示（排除口径见覆盖面）。
- 外部 `http(s)` 链接的提示。
- tooltip 统一提示体系的组件建设（#300 已另行落地，本规格只消费该体系）。
- 悬停延迟时长可配置化。
- 浮层内多层提示叠加（浮窗始终一次一个的既有边界不变）。
- 嵌入卡片呈现随总开关启停（明确不受影响）。
