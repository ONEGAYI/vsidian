# 设置页视觉刷新规格：独立滚动、分组容器与快捷键页重做

> 状态：已评审（grilling 八问收敛），实施中。需求留痕见 [ONEGAYI/vsidian#155](https://github.com/ONEGAYI/vsidian/issues/155)。
> 术语增量已录入 [CONTEXT.md](../../CONTEXT.md)（键位捕获签、设置页容器语言）。

## 背景与问题

当前设置页（`Vsidian 设置` 面板）存在三类观感与交互问题：

1. **单滚动轴**：整页只有 webview body 一个滚动条，侧栏导航与正文同步滚动；
   内容较长时侧栏滚出视野（「滚动出界」），导航失效。
2. **缺乏容器层级**：条目以分割线平铺，无分组容器的视觉聚合；与 Obsidian
   设置页的「分组容器 + 底色差」观感差距明显。
3. **快捷键页布局混乱**：每个操作竖向堆叠四行（标题行 / 键位牌行 / 三个文本
   按钮行 / 录制输入行），分行怪异、录制条与相邻分割线边界不明。

参考基准：Obsidian 1.13.7 设置页（独立双滚动、分组容器）与快捷键设置页
（筛选签、单行布局、就地捕获）。

## 术语

- **设置页容器语言**：本规格确立的设置页呈现约定，见 CONTEXT.md 词条。
- **分组容器**：把同一分组的设置条目聚合为一块的圆角容器，底色与页面正文
  形成色差。
- **筛选签**：快捷键页顶部的过滤按钮组（冲突 / 全部 / 已分配 / 由我分配 /
  未分配），单选生效。
- **键位捕获签**：快捷键行内就地录制键位的控件，见 CONTEXT.md 词条。

## 需求与设计

### 1. 独立滚动骨架

- 外层 `.vsidian-settings` 锁定视口高度（`100%` 高度链：html/body/#app → 根），
  自身不滚动。
- **侧栏与主区各自 `overflow-y: auto`**：两列各自出现自己的滚动条，互不带动；
  侧栏项目少时无滚动条，属预期。
- 主区滚动位置在切换分页时重置到顶部。
- 窄屏（<600px）维持现有退化：侧栏折叠到顶部横排，此时恢复整页单滚动。

### 2. 分组容器与色差（全分页统一）

- **适用范围**：常规 / 编辑器的条目按组包进分组容器；快捷键行列表、CSS 片段
  列表、样式参考条目区套用同一容器语言（圆角、色差底、内边距），替换分割线
  平铺风格。
- **色差实现基调**：基于正文背景的半透明前景叠加（`color-mix(in srgb,
  前景色 x%, 正文背景)`），对任意主题（含用户自定义主题）自适应。实现时以
  CSS 变量收敛色差取值，便于人工验收时在候选变量族（语义控件底色、侧栏底色、
  半透明叠加）间快速切换。
- 搜索结果页的结果卡片同步纳入容器语言。
- 样式参考分页保留其既有二级布局（类目栏 + 条目表 + 分页），仅外层间距与
  容器观感对齐，不重排其内部结构。

### 3. 布尔控件换拨动开关

- boolean 设置项渲染为滑块式拨动开关（Obsidian 观感）。
- **纯 CSS 实现**：保留 `<input type="checkbox">` 语义与既有类名，仅外观切换
  （`appearance: none` 自绘轨道与滑块）；键盘可达（Tab 聚焦、空格切换）与
  数据行为不变。
- 明暗主题下开关的开态使用主题强调色（focusBorder 族）。

### 4. 快捷键页重做（对齐 Obsidian）

#### 工具行

- **单搜索框 + 键盘图标切换**：一个搜索框承担两种过滤维度——文字模式按操作
  名过滤；点击框内键盘图标进入按键捕获模式（图标呈激活态），就地按键录制
  过滤键位，再次点击或 Esc 退回文字模式。
- 「全部恢复默认」按钮置于搜索框右侧。
- 状态行（保存中 / 已保存 / 冲突提示）保留。

#### 筛选签

- 单选按钮组：`冲突 (N)` / 全部 / 已分配 / 由我分配 / 未分配；默认「全部」。
- 语义（全部落在共享纯逻辑，可单测）：
  - **冲突**：当前生效键位与其他操作（生效模式有交叠）发生键位重叠的操作，
    签上计数为这类操作的个数；
  - **已分配**：生效键位非空；**未分配**：生效键位为空；
  - **由我分配**：overrides 中显式登记的操作（含显式清空——空数组=明确禁用，
    与存储语义一致）。

#### 行布局

- 每操作一行：左侧操作名 + 生效模式说明；右侧依次为键位牌组、更多操作菜单、
  添加按钮。
- **键位牌**：`kbd` 样式圆角牌 + 牌上 × 移除（现行为保留）。
- **更多操作菜单（⋯）**：收纳「清空绑定」「恢复默认」两项（原第三行文本
  按钮退位）；点击展开行内菜单，点击别处或再点 ⋯ 收起。
- **添加（＋）**：未捕获态显示 ＋；点击后 **＋ 原位变为 ✓（提交）**，同时
  行内键位牌区末尾出现键位捕获签（占位「按下快捷键…」，激活态描边）。

#### 键位捕获签交互

- 就地捕获键盘输入，支持单段或连续两段键位（沿用现有录制器状态机：
  每段更新草稿显示，两段满后草稿定型）。
- **提交**：Enter 或点击行尾 ✓（✓ 在草稿为空时禁用）。
- **取消**：Esc 或捕获签失焦（失焦目标为 ✓ 时不算取消——以 relatedTarget
  区分，防「点提交先失焦」误取消）。
- 提交后捕获签收回为 ＋，新键位牌入列；取消则草稿丢弃。
- 冲突：沿用现模型——提交触发冲突时行内警示条（含「替换原键位」按钮）保留，
  仅按容器语言重样式。

#### 行为保持（不顺手改变）

- `focusEntry` 全局搜索定位：点击搜索结果落入快捷键页时，仍定位到对应行并
  聚焦捕获签。
- 数据模型、存储格式、宿主协议（`keybindings.*` 消息）、冲突判定与替换语义
  全部不变；本规格只动呈现层与交互编排。
- 生效模式说明、未绑定占位、i18n 双语言包机制照旧。

## 验收标准

### 自动化

- 共享纯逻辑新增单测：冲突操作集合计算、四种筛选谓词（含空数组=显式禁用归
  「由我分配」）。
- 快捷键页视图单测重写对齐新 DOM：筛选签过滤、捕获签状态机（＋→✓、Enter
  提交、Esc/失焦取消、relatedTarget 例外）、⋯菜单动作、focusEntry 定位。
- 设置页骨架单测：侧栏 / 主区独立滚动容器结构、分组容器包裹、开关控件语义
  （type=checkbox + aria）。
- 浏览器套件（真实 Chromium）：`settingsPage` 套件补一条**绘制层断言**——
  主区滚动时侧栏不动（两容器独立滚动的可见效果）；`keybindings` /
  `keybindingEditor` 套件对齐新 DOM 与捕获签真实键盘流。
- `npm run compile`（tsc）、`npm run test:unit`、语言包 parity 与 CJK 字面量
  契约扫描全绿。

### 人工验收（自动化不替代）

- 明暗两种主题下：双滚动条形态、容器色差观感、开关观感、快捷键页单行布局。
- 色差基调若不满意，在候选变量族间切换后复验。
- 真实键盘录制两段键位（如 Ctrl+K Ctrl+B）与 Esc 取消手感。
