# 统一自绘悬停提示（tooltip）规格

> 状态：规格定稿（2026-10-02 设计访谈，grill 九题三轮共识），待实施。
> 访谈结论摘要见 [CONTEXT.md](../../CONTEXT.md)「悬停提示」条目；实施工单见仓库 Issues（开票时回填编号）。

## 背景与问题

全站悬停提示现状为原生 `title` 属性（约 60 处，编辑器 webview 绝大多数 + 设置页 2 处），观感由浏览器接管：样式不可控、出现延迟不可调、不随明暗主题变化、无法承载键位徽章等结构。同时原生 title 气泡与未来任何自绘呈现互斥——只要 title 属性在场，浏览器气泡无法阻止。

悬停提示文案的生命周期已有两条成熟换词通道（`localeDom` 注册表与 `localeOnDemand` 扫描），文案双写口径统一为 aria-label（可访问名）+ title（悬停词）同词。

## 目标

1. 编辑器 webview 与设置页 webview 的悬停提示统一为**自绘小卡片**，观感对齐 Obsidian 参照截图：浅色主题浅底深字、深色主题深底白字，带键位徽章形态。
2. 明暗与高对比主题经宿主变量族**自适应**，不写专门主题分支。
3. 小卡片可聚焦、内部文字可选中复制；不装载按钮与交互逻辑。
4. 存量原生 title 全量退役，迁移收敛在换词通道内部，调用方 API 面零改动。

## 非目标

- 富内容提示（图片预览、Markdown 渲染、多段富文本布局）。
- 提示内按钮、链接等交互逻辑（「复制」按钮等）。
- CM6 文本内悬停（`hoverTooltip` 诊断类）——正文悬停预览已独立存在，不属于本功能。
- 宿主侧 UI（命令面板、状态栏、原生工作台）——扩展无 DOM 控制权。
- 触屏适配；跨显示器定位（视口以当前窗口为界）。
- 用户可配置的出现位置偏好（上下左右选择）。

## 视觉规格

观感参数全部经公开变量承载（默认值经目检对齐参照截图，实施后由用户目检微调；数值可调，机制不可变）：

| 变量 | 承载 | 默认值方向 |
| --- | --- | --- |
| `--vsidian-tooltip-background` | 卡片背景 | 引 `--vscode-editorHoverWidget-background`（浅浅深深自适应） |
| `--vsidian-tooltip-foreground` | 文字前景 | 引 `--vscode-editorHoverWidget-foreground` |
| `--vsidian-tooltip-border` | 边框 | 引 `--vscode-editorHoverWidget-border`（浅色细边、深色近无） |
| `--vsidian-tooltip-radius` | 圆角 | 约 6px |
| `--vsidian-tooltip-font-size` | 字号 | 约 12px |
| `--vsidian-tooltip-max-width` | 最大宽度 | 约 320px，溢出换行 |
| `--vsidian-tooltip-key-background` | 键位徽章背景 | 浅色近白、深色浅白透明，目检定 |
| `--vsidian-tooltip-key-foreground` | 键位徽章前景 | 随徽章背景目检定 |
| `--vsidian-tooltip-show-delay` | 出现延迟（ms） | 300，与悬停预览节奏一致 |

- 阴影引宿主 widget shadow 变量；内边距约 4px 8px（不公开变量，如片段需要再升级）。
- 公开变量与类名（容器、键位徽章）登记进 styleContract，用户指南由脚本再生；片段可定向覆盖。

## 行为规格

**触发与显隐**：

- 事件委托于 document（`mouseover` / `focusin` / 对应离开事件），监听携带提示属性的目标，不逐控件绑定。
- 悬停出现延迟取 `--vsidian-tooltip-show-delay`（JS 侧读取计算值）；焦点进入**即时**显示（无延迟）。
- 指针移入提示本体**保活**（否则文字无法选中）；移出触发元素与本体的联合区域即收。
- 提示容器 `tabindex="0"` 可聚焦；提示自身持有焦点时按 Esc 收起并还焦触发元素；指针悬停态不接管 Esc（不与其他浮层的 Esc 链冲突）。
- 同屏至多一个；触发目标切换即重定位。
- 态变文案（查找输入无效、导出禁用原因等）随属性更新即时刷新或清空。

**定位（纯函数几何模块，先例 `hoverPopupGeometry` / `frontmatterPopover` 定位）**：

- 锚定触发元素（非鼠标位置）：下方优先 → 上方翻转 → 水平**居中优先**（锚点中心对齐提示中心，对齐 Obsidian 参照观感）→ 越出边缘才翻转对齐（右缘→右对齐锚点、左缘→左对齐锚点）→ 仍越界钳制进视口；间距与视口边距沿用悬停预览先例（gap 6 / margin 8）。（2026-10-02 验收反馈：水平基准由左对齐改为居中）

**层级与互斥（对访谈 Q7 措辞的实施修正）**：

- 访谈原定「进 popupMutex 互斥族、让位不抢占」。实施设计修正为：**不参与 `popupMutex` 争夺，z-index 置于模态之上（10500）**——因为图表弹窗、图片弹窗、悬停预览弹窗**自身内部的按钮**同样需要悬停提示，若被互斥压制，浮层内提示将退化为原生；而指针/焦点驱动的显隐天然保证模态打开时外部目标不会触发（模态遮罩拦截指针）。tooltip 不 claim、不抢占、不遮挡，对既有浮层零干扰——「不干扰既有浮层」的决策意图完整保留，机制从互斥改为层级+指针驱动。
- 挂载点 `#app`（回退 body），继承主题变量与用户 CSS 片段作用域（悬停预览弹窗同款理由）。

## 接管机制

1. **专用属性迁移**：`bindLocale` / `bindLocaleAttrs` / `bindLocaleFn` 及 `bindLocaleFnAttrs` 中目标属性为 `title` 的路径内部改写为 `data-tooltip`；`localeOnDemand` 扫描通道同步改写目标属性。调用方（全部存量约 60 处）API 面零改动。
2. **aria 口径不变**：aria-label 继续承担可访问名，与提示内容同词；title-only 特例（图片弹窗导出禁用提示）迁移后 aria 侧维持既有键，禁用原因走提示属性，读屏可达性不回退。
3. **原生 title 全量退役**：迁移完成后源码不再有产出悬停提示的 title 写入；以契约扫描防回潮（新增原生悬停 title 写入即红）。
4. **内容三分类同层**：操作提示（i18n 键）、用户内容字面量（图片 alt、公式错误原始 TeX、CSS 片段拒绝路径——直接写提示属性，不经 i18n）、态变提示（插值与清空走既有换词通道）。
5. **键位徽章结构化**：缀尾键位的提示（快速操作条等十余处）迁移时拆为两段——名称走主属性，键位走结构化通道（`data-tooltip-keys`，多段键位各一枚徽章）；键位数据源为既有键位注册表与拼接键，不另建事实源。
6. **设置页同机制**：提示模块为 webview 侧共享源码、两产物各自打包；设置页不引 localeOnDemand，其注册表换词路径不受影响。

## 测试与验收

- **几何纯函数单测**（vitest node）：下/上翻转、水平居中与越缘翻转、视口钳制的矩阵用例——先例 `hoverPopupGeometry`。
- **jsdom 委托单测**：显隐时序（fake timers 验延迟变量读取）、移入保活、focus 即显、Esc 还焦、换语言包后提示内容重刷（先例 locale 契约测试族）。
- **防回潮契约**：源码扫描禁止新增原生悬停 title 写入；styleContract 检查器覆盖新变量与类名。
- **browser 测试（Playwright）**：悬停后提示**可见性绘制层断言**（可见 + 计算样式读变量值，不接受 DOM 存在性断言——视觉层断言约定）；明暗主题类切换的样式跟随断言；内部文字选区一条。
- **人工验证清单补项**：明暗/高对比观感目检、多屏与窗口边缘、缩放倍率、与悬停预览弹窗和两类模态弹窗共存的观感。

## 扩展约定（落档）

新增或修改悬停提示（新控件、新浮层内按钮、调整键位徽章）前，必读本规格「接管机制」节：

1. 文案入 `src/shared/locales/` 双语言包（用户内容字面量除外）。
2. 控件经 `bindLocale` 家族绑定（或动态场景直接写 `data-tooltip`）；**禁止新写原生 title 悬停写入**（契约扫描拦截）。
3. 带快捷键的操作走结构化键位通道，不做文字缀尾。
4. 实施落地时在 AGENTS.md 补「悬停提示扩展约定」常驻节。

## 边界与明确不包含

- 「悬停预览」（引用文档富预览浮层）、「查找选项条」、「表格把手」等既有浮层/悬停形态不在本票范围，其内部按钮的悬停提示统一接管（第 4 条内容分类覆盖）。
- 出现延迟变量只控出现；消失即时（保活边界见行为规格），不公开消失延迟。
- 提示内容的换行由 `max-width` 自然约束，不做手动分页或滚动。
