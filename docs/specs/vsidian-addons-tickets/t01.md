# feat: 附加组件 T01——身份发现、兼容检查与轻量注册

总览：#347。类型：实施。

Blocked by: 无

执行状态：可认领；无前置依赖。

## 目标

一个声明了附加组件身份的独立 VSCode 扩展可以被发现、兼容检查、唤醒并且只注册一次，用户能在 Vsidian 自有设置页看到基础状态和 VSCode 管理入口。

## 范围与已确认规则

- 私有顶层身份声明加代码注册，组件 ID 沿用 Extension.id；关键词仅帮助市场搜索。不得列出普通扩展，不建立第二套能力或激活事件 DSL。
- Vsidian activate 返回可访问 API 后再协调扫描唤醒；先订阅 extensions.onDidChange 再扫描。依赖自己的组件不能被自身 activate 等待。
- 同时覆盖组件先由 VSCode 激活和 Vsidian 主动唤醒；入口核对当前宿主身份、API 范围、实验兼容与重复接入，重复注册不重跑 setup。
- 合法声明不兼容、激活失败与当前宿主不可用各显示原因；查不到不能直接断言未安装或装错侧。官方组件来自主仓库明确的扩展 ID 清单。
- 给基础组件状态页面接入市场搜索与 VSIX/安装管理入口，安装和整扩展禁用继续由 VSCode 管理。实现新增轻量协议，不迁移全部编辑器或设置模型。
- 随本批次首个实施 PR 落档 ADR、规格、技术提议与开票索引；对暂未实现的接口保持草案状态。

## 验收标准

- [ ] 普通扩展不入组件列表；兼容测试组件默认启用，不兼容与失败组件有清楚状态。
- [ ] 两条激活路径、清单刷新与重复请求的真宿主测试证明无互等、无重复注册，API 在注册前可访问。
- [ ] 身份字段、兼容判定、注册拒绝类型、官方清单归属及首个候选 API 版本有声明、文档和消费样例；声明能力不冒充已发布稳定 API。
- [ ] VSCode 搜索/管理入口真实可用，页面文字经 i18n；既有内置设置入口保持有效。

## 验证与留证

- 身份/兼容纯逻辑契约
- 设置页状态与管理入口
- 真宿主激活顺序和重复注册

## 范围外

- 不等待 V01/V02 才做独立的发现注册工作
- 不装载完整组件页面功能或建立内部安装器

## 实施与交付约定

- 接口名称与字段仍是待冻结技术提议；实现可据通过的验证收敛形状，已确认的用户行为不能自行弱化。通过公开消费路径验证，不引用内部控制器当 SDK。
- 可执行变更按仓库 TDD 约定先立预期再实现；输入/光标变更必跑浏览器原生路径，装载/历史/安装需真宿主。长命令首次执行留完整日志和退出码，复核读报告。
- 页面 DOM、CSP、资源或样式入口改动先执行项目 style-contract；用户可见平台文字经 i18n，新增操作评估快捷键、模式和默认绑定。
- 在独立工作树实施，遵循 AGENTS 的提交、推送及 PR 边界；验收实现不等于授权合并或对外发布。完成时回填证据和未验项，自动检查不能写成用户已验收。
