## 目标

独立组件通过公开页面入口和 JSON 通信，在编辑器/自身设置页挂载一个可见功能，并由平台按设置与运行两个生命周期管理。

## 范围与已确认规则

- 按 V02 的通过方案实现本地页面产物、入口工厂和 SDK 构建桥；稳定能力与 experimental.cm6 分层，实验能力声明兼容。
- 轻量 setup 注册设置定义与自己的设置入口；运行 enable 回调按用户功能开关装配。普通关闭释放运行贡献但保留设置能力。
- 资源仅授权组件安装目录内登记的子目录，使用每页自己的 URI。平台记录组件、实例、请求及装载代次，拒绝旧工厂、旧消息和越界资源。
- 通信只传 JSON 数据，明确成功、拒绝、取消、超时和释放结果；不能桥接函数、DOM 或内部控制器。
- 统一收集释放句柄、异步有效引用与组件清理回调。可归因注册/初始化/回调异常暂停该组件全部注册贡献，启用偏好独立保存；基础原因状态可观察。

## 验收标准

- [x] 测试组件用公开 SDK 在编辑器和自身设置页挂载/通信，宿主 CJS 与浏览器产物分开装配；无裸 require 或重复 CM6。
- [x] 手动停用、重启后停用、故障、视图关闭、重复释放及手动重新接入均符合两个生命周期的边界。
- [x] 释放后消息不能写文档、旧结果不能回挂，失败请求不虚报成功。
- [x] 接口声明、SDK 构建辅助入口、资源/错误语义与生产接入测试同步记录，页面内容有绘制层证据。

- 验证矩阵：单元（`test/unit/addonRuntime.test.ts` 等 7 文件，含重启持久语义）、浏览器生产路径（`test:browser` addonPageSdk 套件 6 场景——真实键盘/CDP IME/绘制层计算色）、真宿主（`test/integration/suite/addonT02Cases.ts` 5 用例——生产编辑器/设置页面板、停用/故障/重新接入/持久层）。
