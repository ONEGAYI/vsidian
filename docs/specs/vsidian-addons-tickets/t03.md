## 目标

先扩展现有提交/确认管线的来源与历史归属接入点，保持旧调用的行为，再让公开编辑 API 接入，不把宽泛重构和新业务混在一票。

## 范围与已确认规则

- 依 V01 的通过协议，为 HostDocumentPort、edit.request、版本/增量确认及目标会话增加可选来源和原子操作归属元数据。旧调用缺省走原行为。
- 维持 TextDocument 权威、WorkspaceEdit 写回、LF/CRLF 转换、串行申请和去重 ack；来源记录贯穿多范围、暂缓合并和失败，不用文本显示名充当身份。
- 通过窄适配点承接同目标历史协调，引用 B 的激活/恢复整组处理；本票不开放组件 applyEdits，也不改变旧输入撤销分段。
- 采用扩展后迁移方式，新增形式与旧调用并存；只清理完成迁移的局部重复逻辑，避免一轮重写 syncController/DocumentSession。

## 验收标准

- [ ] 现有未携带来源的输入、IME、引用 B、富文本粘贴、500ms 分段与冲突恢复保持契约等价。
- [ ] 可选元数据经过真实写回/回流准确归属，失败不留下成功来源记录，重放不重复计入。
- [ ] 纯选区事务不造文本撤销项，跨目标元数据不能合并到父文档历史。
- [ ] 适配点及迁移范围有文档和必要契约测试，未开放或发布新 SDK 功能。
