## 目标

组件注册的普通值、数组和对象能在 Vsidian 设置中编辑、校验、持久化并按用户默认/工作区覆盖生效。

## 范围与已确认规则

- 设置定义来自代码注册，按组件 ID 隔离；JSON 普通值、有限数、数组项和对象字段由可序列化定义校验，不能传函数校验器。
- 为普通值、数组和对象提供可用基础控件。顶部平台提供用户默认/当前工作区作用范围；逐项使用用户默认只清除覆盖。
- 按批校验与保存，失败不发成功通知；变化事件只在持久化成功后发出。覆盖、默认、来源及功能开关普通升级不重置。
- 冻结存储结构、复杂值升级/迁移、无工作区形态与跨窗口协调；组件私有业务缓存不混入设置。内置标量类型不能靠断言伪装成复杂值。

## 验收标准

- [ ] 标量、替换规则数组及对象样例可编辑保存，重新打开/重启回显与实际值一致。
- [ ] 用户默认和工作区值、清除覆盖、无工作区、跨窗口变更各有明确结果，内置设置作用范围保持原约定。
- [ ] 非法补丁整批拒绝，保存失败不虚报，缺省/存量/迁移符合已记录结构。
- [ ] 功能开关和复杂设置的读写、来源 API 与基础控件有公开消费及浏览器/宿主证据。
