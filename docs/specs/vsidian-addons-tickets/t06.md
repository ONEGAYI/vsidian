# feat: 附加组件 T06——统一视图编辑 API 与原子修饰历史

总览：#347。类型：实施。

Blocked by: #351、#352

执行状态：待前置完成并满足放行条件；本票已创建，暂不标 ready-for-agent。

## 目标

组件通过公开 SDK 读取有效视图、文本与选区，提交默认原子或显式非原子修饰，正确写回目标文档并撤回/重做。

## 范围与已确认规则

- 统一主正文、悬停引用、嵌入视图句柄；包含实例/目标/模式/可编辑状态，快照包含多选区、权威版本及能覆盖页面未确认状态的修订标记。
- 公开坐标为 UTF-16/LF；请求从有效句柄取得目标，来源由所属组件/行为上下文添加，不能冒充其他组件。旧快照、只读、已释放或失活写入明确拒绝。
- 每次相关变更默认 atomic，独立跟踪和撤回；可声明 joinPrevious，仍逐次跟踪，并随同文档上次原子操作撤回。无可确认前项不能静默另造语义。
- 按 V01/T03 已验证协议连接宿主历史；原生与 Vsidian 入口一致，组内推进确认回流，引用 B 不能误改 A。
- 提供选区设置和定位，零文本改变的操作不造文本历史。接口名称、错误类型和提交凭据随消费样例冻结。

## 验收标准

- [ ] 外部测试组件通过公开 API 完成真实文本/选区读取与多范围修饰，宿主 dirty/save、LF/CRLF 与提交凭据准确。
- [ ] atomic A、非原子 B、atomic C、非原子 D 在主文档及引用 B 按 AB/CD 撤销与重做，逐次来源不丢。
- [ ] 旧版本/修订、只读、失活、伪来源、空历史与失败路径均有可辨认拒绝，不越权写入或错撤目标。
- [ ] 与 V01 相同的并发、IME、原生入口、分支和重载矩阵进入生产控制器验证；不以临时探针替代。

## 验证与留证

- 宿主写回、引用目标及历史恢复
