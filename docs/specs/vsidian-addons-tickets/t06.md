## 目标

组件通过公开 SDK 读取有效视图、文本与选区，提交默认原子或显式非原子修饰，正确写回目标文档并撤回/重做。

## 范围与已确认规则

- 统一主正文、悬停引用、嵌入视图句柄；包含实例/目标/模式/可编辑状态，快照包含多选区、权威版本及能覆盖页面未确认状态的修订标记。
- 公开坐标为 UTF-16/LF；请求从有效句柄取得目标，来源由所属组件/行为上下文添加，不能冒充其他组件。旧快照、只读、已释放或失活写入明确拒绝。
- 每次相关变更默认 atomic，独立跟踪和撤回；可声明 joinPrevious，仍逐次跟踪，并随同文档上次原子操作撤回。无可确认前项不能静默另造语义。
- 按 V01/T03 已验证协议连接宿主历史；原生与 Vsidian 入口一致，组内推进确认回流，引用 B 不能误改 A。
- 提供选区设置和定位，零文本改变的操作不造文本历史。接口名称、错误类型和提交凭据随消费样例冻结。

## 验收标准

- [x] 外部测试组件通过公开 API 完成真实文本/选区读取与多范围修饰，宿主 dirty/save、LF/CRLF 与提交凭据准确。（集成用例 1：views.list 主句柄、快照文本/版本/修订、多范围一笔、凭据 version 与权威对位、dirty/save、零文本操作不造历史、CRLF 文档 LF 坐标替换与行尾保持）
- [x] atomic A、非原子 B、atomic C、非原子 D 在主文档及引用 B 按 AB/CD 撤销与重做，逐次来源不丢。（集成用例 2：ABCD 四笔、AB/CD 组单位撤回与重做、协调器条目流组归属与逐次来源；集成用例 4：引用 B 经 embed 句柄 A 原子+B' 并组、临时激活路由一次撤整组、父子隔离）

- 接口名称与字段仍是待冻结技术提议；实现可据通过的验证收敛形状，已确认的用户行为不能自行弱化。通过公开消费路径验证，不引用内部控制器当 SDK。
