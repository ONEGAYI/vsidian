## 目标

用户在组件管理设置页的行为冲突管理入口，辨认所属组件并调序或只关闭部分行为，立即看到输入组合变化。

## 范围与已确认规则

- 入口固定在组件管理设置页，名称为行为冲突管理；管理单位是注册的具体行为，不列出所有内部业务条件分支。
- 展示必填行为名称和所属组件，说明/例子存在时按需展开。布局、分组和必要筛选服务定位，最近输入排查并非强制新增范围。
- 提供可理解的顺序调整和单项开关，默认按默认序依次触发；单项关闭保留配置，不停用整个组件。
- 与整体组件开关、用户默认/工作区覆盖和失活/故障状态一致；调整热生效，组合输入安全收尾。

## 验收标准

- [ ] 未掌握完整组件行为的用户仍能按名称、所属组件和可选例子识别调整对象。
- [ ] 调序与只关某项能通过真实输入展示结果，其余适用行为继续运行；重开/重启恢复。
- [ ] 整体停用/故障与单项关闭互相区分，配置不丢，平台内置输入安全规则不被 UI 绕过。
- [ ] 新增操作评估快捷键入口和生效模式，i18n、键盘可操作性与绘制层验证完成。

## 验证与留证

- 设置页调序与逐项切换
- 真实输入效果与热切换
- 重启、作用范围与状态回显
