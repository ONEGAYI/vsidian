## 目标

新安装的渲染组件直接替换其支持语言的当前显示，包括内置 Mermaid；用户按需调整，正常关闭或整组件故障停用后恢复内置。

## 范围与已确认规则

- 为所有代码块语言提供多候选注册与单一生效提供者，支持语言/模式、挂载刷新释放及可选图形导出；内置实现作为候选保留。
- 兼容且已启用的新安装组件成功接入后自动替换，无需逐语言初始选择。区分新发现批次与重启、重复注册、普通升级，后者不覆盖既有首选。
- 冻结多候选同时接入的确定性默认次序及存储；不靠脚本装载竞速决定生效者，不声称拥有未公开的真实安装时间。支持按需调整和改回内置。
- 原有图形注册两表与按钮/弹窗/导出路径适配，保留内置实现；已挂载内容热切换，旧代次与迟到结果不得回潮。
- 正常停用及整组件已故障降级停用后内置接管，无图形内置则普通代码块；仍运行的渲染 bug 或自处理局部失败不自动接管。保留首选，手动恢复成功按原选择显示。

## 验收标准

- [ ] 安装测试渲染组件后，无额外选择就替换至少内置 Mermaid 和原普通语言的显示，Live/阅读仅在支持模式执行。
- [ ] 同语言多候选、用户调整、重启/升级、跨窗口发现及已开文档热切换符合确定性规则。
- [ ] 正常关闭、已全组件故障停用、仍运行错误输出三种情况分别可测，故障原因和首选保留，重试成功恢复。
- [ ] 图形按钮/导出与内置显示不回退，绘制层断言证明实际选中内容；异步旧结果不覆盖恢复内容。

## 验证与留证

- 候选选择和发现批次契约
- Live/阅读绘制及图形交互
- 安装、热切换、故障与重启首选

## 范围外

- 不同时运行同语言全部渲染器
- 不承诺判断第三方错误输出或代为修复

## 实施与交付约定

- 接口名称与字段仍是待冻结技术提议；实现可据通过的验证收敛形状，已确认的用户行为不能自行弱化。通过公开消费路径验证，不引用内部控制器当 SDK。
- 可执行变更按仓库 TDD 约定先立预期再实现；输入/光标变更必跑浏览器原生路径，装载/历史/安装需真宿主。长命令首次执行留完整日志和退出码，复核读报告。
- 页面 DOM、CSP、资源或样式入口改动先执行项目 style-contract；用户可见平台文字经 i18n，新增操作评估快捷键、模式和默认绑定。
- 在独立工作树实施，遵循 AGENTS 的提交、推送及 PR 边界；验收实现不等于授权合并或对外发布。完成时回填证据和未验项，自动检查不能写成用户已验收。
