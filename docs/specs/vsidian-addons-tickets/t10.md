## 目标

组件注册自己的可绑定操作和新增菜单项，平台统一管理模式、快捷键、归属与停用回收，内置项不会被覆写。

## 范围与已确认规则

- 公开命令与菜单注册使用组件命名空间，标题/名称、回调、作用模式和可选默认绑定由代码提供；默认未绑定允许。
- 所有面向用户的操作进入统一快捷键管理和冲突检查；写操作只在 Live 正文接管，源码/设置输入不接管，阅读或双模式按操作声明。
- 拒绝内置 ID、同名注册间接替换、隐藏/删除/改名及其他组件归属侵犯。内核既有 override/hide 不直接作为公开 SDK。
- 单项/全部恢复与显式清空沿既有快捷键契约，停用回收自己的命令和菜单；不影响内置菜单。

## 验收标准

- [x] 外部组件经 SDK 的新增菜单项与命令能够触发真实业务，快捷键管理可绑定、清空、恢复并重启保留。（夹具 addon-t10：insertStamp 命令与 stampEntry 菜单项经 views.applyEdits 真实提交 T10-STAMP 文本落盘 dirty/save——浏览器真实键盘与真宿主集成双路径；绑定/冲突拒绝/显式清空/恢复默认沿宿主权威存储，集成断言 + 单测钉住存储净化保留命名空间键——组件不在场时用户绑定与显式清空不丢；宿主真重启不可集成内重放，与 T06 同等限制，由存储语义单测承载）
- [x] 同名、内置及跨组件覆盖尝试明确拒绝，未出现注册后替换内置菜单的间接路径。（注册入口只收局部 ID + 平台注入命名空间——结构上免疫；同名注册 duplicate-command、局部 ID 含点 local-id:dot、Tab 默认绑定 tab-forbidden、菜单 iconKey 未登记 icon-key 均为明确拒绝码且不进宿主目录；内核 override/hide 未作为公开 SDK——SDK 面无任何覆写入口）

## 实施回执（2026-10-07）

- **形状**：页面 SDK 增 `commands.register(def, handler)` 与 `menus.registerItem(def)`（仅编辑器页；设置页 undefined）；命令形状 `{ id, title, mode, writes?, defaultBindings? }`、菜单形状 `{ id, label, iconKey?, order?, command?, when?, enable? }`——仍是草案形状，随公开声明冻结。
- **键位存储**：与内置同一 `KeybindingOverrides`（键 = 命名空间命令 ID）；三环境（编辑器 webview / 设置页 / 宿主）各持运行期操作表（`setRuntimeOperations`），经 `addonCommands.report`（webview→宿主全量对账）与 `addons.commandCatalog`（宿主→设置页目录）同步。
- **执行链**：快捷键 router 本地分支 → 宿主命令面板（executeCommand → 活动面板转发 `addonCommand.execute`）→ 菜单点击（handler 优先分派路径）三入口共用组件回调；回调异常注册表吞掉留痕（键路由/宿主回发不断链）。
- **回收**：装载器 releaseLoad（停用/故障/卸载）在 webview 侧闭环回收（releaseAddon——不依赖宿主消息到达）；宿主侧 runtime 状态对账（非 enabled 即整组件回收 VSCode 命令 + 目录清空 + 广播）。
- **测试**：单测 31 例（addonCommands.test 16 + addonCommandsRuntime.test 9 + addonCommandService.test 6）；浏览器 `test/browser/addonT10Commands.mjs` 5 场景（生产装配，真实键盘/右键）；集成 `addonT10Cases` 4 用例（真宿主 1.82.3 便携，生产链路）。夹具 `addon-t10`（宿主 CJS + 构建桥页面产物）。
- **未验项**：真实 IME 组合期与命令回调交错的键盘行为（浏览器 CDP composition 属 T02/T05 套件，T10 命令回调非输入链路）；宿主真重启后命令目录恢复（V01 同等限制——runtime 重新发现唤醒，单测承载存储语义）；人工验收（菜单观感/物理鼠标）沿 manual-verification 清单。
