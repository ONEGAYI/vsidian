## 目标

组件注册自己的可绑定操作和新增菜单项，平台统一管理模式、快捷键、归属与停用回收，内置项不会被覆写。

## 范围与已确认规则

- 公开命令与菜单注册使用组件命名空间，标题/名称、回调、作用模式和可选默认绑定由代码提供；默认未绑定允许。
- 所有面向用户的操作进入统一快捷键管理和冲突检查；写操作只在 Live 正文接管，源码/设置输入不接管，阅读或双模式按操作声明。
- 拒绝内置 ID、同名注册间接替换、隐藏/删除/改名及其他组件归属侵犯。内核既有 override/hide 不直接作为公开 SDK。
- 单项/全部恢复与显式清空沿既有快捷键契约，停用回收自己的命令和菜单；不影响内置菜单。

## 验收标准

- [ ] 外部组件经 SDK 的新增菜单项与命令能够触发真实业务，快捷键管理可绑定、清空、恢复并重启保留。
- [ ] 同名、内置及跨组件覆盖尝试明确拒绝，未出现注册后替换内置菜单的间接路径。
- [ ] 模式、写入门控、Tab 固定链及设置输入排除符合既有约定；普通关闭和故障后自己的贡献撤下。
- [ ] 声明/指南、i18n、菜单图标和键位注册同步检查，真实键盘与绘制验证通过。

## 验证与留证

- 命名空间/归属和绑定契约
- 真实模式/键盘与菜单交互
- 停用/重启/清空恢复

## 范围外

- 不公开覆写、隐藏或接管内置菜单 API
- 不提供任何命令绑定 Tab 的通道

## 实施与交付约定

- 接口名称与字段仍是待冻结技术提议；实现可据通过的验证收敛形状，已确认的用户行为不能自行弱化。通过公开消费路径验证，不引用内部控制器当 SDK。
- 可执行变更按仓库 TDD 约定先立预期再实现；输入/光标变更必跑浏览器原生路径，装载/历史/安装需真宿主。长命令首次执行留完整日志和退出码，复核读报告。
- 页面 DOM、CSP、资源或样式入口改动先执行项目 style-contract；用户可见平台文字经 i18n，新增操作评估快捷键、模式和默认绑定。
- 在独立工作树实施，遵循 AGENTS 的提交、推送及 PR 边界；验收实现不等于授权合并或对外发布。完成时回填证据和未验项，自动检查不能写成用户已验收。
