## 目标

组件在合法视图位置新增自己的按钮和面板，能够使用已注册操作，随所属视图或组件退出而完整回收。

## 范围与已确认规则

- 定义有明确归属的按钮/面板挂载位置与 SDK 句柄，使用自己的稳定 ID、可读标题及 T10 操作，不把内核容器或整编辑器交给作者接管。
- 支持主文档、悬停/嵌入可用实例和声明模式；界面回调仍携当前目标与生命周期。
- 按钮提示使用既有 data-tooltip/键位徽章，新增可绑定操作按统一规则评估。公开样式入口与组件自身样式界限记录。
- 面板关闭、视图释放、模式切换、组件停用或故障回收挂载与监听，迟到结果不能进入失效面板。
