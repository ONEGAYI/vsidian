# feat: 附加组件 T11——所属按钮、面板与视图界面贡献

执行状态：待前置完成并满足放行条件；本票已创建，暂不标 ready-for-agent。

## 目标

组件在合法视图位置新增自己的按钮和面板，能够使用已注册操作，随所属视图或组件退出而完整回收。

## 范围与已确认规则

- 定义有明确归属的按钮/面板挂载位置与 SDK 句柄，使用自己的稳定 ID、可读标题及 T10 操作，不把内核容器或整编辑器交给作者接管。
- 支持主文档、悬停/嵌入可用实例和声明模式；界面回调仍携当前目标与生命周期。
- 按钮提示使用既有 data-tooltip/键位徽章，新增可绑定操作按统一规则评估。公开样式入口与组件自身样式界限记录。
- 面板关闭、视图释放、模式切换、组件停用或故障回收挂载与监听，迟到结果不能进入失效面板。

## 验收标准

- [ ] 外部组件通过公开 API 新增可见按钮和自己的面板，操作作用于正确目标文档。
- [ ] 模式、引用实例释放及所有退出路径不留失活按钮/面板或跨目标回调。
- [ ] 组件不能覆盖内置界面/菜单/设置框架，所属 ID 冲突拒绝可测试。
- [ ] 提示、i18n、绘制层和样式契约证据完整，消费样例不依赖内部控制器。

## 验证与留证

- 挂载归属与代次
- 视图界面绘制和交互
- 模式与引用视图释放

## 范围外

- 不重做全应用布局
- 自定义设置内容仍走 T05 的独立生命周期

## 实施与交付约定

- 接口名称与字段仍是待冻结技术提议；实现可据通过的验证收敛形状，已确认的用户行为不能自行弱化。通过公开消费路径验证，不引用内部控制器当 SDK。
