## 目标

主仓库以公开声明、结构化语义清单和发行台账维护六组 API，生成可消费的版本参考与指南，达到与 CSS 样式契约同等的维护入口。

## 范围与已确认规则

- 整理六组真实接口及稳定/实验分层；声明和语义清单为事实源，不手写第二份函数签名。语义包含目标、模式、坐标、生命周期、错误、历史及自动渲染规则。
- 生成参考/版本索引与开发指南，覆盖发现安装、两端 SDK、行为/设置/渲染、调试、迁移及三类样例入口；AGENTS 保持单一触发指针。
- API 独立编号，候选首版与实验兼容清单随验证冻结；发行台账区分草案/已发布和实际发布日期。未真正发行前不能伪造稳定历史或日期。
- 稳定移除需先发布弃用及替代，从实际发布日起同时满两个后续 API 次版本和 30 天。开发文档不要求打入 Vsidian VSIX。
- 为独立示例仓库准备主仓库可复制开发说明，Wiki 仅可展示；此票不创建或发布外部仓库/包。

## 验收标准

- [ ] 六组已实现接口有公开声明、对应语义和版本参考，消费编译不导入内部控制器；实验入口单独说明兼容边界。
- [ ] 生成结果新鲜度可检查，签名/语义调整必须同步指南、样例和版本记录，AGENTS 入口可发现全部事实源。
- [ ] 候选首版、实际发行状态和弃用起点可辨认，没有将普通 Vsidian 版本当作 API 跨度。
- [ ] 文档链接、生成结果、消费样例和包排除有验证，文档不冒充已经对外发布 SDK。

## 验证与留证

- 声明消费编译
- 参考生成与链接/新鲜度
- 候选/发行/弃用台账内容契约

## 实施与交付约定

- 接口名称与字段仍是待冻结技术提议；实现可据通过的验证收敛形状，已确认的用户行为不能自行弱化。通过公开消费路径验证，不引用内部控制器当 SDK。
- 可执行变更按仓库 TDD 约定先立预期再实现；输入/光标变更必跑浏览器原生路径，装载/历史/安装需真宿主。长命令首次执行留完整日志和退出码，复核读报告。

- 在独立工作树实施，遵循 AGENTS 的提交、推送及 PR 边界；验收实现不等于授权合并或对外发布。完成时回填证据和未验项，自动检查不能写成用户已验收。
