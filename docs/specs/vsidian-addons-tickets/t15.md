## 目标

开发者有三套只使用公开 SDK 的可独立构建样例，共同检验 API 不只为 Easy Typing 一项需求服务。

## 范围与已确认规则

- 输入样例借鉴 Easy Typing 的一个明确场景，如自动空格或括号处理，展示默认原子及声明非原子、顺序与逐项关闭；不承诺完整移植。
- 渲染样例支持替换一个内置语言及一个普通语言，展示安装后自动接管、按需调整、正常停用/全组件故障及自身 bug 的区别。
- 界面样例新增自己的命令/菜单、按钮或面板及复杂设置，展示用户默认/工作区覆盖、停用后配置和手动恢复。
- 每个样例为独立 VSCode 扩展工程，声明依赖、同宿主偏好、身份/API兼容与各自宿主/页面产物；不得导入内部代码或重复 CM6。
- 维护于主仓库可打包的示例/测试位置，使用同一公开 SDK 开发包与生成指南，准备后续独立仓库复制路径。

## 验收标准

- [ ] 三个工程各自编译、构建、打包，产物无内部路径导入、裸 require 或重复 CM6；运行资源齐全。
- [ ] 经公开接入从安装/注册到可见结果均有端到端证据，输入、渲染、界面三类覆盖完整。
- [ ] 示例确能展示已确认默认值、设置/行为/故障规则，文档与实际代码一致。
- [ ] Vsidian 主 VSIX 不夹带测试样例和开发文档；外部示例仓库可复制清单可审阅。

## 验证与留证

- 三工程独立消费与构建
- 公开 API 使用及产物扫描
- 三类可见行为端到端

## 范围外

- 不完整移植 Easy Typing
- 不创建独立 GitHub 仓库或发布 Marketplace/npm 包
