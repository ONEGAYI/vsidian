# test: 附加组件 V02——页面 SDK、共享 CM6 与资源释放验证

总览：#347。类型：验证。

Blocked by: 无

执行状态：可认领；无前置依赖。

## 目标

验证独立浏览器脚本加本页 SDK 注入能够实际接入编辑器与自身设置页，包含共享 CM6、资源拒绝对照和卸载边界。

## 范围与已确认规则

- 现有核心为 browser/IIFE；组件提供独立页面产物，由加载器关联组件身份和代次后调用工厂。宿主 CJS 或仅 external 的裸 require 不能充当浏览器 SDK 桥。
- 最小宿主只验证授权脚本、注入 EditorState 创建状态及移除测试节点，未验证真实 StateField/ViewPlugin、第一笔输入、完整释放或拒绝对照。
- 接入真实 CM6 扩展并验证行为/绘制结果及构造器身份；组件不得再次打包一份 CM6 运行时。输入可交互前完成必要装配，首个按键与 IME 不丢失。
- 编辑器与设置页分别登记组件安装目录内的入口和资源子目录，通过各自 localResourceRoots 与 asWebviewUri 授权。覆盖脚本、CSS、图片及未授权/越界路径拒绝。
- 普通停用、视图关闭、故障与手动恢复回收注册、监听、挂载和消息；旧代次及迟到结果不回挂。当前 CSP 实际允许资源源和 nonce，不能引用旧注释冒充现行事实。
- 记录实际下界宿主浏览器版本；既有 1.82.3 探针是 Chrome 114，chrome118 构建目标不能代替真宿主结果。

## 验收标准

- [ ] 真实输入扩展和组件设置页各有运行证据，验证首次输入及独立页面 SDK 工厂装配。
- [ ] 授权资源加载与未授权资源拒绝都有对照，至少一条呈现检查落在绘制层。
- [ ] 重复接入、关闭、故障、恢复和迟到消息矩阵可重放，释放后相关贡献和监听不再生效。
- [ ] 记录模块格式、SDK 构建桥、资源授权与共享运行时的具体方案和放行结论，未验证范围显式保留。

## 验证与留证

- 真实 VSCode 1.82.3 Webview 资源与 CSP
- 生产构建方式下的 CM6 输入和绘制
- 模块释放与代次拒收定向测试

- 不把测试组件发布到 Marketplace、npm 或独立外部仓库
- Remote SSH 留给安装侧验证票
