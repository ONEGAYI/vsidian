## 目标

补齐目标区重编辑、前缀查询、#／^／竖线转阶段与按键仲裁，让候选遵守完整输入契约。

## 交付范围

- 局部字段识别覆盖既有双链，只有单个折叠光标在目标区且用户输入／删除后再次触发；光标移动、别名编辑和外部同步不重开。
- 搜索只用光标左侧前缀；确认替换整个文件字段，保留右侧既有锚点／别名的阶段范围，避免旧名称残留。
- #／^ 接受高亮文件并切阶段，^ 形成 #^ 且不重复补 #；无明确目标只显示不可接受的占位；竖线接受当前阶段的真实高亮、无高亮保留，再关闭并手动输入。
- 新链接主动竖线留空，已有别名保留；无竖线的完成操作补默认文件名；确定各阶段确认后光标位置。
- 协调候选 Esc／Enter／Tab、自动补符／闭合越过、围栏越界、表格既有按键与缩进；不将 Tab 放进全局 keybindingRouter。
- 评估并记录会话操作可绑定入口、默认绑定／模式；IME 期间不消费选词键，多 range 不接管，模式／实例变化取消会话。

## 验收标准

- [ ] [[A¦a|B]] 在目标区输入／删除后查 A，确认文件替换完整 Aa 并原样保留 B。
- [ ] Esc 后仅移动光标不重开；编辑 B 不触发；返回 Aa 并修改才重开。
- [ ] 高亮文件后 #／^／竖线无需先 Enter 即转阶段；占位不写正文，无高亮竖线不补猜测文件。
- [ ] 竖线得到 [[方案.md|¦]]；Enter／Tab 新文件确认仍得到 [[方案.md|方案]]；已有别名不被覆盖。
- [ ] 候选 Esc 先关闭候选，其他既有弹层优先级和后续引用关闭链路保持；无可确认项原 Tab 越界／切格／缩进不变。
- [ ] 真实 IME 提交、选词 Enter、非空选区、多 range、外部同步／撤销和双模式切换均不出现误写或双补。
- [ ] 快捷键评估落入 keybindings 文档，未新增无门控全局键；文案／绘制与旧样式兼容证据完整。
