## 目标

对明确 Markdown 目标读取当前正文并提供标题候选，保留全部重复标题、选中时提示现有定位风险。

## 交付范围

- 文件目标明确且按来源相对路径解析为 Markdown 后，读取宿主当前 TextDocument；不以索引副本替代未保存内容。
- 按现有 ATX 标题／围栏排除口径枚举，候选有独立位置／身份，使用实际输入的标题前缀搜索。
- 重复标题全部展示，不合并；按现有定位规范化检测同名，选中时 toast，继续接受而不改跳转规则。
- 接受标题生成现有 #标题 语法，保留已有别名，无别名时仍用文件名；无目标／空候选显示不可接受占位。
- 目标改动、删除／改名和查询／版本变化时淘汰旧结果；权限／读取失败有真实状态，不猜当前文档或短名文件。

## 验收标准

- [ ] 目标存在未保存标题变更时，候选反映当前有效正文，不出现已删除旧标题。
- [ ] 两个同名标题各自出现可选择；选任何同名项 toast 提示风险，未合并，也未改变现有首处定位。
- [ ] 已高亮 Markdown 输入 # 后进入标题列表，输入前缀自动查询；非 Markdown 无标题／块列表。
- [ ] 接受结果如 [[方案.md#预算|方案]]；手写 B 保留，零目标 [[#]] 只占位不读默认文档。
- [ ] 旧目标版本／请求／根的返回无法覆盖新候选；失败不改变来源原文或自动保存目标。

## 验证

- 标题枚举与重名／版本单测；生产 browser：# 转阶段、全部重名行、toast、占位与选区。
- 真宿主：当前未保存 TextDocument、接受／跳转现行语义、删除与权限失败；可见候选／toast 绘制。

## 不包含与失败口径
