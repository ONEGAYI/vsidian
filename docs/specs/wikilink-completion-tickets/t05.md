## 目标

^ 转入块候选，按已确认粗粒度边界选择有／无 ID 的块，完成补写、来源插入及尽力撤回。

## 交付范围

- 按 shared/blockId 的空行／围栏边界枚举可引用块，连续列表和代码围栏各整体一块；可按片段及已有 ID 搜索。
- 有 ID 复用，无 ID 以目标当前文档查重生成，按已有独立行插入计划写入；先验证目标版本、块身份、可写和来源会话。
- ^ 是触发键，最终写 #^ID；路径／默认别名按既定规则，补 ID 和来源接受不自动保存。
- 根据 V01 放行方案记录来源接受与本次新增标记的因果关系，源与目标相同文档时一笔受控编辑。
- 来源撤销时尝试仅删除本次新增 ID；版本／标记变化、已观测新使用或不可执行时保留并 toast，来源继续撤销。
- 重做、来源接受失败、请求取消／释放的补 ID 收尾复核最新版；不借目标普通 undo 删除其无关输入。

## 验收标准

- [ ] 已有 ID 与无 ID 块均能出现；空查询／^ 无目标只有占位，代码围栏内部伪 ID 不被当作独立块。
- [ ] 连续列表整体、含空行代码围栏整体与现有块定位一致；生成 ID 查重，不能重写已有 ID。
- [ ] 选择无 ID 块后目标 dirty、来源写入 #^ID，两者都未自动保存，普通可写案例可撤销并尝试移除新增标记。
- [ ] 同文档操作按同一历史撤销；跨文档无法安全移除、目标已有修改、只读和失败案例保留 ID 并 toast，源撤销不阻塞。
- [ ] 重做与接受失败不复活他人改写的 ID，不删除既有标记，不撤掉 B 的无关输入。
- [ ] 按 V01 的明确放行结论落实现与验证；不得以附加组件 SDK／严格原子历史为新前置。

## 验证

- 块／ID／版本／收尾单测，生产 browser：^ 查询、选择和 toast／占位。
- 真宿主：跨文档与同文档、dirty、撤销／重做、目标并发修改、只读及取消释放；报告沿 V01 证据扩展。

## 不包含与失败口径

不做逐列表项、严格零副作用保证、自动保存、删除既有 ID 或 ^^ 全根块搜索。
