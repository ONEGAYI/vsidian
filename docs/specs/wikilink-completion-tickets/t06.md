## 目标

把完整候选链路接入主表格、悬停、嵌入和递归内部 Live，确保查询、插入和撤销属于实际编辑文档。

## 交付范围

- 通过 LiveEditorInstance 的公共装配与依赖注入提供候选，不建立第二套输入控制器；补齐 refEdit 请求／结果校验和白名单。
- B 内编辑时，文件范围与插入路径以 B 目录／根为准；B 引 C 的补 ID 和来源历史都不误写 A。
- 覆盖普通表格单元格及格内引用 Live，沿原始源码／解码坐标映射处理别名竖线，正文和表格语义一致。
- 涵盖根悬停、正文独占／混排嵌入与递归最深焦点；父 A 改动、内部滚动、模式切换与实例释放正确定位／取消。
- 共享缓存可加速，但每实例拥有查询代次、选择状态和端口守卫；释放后迟到不得回写父实例或新 B 会话。
- 候选中的 Esc 先关闭列表，再按原选区／关闭引用链路；读取失败、ID 警示和键位路由保持目标归属。

## 验收标准

- [ ] A／B 不同目录、各有同名文件时，B 候选与接受路径只以 B 为来源；A 字节和 appliedEdits 不变。
- [ ] 表格源码的竖线／别名按既有 \| 转义，前缀查询与完整字段替换不破坏网格，Tab 和 Esc 优先级正确。
- [ ] 悬停、独占／混排嵌入、格内嵌入与递归 C 中文件／标题／块均可选择，不出现父子同时消费按键。
- [ ] B 选择 C 的无 ID 块时，B 来源插入、C 补 ID及尽力撤销各归其文档；A 不被保存／撤销。
- [ ] 关闭／切 Reading／重绑端口／A 改动后的迟到结果拒收，最深焦点和 LF／CRLF 兼容矩阵有证据。
- [ ] 内部滚动和限高下候选仍实际可见且贴对应编辑器；主题／字体样式和 i18n 同源。

## 验证

- refEdit 协议／归属／源区间单测；生产 browser：tableCaret／embedLive／hoverLive／递归与真实键盘组合。
- 真宿主：B 解析与写回、C 补 ID、焦点历史、端口释放和绘制断言；style-contract 全门禁。

## 不包含与失败口径

不放宽引用权限、跨根解析或 Reading 写入；不得借根 A 统一消息通道绕过 B 守卫。
