## 目标

汇总全批生产验证，证明全文件候选的费用和失败收尾，交付人工待验、规格落档及完整报告。

## 交付范围

- 运行与变更相关的完整 unit／生产 browser／开发及安装态宿主／样式契约门禁，消费首轮日志和工具报告，不为补看信息重跑。
- 1千／1万／10万文件分别测首建、恢复、空查询、短长多词查询、文件事件、取消；区分 Markdown 和仅登记类型。
- 记录候选响应、事件循环、内存、磁盘／传输，不用小库或源码核查冒充性能通过，按数据调整边界。
- 补多根／嵌套根、无工作区、来源无路径、损坏缓存、丢事件、权限、重名标题、ID 收尾与双语言主题矩阵。
- 实际条件允许时做 Remote SSH；无法执行的部分保留待验和可复现实验步骤，不声明已通过。
- 更新人工清单、规格／批次状态、file-tree、查询复用来源和许可；自动化／代理自检不表述为用户验收。

## 验收标准

- [ ] 各核心用户故事有生产 browser／宿主或明确人工入口，至少一条候选绘制层集成断言有效。
- [ ] 全量验证报告有实际退出码和首轮日志，失败依据报告归类；未解决失败不被记录为通过。
- [ ] 三档文件数的匹配与登记费用有原始数据，长任务有界／可取消，不把附件全文塞进缓存。
- [ ] Windows 与 POSIX 路径语义、多根归属、Root／B／C、EOL、IME 和表格矩阵有证据或明确待验。
- [ ] Remote 和物理输入／鼠标／观感的人验记录真实状态，未执行项和限制明确。
- [ ] 规格、票面、文件树、样式与来源许可相互一致；总览不自动关闭，不自行推送／合并／发布。

## 验证

- 真实回归＋容量测量；优先消费 browser／integration 自带报告；装包／安装态依项目技能执行。
- 人工：日常 VSCode、真实 IME、鼠标、主题与 Remote SSH；记录执行者、版本和结果。

## 不包含与失败口径

不把文档验证或 CI 已知抖动豁免当作本功能完成；不扩大发布授权。

- 现有 #194／#196／#197–#202 与引用内部 Live 为已落地基础，不作为未完成依赖；#16 仅背景，附加组件 API／SDK 不作为前置。

- 用户文案 i18n；新增设置走自有设置页，操作按统一键位规则评估；保存和权威正文归 VSCode，缓存不扩大权限。
